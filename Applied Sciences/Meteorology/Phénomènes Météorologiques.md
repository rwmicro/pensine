# Phénomènes Météorologiques


### Nuages

**Classification (Luke Howard, 1802)**

*Nuages Hauts (>6000m)*
- **Cirrus (Ci)** : Filaments fins, glace, beau temps
- **Cirrocumulus (Cc)** : Petits flocons blancs
- **Cirrostratus (Cs)** : Voile fin, halo autour soleil/lune

*Nuages Moyens (2000-6000m)*
- **Altocumulus (Ac)** : Flocons/rouleaux gris/blancs
- **Altostratus (As)** : Voile gris uniforme, soleil diffus
- **Nimbostratus (Ns)** : Gris sombre, pluie/neige continue

*Nuages Bas (<2000m)*
- **Stratocumulus (Sc)** : Nappes/rouleaux gris
- **Stratus (St)** : Couche uniforme grise, brouillard élevé
- **Cumulus (Cu)** : Boules coton, beau temps si petits

*Nuages à Développement Vertical*
- **Cumulonimbus (Cb)** : Tour/enclume, orages violents
- **Cumulus congestus** : Tours développées, averses possibles

### Précipitations

**Formation**
- **Coalescence** : Gouttelettes fusionnent (nuages chauds)
- **Effet Bergeron** : Cristaux glace croissent (nuages froids)

**Types**

*Pluie*
- Gouttes >0.5mm
- Origine : Nuages Ns, Cb, Cu congestus

*Bruine (Drizzle)*
- Gouttes <0.5mm
- Origine : Nuages St bas

*Neige*
- Cristaux glace (température <0°C sol)
- Formes variées : Étoiles, plaquettes, aiguilles

*Grêle*
- Billes glace (>5mm), parfois >10cm
- Cumulonimbus : Courants ascendants violents
- Dégâts cultures, véhicules

*Verglas*
- Pluie surfond sur surface froide (<0°C)
- Très dangereux : Routes, lignes électriques

### Orages

**Formation**
1. **Cumulus** : Air chaud humide s'élève
2. **Maturité** : Cumulonimbus, pluie intense, éclairs
3. **Dissipation** : Courants descendants dominent

**Composantes**
- **Éclairs** : Décharge électrique (nuage-sol ou intra-nuage)
- **Tonnerre** : Onde sonore (expansion air chauffé)
- **Délai Éclair-Tonnerre** : Distance = secondes × 340m (vitesse son)

**Types**
- **Unicellulaires** : Isolés, courte durée (<1h)
- **Multicellulaires** : Plusieurs cellules, quelques heures
- **Supercellulaires** : Très violents, rotation (tornades possibles)

**Dangers**
- Foudre : 24 000 morts/an mondialement
- Vents violents, grêle, inondations éclair
- Tornades (supercellules)

### Tornades

**Caractéristiques**
- **Définition** : Colonne d'air en rotation violente, nuage-sol
- **Diamètre** : 10m à 2km
- **Vitesse Vents** : 65-500+ km/h
- **Durée** : Minutes à heure
- **Distance** : Quelques centaines mètres à 100+ km

**Échelle EF (Enhanced Fujita)**
- **EF0** : 105-137 km/h (dégâts légers)
- **EF1** : 138-178 km/h (modérés)
- **EF2** : 179-218 km/h (considérables)
- **EF3** : 219-266 km/h (sévères)
- **EF4** : 267-322 km/h (dévastateurs)
- **EF5** : >322 km/h (incroyables, rares)

**Géographie**
- **Tornado Alley** (USA) : Oklahoma, Kansas, Texas
- Formation : Rencontre air froid sec (Canada) + chaud humide (Golfe Mexique)

### Cyclones Tropicaux

**Nomenclature**
- **Ouragan** : Atlantique Nord, Pacifique NE
- **Typhon** : Pacifique NW
- **Cyclone** : Océan Indien, Pacifique Sud

**Formation**
- **Conditions** :
  1. Eau >26.5°C (énergie)
  2. Faible cisaillement vent
  3. Rotation Terre (Coriolis)
  4. >5° latitude (Coriolis suffisante)
- **Zone** : 5-20° latitude N/S

**Structure**
- **Œil** : Centre calme, 20-60km diamètre
- **Mur de l'Œil** : Vents max, pluies intenses
- **Bandes Spirales** : Orages autour centre

**Échelle Saffir-Simpson** (Ouragans)
- **Catégorie 1** : 119-153 km/h
- **Catégorie 2** : 154-177 km/h
- **Catégorie 3** : 178-208 km/h (majeur)
- **Catégorie 4** : 209-251 km/h (majeur)
- **Catégorie 5** : >251 km/h (majeur, catastrophique)

**Dangers**
- **Onde de Tempête** : Élévation niveau mer (jusqu'à 6m+)
- **Vents** : Destruction bâtiments, arbres
- **Pluies Torrentielles** : Inondations
- **Tornades** : Associées souvent

**Ouragans Notables**
- **Katrina** (2005) : Cat 5, Nouvelle-Orléans dévastée
- **Maria** (2017) : Cat 5, Porto Rico
- **Dorian** (2019) : Cat 5, Bahamas
