# Changement Climatique


### Effet de Serre

**Principe**
1. Soleil émet rayonnement (visible, UV)
2. Terre absorbe, réchauffe
3. Terre émet rayonnement infrarouge
4. Gaz à effet de serre (GES) absorbent IR, réchauffent atmosphère
5. Température équilibre plus élevée

**Gaz à Effet de Serre**
- **Vapeur d'Eau (H₂O)** : Principal GES naturel, rétroaction
- **Dioxyde de Carbone (CO₂)** : 280 ppm (préindustriel) → 420+ ppm (2024)
  - Sources : Combustion fossiles, déforestation
  - Durée vie : Siècles
- **Méthane (CH₄)** : Élevage, rizières, fuites gaz naturel
  - Pouvoir réchauffant : 28-36× CO₂ (100 ans)
- **Protoxyde d'Azote (N₂O)** : Agriculture (engrais)
  - Pouvoir : ~300× CO₂
- **Gaz Fluorés** : HFC, PFC (industrie, réfrigération)

### Observations du Changement

**Températures**
- **+1.1°C** depuis ère préindustrielle (1850-1900)
- **Accélération** : +0.2°C par décennie (1980-2020)
- **Projection** : +1.5-4.5°C d'ici 2100 selon scénarios

**Glaces**
- **Arctique** : Banquise -13% par décennie (été)
- **Groenland** : Fonte ~280 Gt/an (gigatonnes)
- **Antarctique** : Fonte accélère (Ouest)
- **Glaciers** : Recul généralisé (Alpes, Himalaya, Andes)

**Niveau Mers**
- **+20 cm** depuis 1900
- **Rythme Actuel** : +3.3 mm/an
- **Causes** : Dilatation thermique (50%), fonte glaces (50%)
- **Projection** : +0.3-1m d'ici 2100

**Événements Extrêmes**
- **Canicules** : Fréquence/intensité augmentées
- **Sécheresses** : Prolongées (Méditerranée, Australie, Afrique)
- **Précipitations** : Plus intenses localement
- **Cyclones** : Plus intenses (débat sur fréquence)

### Impacts

**Environnementaux**
- **Écosystèmes** : Migration espèces, extinction accélérée
- **Océans** : Acidification (↑CO₂ absorbé), blanchiment coraux
- **Pergélisol** : Dégel (libération CH₄, CO₂)
- **Forêts** : Incendies (Australie, Californie, Sibérie)

**Humains**
- **Agriculture** : Rendements ↓ (sécheresses), zones culture changées
- **Eau** : Stress hydrique accru (glaciers sources)
- **Santé** : Maladies vectorielles (paludisme expansion), canicules
- **Migrations** : Réfugiés climatiques (sécheresses, élévation mers)
- **Économie** : Dommages infrastructures, assurances

**Rétroactions**
- **Positive** (amplification) :
  - Vapeur eau : ↑T → ↑évaporation → ↑GES
  - Albédo : Fonte glace → surface sombre → ↑absorption chaleur
  - Pergélisol : Dégel → libération CH₄/CO₂
- **Négative** (atténuation) :
  - Végétation : ↑CO₂ → croissance plantes → ↑séquestration
  - Nuages : Complexe, incertain

### Atténuation

**Réduction Émissions**
- **Énergies Renouvelables** : Solaire, éolien, hydraulique (voir [[Physics/Thermodynamique]])
- **Efficacité Énergétique** : Bâtiments, transports, industrie
- **Électrification** : Transports, chauffage
- **Capture Carbone** : CCS (Carbon Capture and Storage), DAC (Direct Air Capture)

**Secteurs Clés**
- **Énergie** (73% émissions) : Fossiles → renouvelables
- **Agriculture** (18%) : Pratiques durables, moins élevage (voir [[Agriculture/Agriculture - Index]])
- **Transport** (16%) : Électrique, transports publics
- **Bâtiments** : Isolation, pompes à chaleur
- **Industrie** : Procédés bas carbone (acier, ciment)

**Accords Internationaux**
- **Protocole de Kyoto** (1997) : Premiers engagements
- **Accord de Paris** (2015) : Limiter réchauffement <2°C, idéalement 1.5°C
  - Contributions déterminées nationalement (NDC)
- **COP** (Conferences of Parties) : Négociations annuelles

### Adaptation

**Stratégies**
- **Côtes** : Digues, restauration mangroves, relocalisation
- **Agriculture** : Variétés résistantes, irrigation efficace, diversification
- **Eau** : Stockage, dessalement, gestion demande
- **Villes** : Îlots fraîcheur, toits verts, infrastructures résilientes
- **Santé** : Surveillance maladies, plans canicule

**Planification**
- Évaluation vulnérabilités
- Intégration politiques développement
- Financement (Fonds Vert Climat)
