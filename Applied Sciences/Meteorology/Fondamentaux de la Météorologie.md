# Fondamentaux de la Météorologie


### L'Atmosphère Terrestre

**Structure Verticale**

*Troposphère* (0-12 km)
- Contient 75% masse atmosphère
- Où se produisent phénomènes météo
- Température décroît avec altitude (~6.5°C/km)
- Sommet : Tropopause

*Stratosphère* (12-50 km)
- Couche d'ozone (15-35 km) : Absorbe UV
- Température croît (ozone absorbe rayonnement)
- Air stable, peu turbulences
- Utilisée aviation long-courrier

*Mésosphère* (50-80 km)
- Température décroît à nouveau
- Plus froide atmosphère (-90°C sommet)
- Météores brûlent ici

*Thermosphère* (80-600 km)
- Température très élevée (>1000°C)
- Aurores boréales/australes
- Station Spatiale Internationale (ISI) : ~400 km

*Exosphère* (>600 km)
- Transition vers espace
- Atomes s'échappent gravité

**Composition Atmosphère**
- **Azote (N₂)** : 78%
- **Oxygène (O₂)** : 21%
- **Argon (Ar)** : 0.93%
- **Dioxyde de Carbone (CO₂)** : 0.04% (variable, augmente)
- **Vapeur d'Eau (H₂O)** : 0-4% (variable selon lieu/temps)
- **Gaz Traces** : Méthane (CH₄), ozone (O₃), etc.

### Variables Météorologiques

**Température**
- **Mesure** : Thermomètres (mercure, électroniques)
- **Unités** : °C (Celsius), °F (Fahrenheit), K (Kelvin)
- **Record Mondial** : 
  - Max : 56.7°C (Death Valley, USA, 1913)
  - Min : -89.2°C (Vostok, Antarctique, 1983)

**Pression Atmosphérique**
- **Définition** : Poids colonne d'air au-dessus
- **Niveau Mer** : 1013.25 hPa (hectopascals) = 1 atm
- **Mesure** : Baromètre (mercure, anéroïde)
- **Variation** : Haute pression (anticyclone), basse pression (dépression)
- **Altitude** : Diminue ~1 hPa par 8m

**Humidité**
- **Humidité Absolue** : Masse vapeur eau / volume air (g/m³)
- **Humidité Relative** : % saturation à température donnée
- **Point de Rosée** : Température où air devient saturé
- **Mesure** : Hygromètre, psychromètre

**Vent**
- **Vitesse** : km/h, m/s, nœuds
- **Direction** : D'où vient le vent (N, NE, E, SE, S, SW, W, NW)
- **Mesure** : Anémomètre (vitesse), girouette (direction)
- **Échelle Beaufort** : 0 (calme) à 12 (ouragan)

**Précipitations**
- **Types** : Pluie, neige, grêle, verglas, bruine
- **Mesure** : Pluviomètre (mm ou L/m²)
- **Intensité** : Faible (<2.5 mm/h), modérée (2.5-10), forte (>10)

**Visibilité**
- **Définition** : Distance max objet visible
- **Facteurs** : Brouillard, brume, précipitations, poussière
- **Aviation** : Critique pour sécurité
