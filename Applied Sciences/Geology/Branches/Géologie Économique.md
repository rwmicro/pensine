# Géologie Économique


### Ressources Minérales

**Minerais Métalliques**
- **Fer** : hématite, magnétite (sidérurgie)
- **Aluminium** : bauxite (transport, construction)
- **Cuivre** : chalcopyrite (électricité)
- **Or, Argent** : joaillerie, électronique
- **Terres rares** : électronique, aimants, batteries (Chine 80% production)

**Minerais Non-Métalliques**
- **Sel** : halite (alimentation, chimie)
- **Phosphates** : engrais
- **Calcaire** : ciment, chaux
- **Argiles** : céramique, briques
- **Diamants industriels** : abrasifs

**Gisements**
- Magmatiques (chromite, platine)
- Hydrothermaux (or, argent, cuivre)
- Sédimentaires (fer rubané, phosphates)
- Altération (bauxite, latérites nickélifères)

### Énergies Fossiles

**Pétrole et Gaz Naturel**
- **Formation** : matière organique (plancton) enfouie, température (60-120°C pour pétrole)
- **Roche-mère** : schistes bitumineux
- **Réservoir** : grès, calcaires poreux
- **Piège** : anticlinal, faille, discordance + roche couverture imperméable
- **Extraction** : conventionnelle (puits), non-conventionnelle (fracturation hydraulique)
- **Réserves** : Moyen-Orient, Russie, USA

**Charbon**
- Tourbe → Lignite → Houille → Anthracite (↑ température, pression, temps)
- Dépôts forêts Carbonifère, Permien
- Mines : ciel ouvert, souterraines
- Pollution (CO₂, particules, SO₂)

**Schistes Bitumineux, Sables Bitumineux**
- Pétrole non conventionnel
- Extraction coûteuse, polluante

### Géothermie

- Chaleur interne Terre
- Haute température (volcans, Islande) : électricité
- Basse température : chauffage
- Renouvelable, faible CO₂
