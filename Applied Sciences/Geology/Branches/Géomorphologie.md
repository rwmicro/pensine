# Géomorphologie


### Processus d'Érosion

**Météorisation (Altération)**
- **Physique** : fragmentation sans changement chimique
  - Thermoclastie (gel-dégel), haloclastie (sel), désagrégation granulaire
- **Chimique** : dissolution, oxydation, hydrolyse
  - Dissolution calcaire → karst (grottes, dolines, poljés)
  - Altération granites → argiles + sables quartzeux

**Agents d'Érosion**

**Eau**
- **Fluviale** : vallées, méandres, deltas, terrasses
  - Érosion, transport, sédimentation
  - Gorges (Colorado : Grand Canyon)
- **Marine** : falaises, plages, arches, grottes
  - Vagues, marées, courants
- **Souterraine** : karst, rivières souterraines, stalactites/stalagmites

**Vent (Éolien)**
- Déserts : dunes (barkhanes, transverses, paraboliques)
- Déflation, abrasion
- Loess (sédiments fins déposés)

**Glace (Glaciaire)**
- Glaciers : érosion puissante
- **Formes érosion** : vallées en U, cirques, arêtes, horns (Matterhorn)
- **Dépôts** : moraines (frontale, latérale, médiane, de fond), drumlins, eskers

**Gravité**
- Glissements terrain, éboulements, coulées de débris

### Reliefs

**Montagnes**
- Jeunes : Himalaya, Alpes, Rocheuses (relief accentué, sommets aigus)
- Anciennes : Appalaches, Oural (érodées, arrondies)

**Plateaux**
- Tibet, Colorado Plateau

**Plaines**
- Alluviales, côtières, abyssales

**Volcans**
- Boucliers (Hawaii), stratovolcans (Fuji), caldeiras (Yellowstone)
