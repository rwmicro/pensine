# Minéralogie


### Définition et Propriétés

**Minéral**
- Solide naturel, inorganique (généralement)
- Composition chimique définie
- Structure cristalline ordonnée (arrangement atomique régulier)
- Propriétés physiques constantes

**Critères d'Identification**

**1. Cristallographie**
- **Système cristallin** : 7 systèmes (cubique, hexagonal, tétragonal, orthorhombique, monoclinique, triclinique, rhomboédrique)
- **Habitus** : forme externe cristaux (prismatique, tabulaire, aciculaire, massif)

**2. Dureté (Échelle de Mohs, 1-10)**
1. Talc (rayable ongle)
2. Gypse
3. Calcite (rayable pièce cuivre)
4. Fluorite
5. Apatite (rayable verre)
6. Orthose (feldspath)
7. Quartz (raye verre)
8. Topaze
9. Corindon (rubis, saphir)
10. Diamant (substance naturelle la plus dure)

**3. Clivage et Fracture**
- **Clivage** : cassure selon plans de faiblesse cristallographique (mica : 1 plan parfait)
- **Fracture** : cassure irrégulière (quartz : conchoïdale)

**4. Couleur et Éclat**
- **Couleur** : peut varier (impuretés, altération)
- **Trait** : couleur poudre minéral (plus fiable)
- **Éclat** : métallique, vitreux, nacré, adamantin, terreux, soyeux

**5. Densité**
- Rapport poids/volume
- Quartz : 2,65 ; Galène : 7,5

**6. Autres**
- **Magnétisme** : magnétite
- **Fluorescence UV** : calcite, fluorite
- **Radioactivité** : uraninite, pechblende
- **Goût** : halite (NaCl, sel gemme)

### Groupes Minéraux Majeurs

**Silicates (90% croûte terrestre)**
- Structure base : tétraèdre SiO₄
- **Nésosilicates** : tétraèdres isolés
  - Olivine (Mg,Fe)₂SiO₄ : vert, manteau, péridotite
  - Grenat : métamorphisme
- **Sorosilicates** : tétraèdres doubles (épidote)
- **Cyclosilicates** : anneaux (béryl : émeraude, aigue-marine ; tourmaline)
- **Inosilicates** : chaînes
  - **Pyroxènes** : chaîne simple (augite)
  - **Amphiboles** : chaîne double (hornblende)
- **Phyllosilicates** : feuillets (structure 2D)
  - **Micas** : biotite (noir), muscovite (blanc), clivage parfait
  - **Argiles** : kaolinite, montmorillonite
  - **Chlorite, Talc, Serpentine**
- **Tectosilicates** : réseau 3D (75% croûte)
  - **Quartz** SiO₂ : très abondant, dur (7), inaltérable, variétés (cristal de roche, améthyste, citrine, agate)
  - **Feldspaths** (60% croûte) :
    - Plagioclases (Na-Ca) : albite → anorthite
    - Feldspaths alcalins (K) : orthose, microcline
  - **Feldspathoïdes** : néphéline, leucite

**Carbonates**
- **Calcite** CaCO₃ : calcaire, marbre, effervescence HCl
- **Dolomite** CaMg(CO₃)₂ : dolomie
- **Aragonite** : même formule calcite, structure différente (polymorphe)
- **Sidérite, Magnésite**

**Oxydes et Hydroxydes**
- **Hématite** Fe₂O₃ : minerai fer principal, rouge
- **Magnétite** Fe₃O₄ : magnétique, noir
- **Corindon** Al₂O₃ : rubis (Cr), saphir (Fe, Ti), dureté 9
- **Quartz** SiO₂ (déjà mentionné)
- **Bauxite** : Al(OH)₃, minerai aluminium

**Sulfures**
- **Pyrite** FeS₂ : "or des fous", cubique, métallique
- **Galène** PbS : minerai plomb, cubique, dense, clivage parfait
- **Sphalérite** ZnS : minerai zinc
- **Chalcopyrite** CuFeS₂ : minerai cuivre
- **Cinabre** HgS : mercure, rouge

**Sulfates**
- **Gypse** CaSO₄·2H₂O : dureté 2, plâtre
- **Barytine** BaSO₄ : dense

**Halogénures**
- **Halite** NaCl : sel gemme, cubique
- **Fluorite** CaF₂ : fluorescence, clivage octaédrique parfait

**Éléments Natifs**
- **Or** Au, **Argent** Ag, **Cuivre** Cu : métalliques
- **Soufre** S : jaune
- **Graphite** C : noir, doux, conducteur
- **Diamant** C : transparent, dur (10), isolant

### Gemmes et Pierres Précieuses

**Les "Quatre Grandes"**
- **Diamant** : carbone pur, dureté 10, indice réfraction élevé, dispersion (feux)
  - Formation : manteau (150-200 km), pression extrême, remonté par kimberlite
  - Mines : Afrique du Sud, Russie, Botswana, Canada
- **Rubis** : corindon rouge (Cr³⁺), Myanmar, 9
- **Saphir** : corindon bleu (Fe, Ti), aussi rose, jaune, 9
- **Émeraude** : béryl vert (Cr, V), Colombie, 7,5-8

**Autres Gemmes**
- **Topaze, Aigue-marine, Tourmaline, Améthyste, Opale, Jade (néphrite, jadéite), Turquoise, Péridot (olivine), Tanzanite**

**Critères Qualité (4C)**
- **Carat** : poids (1 carat = 0,2 g)
- **Couleur** (Color)
- **Pureté** (Clarity) : inclusions
- **Taille** (Cut) : facettes, proportions
