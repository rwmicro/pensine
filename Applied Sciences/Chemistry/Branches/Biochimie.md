# Biochimie

**La chimie du vivant**

## Définition

La biochimie étudie les processus chimiques au sein des organismes vivants, notamment les molécules biologiques et leur métabolisme.

## Macromolécules biologiques

### 1. Protéines

**Structure** : Chaînes d'acides aminés (20 types)

**Niveaux de structure** :
- Primaire : Séquence
- Secondaire : Hélice α, feuillet β
- Tertiaire : Repliement 3D
- Quaternaire : Assemblage de sous-unités

**Fonctions** :
- Enzymes (catalyse)
- Structure (collagène, kératine)
- Transport (hémoglobine)
- Défense (anticorps)
- Régulation (hormones)

### 2. Acides nucléiques

**ADN** (acide désoxyribonucléique) :
- Double hélice
- Stockage de l'information génétique
- Bases : A, T, G, C

**ARN** (acide ribonucléique) :
- Simple brin
- Transmission de l'information
- Bases : A, U, G, C

**Dogme central** :
```
ADN → ARN → Protéine
```

### 3. Lipides

**Types** :
- Triglycérides (graisses)
- Phospholipides (membranes)
- Stéroïdes (cholestérol, hormones)

**Fonctions** :
- Stockage d'énergie
- Membranes cellulaires
- Signalisation

### 4. Glucides

**Types** :
- Monosaccharides (glucose, fructose)
- Disaccharides (saccharose, lactose)
- Polysaccharides (amidon, glycogène, cellulose)

**Fonctions** :
- Énergie rapide
- Stockage d'énergie
- Structure (cellulose)

## Métabolisme

### Catabolisme (dégradation)

**Glycolyse** :
- Glucose → Pyruvate
- Produit 2 ATP

**Cycle de Krebs** :
- Oxydation du pyruvate
- Produit NADH, FADH₂, CO₂

**Chaîne respiratoire** :
- NADH → ATP (32-34 ATP par glucose)
- Consomme O₂

### Anabolisme (synthèse)

**Photosynthèse** :
```
6 CO₂ + 6 H₂O + lumière → C₆H₁₂O₆ + 6 O₂
```

**Synthèse des protéines** :
- Transcription (ADN → ARN)
- Traduction (ARN → protéine)

## Enzymes

**Catalyseurs biologiques**

**Caractéristiques** :
- Spécificité (clé-serrure)
- Site actif
- Abaissent énergie d'activation

**Facteurs** :
- pH optimal
- Température optimale
- Concentration

**Régulation** :
- Inhibition compétitive
- Inhibition non-compétitive
- Allostérie

## Voies métaboliques importantes

- **Glycolyse** : Dégradation du glucose
- **Gluconéogenèse** : Synthèse du glucose
- **Cycle de Krebs** : Production d'énergie
- **β-oxydation** : Dégradation des lipides
- **Synthèse d'acides gras**
- **Cycle de l'urée** : Élimination de l'azote

## Applications

- **Médecine** : Diagnostic, médicaments
- **Biotechnologie** : Enzymes industrielles, OGM
- **Nutrition** : Régimes, suppléments
- **Forensique** : Analyse ADN
- **Agriculture** : Amélioration des cultures
