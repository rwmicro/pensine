# Chimie analytique

**Identification et quantification des substances**

## Définition

La chimie analytique développe et applique des méthodes pour déterminer la composition chimique et la structure des matériaux.

## Types d'analyse

### Analyse qualitative

**Identifier les composants présents**

Méthodes :
- Tests chimiques (précipitation, coloration)
- Spectroscopie
- Chromatographie

### Analyse quantitative

**Déterminer les quantités**

Méthodes :
- Titrage
- Spectrophotométrie
- Chromatographie quantitative

## Techniques principales

### 1. Spectroscopie

**Interaction lumière-matière**

**UV-Visible** :
- Transitions électroniques
- Concentration de composés colorés
- Loi de Beer-Lambert : A = εlc

**Infrarouge (IR)** :
- Vibrations moléculaires
- Identification de groupes fonctionnels
- Analyse de composés organiques

**RMN (Résonance Magnétique Nucléaire)** :
- Structure moléculaire
- Position des atomes (¹H, ¹³C)
- Identification de molécules organiques

**Spectrométrie de masse (MS)** :
- Masse moléculaire
- Fragmentation
- Très sensible (traces)

### 2. Chromatographie

**Séparation de mélanges**

**Chromatographie sur Couche Mince (CCM)** :
- Rapide, simple
- Analyse qualitative

**Chromatographie Liquide Haute Performance (HPLC)** :
- Séparation de liquides
- Quantification précise
- Pharmaceutique, alimentaire

**Chromatographie en Phase Gazeuse (GC)** :
- Séparation de composés volatils
- Couplage GC-MS (très puissant)
- Forensique, environnement

**Chromatographie d'exclusion** :
- Séparation par taille
- Protéines, polymères

### 3. Électrochimie

**Mesures électriques**

**pH-métrie** :
- Mesure du pH
- Titrage acide-base

**Potentiométrie** :
- Mesure de potentiel
- Électrodes spécifiques (ions)

**Voltampérométrie** :
- Courant vs potentiel
- Traces de métaux

### 4. Titrage

**Réaction quantitative avec réactif connu**

**Types** :
- Acide-base (neutralisation)
- Redox (oxydoréduction)
- Complexométrique (EDTA)
- Précipitation

**Indicateurs** :
- Colorés (phénolphtaléine, bleu de bromothymol)
- pH-mètre

### 5. Analyse thermique

**DSC** (Calorimétrie différentielle à balayage) :
- Transitions de phase
- Pureté

**TGA** (Analyse thermogravimétrique) :
- Perte de masse vs température
- Composition

## Préparation d'échantillon

**Étapes** :
1. Échantillonnage
2. Séchage/broyage
3. Dissolution/extraction
4. Purification
5. Dilution

**Techniques d'extraction** :
- Extraction liquide-liquide
- Extraction solide-liquide (Soxhlet)
- Extraction par fluide supercritique

## Validation de méthode

**Critères** :
- **Exactitude** : Proche de la vraie valeur
- **Précision** : Reproductibilité
- **Sensibilité** : Détection de faibles quantités
- **Sélectivité** : Distinction d'analytes similaires
- **Limite de détection (LOD)**
- **Limite de quantification (LOQ)**

## Applications

### Environnement

- Qualité de l'eau, air, sol
- Polluants (métaux lourds, pesticides)
- Surveillance

### Pharmaceutique

- Pureté de médicaments
- Contrôle qualité
- Métabolites

### Alimentaire

- Additifs
- Contaminants
- Valeur nutritionnelle
- Fraude (traçabilité)

### Forensique

- Analyse de drogues
- Toxicologie
- Résidus de tir
- ADN

### Clinique

- Analyses de sang, urine
- Diagnostic médical
- Dosage hormones, vitamines

### Industrielle

- Contrôle de procédés
- Qualité des produits
- Matières premières
