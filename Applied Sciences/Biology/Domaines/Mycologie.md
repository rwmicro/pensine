# Mycologie

L'étude des champignons (fungi).

**Caractéristiques des Champignons**
- **Eucaryotes** : Noyau défini
- **Hétérotrophes** : Absorbent nutriments (décomposeurs)
- **Paroi Cellulaire** : Chitine (pas cellulose)
- **Structure** : Hyphes → mycélium
- **Reproduction** : Spores (sexuée/asexuée)

**Classification**
- **Zygomycètes** : Moisissures (pain moisi)
- **Ascomycètes** : Levures, morilles, truffes
- **Basidiomycètes** : Champignons à chapeau (amanites, cèpes)
- **Deutéromycètes** : Reproduction asexuée uniquement

**Rôles Écologiques**
- **Décomposeurs** : Recyclage de matière organique
- **Mycorhizes** : Symbiose avec racines de plantes
- **Lichens** : Symbiose avec algues/cyanobactéries

**Champignons Pathogènes**
- **Humains** : Candidose, teigne, aspergillose
- **Plantes** : Rouilles, mildiou, ergot du seigle
- **Amphibiens** : Chytridiomycose (déclin mondial)

**Utilisations**
- **Alimentation** : Champignons comestibles, levure (pain, bière)
- **Médecine** : Pénicilline (antibiotique), statines
- **Biotechnologie** : Production d'enzymes, biocarburants

**Champignons Toxiques**
- Amanite phalloïde (mortelle)
- Amanite tue-mouches (psychotrope)
