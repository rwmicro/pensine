# Ouvertures


### Principes Généraux → [[Ouvertures|voir guide complet]]

1. **Contrôler le centre** (e4, e5, d4, d5)
2. **Développer rapidement les pièces** (Cavaliers et Fous)
3. **Roquer tôt** (sécurité du Roi)
4. **Ne pas sortir la Dame trop tôt** (cible facile)
5. **Ne pas bouger la même pièce deux fois** (sauf nécessité)
6. **Connecter les Tours**

### Ouvertures Blancs

**Ouvertures e4 (Ouvertes)**
- **Partie Italienne** : 1.e4 e5 2.Nf3 Nc6 3.Bc4 → [[Ouvertures#Partie Italienne|détails]]
- **Ruy Lopez (Espagnole)** : 1.e4 e5 2.Nf3 Nc6 3.Bb5 → [[Ouvertures#Partie Espagnole (Ruy Lopez)|détails]]
  - Variantes : Morphy, Marshall, Berlin, etc.
- **Écossaise** : 1.e4 e5 2.Nf3 Nc6 3.d4
- **Gambit du Roi** : 1.e4 e5 2.f4 (romantique, risqué)
- **Viennoise** : 1.e4 e5 2.Nc3

**Ouvertures d4 (Semi-Fermées, Fermées)**
- **Gambit Dame** : 1.d4 d5 2.c4 → [[Ouvertures#Gambit Dame|détails]]
  - Accepté (2...dxc4)
  - Refusé (2...e6, 2...c6)
  - Slave, Semi-Slave
- **Ouverture Anglaise** : 1.c4 → [[Ouvertures#Attaque Anglaise|détails]]
- **Réti** : 1.Nf3
- **Défenses Indiennes** : après 1.d4 Nf6
  - Nimzo-Indienne, Est-Indienne, Ouest-Indienne, Grünfeld, Benoni

### Défenses Noirs

**Contre e4**
- **Défense Sicilienne** : 1.e4 c5 → [[Ouvertures#Défense Sicilienne|détails]]
  - Plus populaire, asymétrique, déséquilibre
  - Variantes : Najdorf, Dragon, Sveshnikov, Taimanov, Kan
- **Française** : 1.e4 e6 → [[Ouvertures#Défense Française|détails]]
- **Caro-Kann** : 1.e4 c6 → [[Ouvertures#Défense Caro-Kann|détails]]
- **Scandinave** : 1.e4 d5
- **Pirc/Moderne** : 1.e4 d6/g6
- **Alekhine** : 1.e4 Nf6 (hypermoderne)

**Contre d4**
- **Nimzo-Indienne** : 1.d4 Nf6 2.c4 e6 3.Nc3 Bb4 → [[Ouvertures#Défense Nimzo-Indienne|détails]]
- **Grünfeld** : 1.d4 Nf6 2.c4 g6 3.Nc3 d5 → [[Ouvertures#Défense Grünfeld|détails]]
- **Est-Indienne** : 1.d4 Nf6 2.c4 g6
- **Slave/Semi-Slave** : réponses au Gambit Dame
- **Hollandaise** : 1.d4 f5 (agressive, risquée)

### Répertoire d'Ouvertures

**Construction**
- Choisir 1-2 ouvertures principales par couleur
- Apprendre variantes principales et idées
- Étudier parties de maîtres
- Analyser ses propres parties

**Ressources**
- Bases de données : ChessBase, Lichess Opening Explorer
- Livres : *My System* (Nimzowitsch), séries "Starting Out", "Dangerous Weapons"
- Vidéos : ChessNetwork, GothamChess, Daniel Naroditsky
