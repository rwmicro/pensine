# Système Solaire


### Formation (il y a 4,6 milliards d'années)

**Nébuleuse Solaire**
- Nuage gaz et poussières (H, He + éléments lourds supernovae antérieures)
- Effondrement gravitationnel (onde choc supernova voisine ?)
- Rotation → disque protoplanétaire

**Protoétoile**
- Concentration masse au centre
- Température ↑ → fusion nucléaire → naissance Soleil
- T Tauri phase : vents stellaires violents

**Planètes**
- Accrétion poussières → planétésimaux → protoplanètes → planètes
- **Ligne de glace** (~4-5 UA) : au-delà, volatils (H₂O, CH₄, NH₃) se condensent
  - Intérieur : planètes rocheuses (telluriques)
  - Extérieur : géantes gazeuses/glacées
- Bombardement intense (cratérisation)

### Le Soleil

**Caractéristiques**
- **Type spectral** : G2V (naine jaune, séquence principale)
- **Masse** : 1,989 × 10³⁰ kg (99,86% système solaire)
- **Rayon** : 696 000 km (109× Terre)
- **Température** : 
  - Surface (photosphère) : 5 778 K
  - Cœur : 15 millions K
  - Couronne : 1-2 millions K (paradoxe chauffage coronal)
- **Luminosité** : 3,828 × 10²⁶ W
- **Composition** : 73% H, 25% He, 2% autres

**Structure**
- **Cœur** (0-0,25 R☉) : fusion H → He (cycle proton-proton)
- **Zone radiative** (0,25-0,7 R☉) : transport énergie par radiation (photons)
- **Zone convective** (0,7-1 R☉) : cellules convection (granulation visible)
- **Photosphère** : surface visible, taches solaires
- **Chromosphère** : atmosphère basse, éruptions
- **Couronne** : atmosphère externe, vent solaire
- **Héliosphère** : bulle magnétique, jusqu'à ~100 UA (héliopause)

**Activité Solaire**
- **Taches solaires** : régions plus froides (3500-4000 K), champ magnétique intense
- **Cycle 11 ans** : minimum → maximum activité
- **Éruptions solaires, éjections masse coronale (CME)** : impact Terre (aurores, orages géomagnétiques)
- **Vent solaire** : flux particules chargées

**Évolution Future**
- Dans ~5 milliards d'années : épuisement H cœur → géante rouge
- Engloutira Mercure, Vénus, peut-être Terre
- Noyau He → fusion He → C, O
- Éjection enveloppe → nébuleuse planétaire
- Cœur résiduel → naine blanche (carbone-oxygène)

### Planètes Telluriques (Rocheuses)

**Mercure**
- **Distance** : 0,39 UA (57,9 millions km)
- **Rayon** : 0,38 R⊕
- **Masse** : 0,055 M⊕
- **Température** : -173°C (nuit) à +427°C (jour) (amplitude maximale système)
- **Atmosphère** : quasi-inexistante (exosphère : Na, K)
- **Surface** : cratérisée (Bassin Caloris 1550 km), falaises (contraction refroidissement)
- **Particularités** : 
  - Excentricité orbitale élevée (0,206)
  - Résonance 3:2 rotation-révolution
  - Noyau fer massif (75% rayon)
  - Glace eau cratères polaires (zones ombre permanente)
- **Missions** : Mariner 10, MESSENGER, BepiColombo (en cours)

**Vénus**
- **Distance** : 0,72 UA
- **Rayon** : 0,95 R⊕
- **Masse** : 0,82 M⊕ ("jumelle Terre" en taille)
- **Rotation** : rétrograde, 243 jours (jour > année!)
- **Atmosphère** : 
  - 96,5% CO₂ (effet de serre extrême)
  - Pression surface : 92 bars (équivalent 900 m sous eau Terre)
  - Nuages acide sulfurique
  - Température surface : 462°C (plus chaude que Mercure!)
- **Surface** : volcans (Maat Mons), plaines lave, cratères
- **Particularités** :
  - Super-rotation atmosphérique (vents 300 km/h altitude)
  - Volcanisme possiblement actif
  - Pas de champ magnétique intrinsèque
- **Missions** : Venera (URSS, atterrissages), Magellan (radar), Venus Express, Akatsuki

**Terre**
- **Distance** : 1 UA (149,6 millions km, unité de mesure)
- **Rayon** : 6 371 km
- **Masse** : 5,972 × 10²⁴ kg
- **Âge** : 4,54 milliards années
- **Atmosphère** : 78% N₂, 21% O₂, 1% Ar + traces (CO₂, H₂O)
- **Température moyenne** : 15°C
- **Particularités** :
  - **Seule planète avec vie connue**
  - Eau liquide surface (70% océans)
  - Tectonique plaques
  - Champ magnétique (protection vent solaire)
  - 1 satellite : Lune
- **Lune** :
  - Rayon : 0,27 R⊕ (grand satellite relatif à planète)
  - Formation : impact géant (Theia, 4,5 Ga)
  - Synchronisation rotation : face cachée
  - Influence : marées, stabilisation axe Terre
  - Éloignement : 3,8 cm/an
  - Exploration : Apollo (1969-1972, 12 humains), missions robotiques

**Mars**
- **Distance** : 1,52 UA
- **Rayon** : 0,53 R⊕
- **Masse** : 0,11 M⊕
- **Rotation** : 24,6 h (similaire Terre)
- **Inclinaison** : 25° → saisons
- **Atmosphère** : 
  - Très ténue : 0,6% pression Terre
  - 95% CO₂
  - Tempêtes de poussière globales
- **Température** : -140°C (pôles hiver) à +20°C (équateur été)
- **Surface** :
  - **Olympus Mons** : plus grand volcan système solaire (25 km haut, 600 km large)
  - **Valles Marineris** : canyon 4000 km long, 7 km profond
  - **Calottes polaires** : H₂O + CO₂ gelés
  - Traces lits rivières asséchés, deltas
- **Eau** : glace sous-surface, saumures saisonnières possible
- **2 Lunes** : Phobos, Deimos (astéroïdes capturés)
- **Missions** : Viking, Pathfinder, Spirit & Opportunity, Curiosity, Perseverance (recherche vie passée), InSight (sismologie)
- **Future** : colonisation envisagée (SpaceX, NASA)

### Ceinture d'Astéroïdes (2-4 UA)

- Millions objets rocheux
- **Cérès** : planète naine, 940 km, 30% masse totale ceinture
- **Vesta, Pallas, Hygiea**
- Restes formation système solaire (Jupiter empêché accrétion planète)
- Classes : C (carbonés), S (silicatés), M (métalliques)
- Missions : Dawn (Vesta, Cérès), Hayabusa (Itokawa), OSIRIS-REx (Bennu)

### Planètes Géantes

**Jupiter**
- **Distance** : 5,2 UA
- **Rayon** : 11,2 R⊕
- **Masse** : 318 M⊕ (2,5× toutes autres planètes combinées)
- **Composition** : 90% H, 10% He + traces CH₄, NH₃, H₂O
- **Pas de surface solide** : géante gazeuse, pression ↑ avec profondeur → H liquide → H métallique
- **Rotation** : 9,9 h (la plus rapide, aplatissement visible)
- **Atmosphère** :
  - Bandes nuageuses (zones claires, ceintures sombres)
  - **Grande Tache Rouge** : anticyclone géant, 3× Terre, >350 ans
  - Vents 600 km/h
- **Champ magnétique** : le plus intense (20 000× Terre)
- **79+ lunes** :
  - **Galiléennes** (découvertes Galilée 1610) :
    - **Io** : volcanisme extrême (forces marée), 400+ volcans actifs
    - **Europe** : croûte glace, océan souterrain 100 km profondeur (cible astrobiologie)
    - **Ganymède** : plus grande lune système solaire (>Mercure), champ magnétique propre
    - **Callisto** : cratérisée, ancienne
- **Anneaux** : ténus (poussière)
- **Missions** : Pioneer, Voyager, Galileo, Juno (en orbite)
- **Rôle** : "aspirateur cosmique" (protège Terre impacts comètes/astéroïdes)

**Saturne**
- **Distance** : 9,5 UA
- **Rayon** : 9,4 R⊕
- **Masse** : 95 M⊕
- **Densité** : 0,687 g/cm³ (flotterait sur eau!)
- **Composition** : similaire Jupiter (H, He)
- **Rotation** : 10,7 h
- **Anneaux** : **spectaculaires**, système le plus étendu
  - Largeur : 282 000 km
  - Épaisseur : 10-100 m!
  - Composition : glace eau (90%) + roche
  - Divisions : Cassini (4 800 km), Encke
  - Âge débattu : récents (100 M ans) ou anciens?
- **83+ lunes** :
  - **Titan** : 2e plus grande lune, atmosphère dense (1,5 bar, N₂ + CH₄)
    - Lacs et mers méthane/éthane liquides
    - Cycle hydrologique méthane (pluie, rivières, évaporation)
    - Atterrissage Huygens (2005)
  - **Encelade** : geysers glace eau (pôle sud), océan souterrain, molécules organiques
  - Mimas, Téthys, Dioné, Rhéa, Japet (deux faces contrastées)
- **Missions** : Pioneer, Voyager, Cassini-Huygens (2004-2017, extraordinaire succès)

**Uranus**
- **Distance** : 19,2 UA
- **Rayon** : 4 R⊕
- **Masse** : 14,5 M⊕
- **Géante de glace** : H₂O, CH₄, NH₃ (pas que H/He)
- **Couleur** : bleu-vert (méthane absorbe rouge)
- **Particularité unique** : **axe rotation incliné 98°** (roule sur orbite!)
  - Cause probable : impact géant
  - Saisons extrêmes : pôle 42 ans lumière, 42 ans obscurité
- **Rotation** : 17,2 h, rétrograde (à cause inclinaison)
- **Anneaux** : 13, sombres (découverts 1977)
- **27 lunes** : Miranda (falaises 20 km!), Ariel, Umbriel, Titania, Oberon
- **Champ magnétique** : incliné 59° axe rotation, décentré
- **Mission** : Voyager 2 (1986, seule visite)

**Neptune**
- **Distance** : 30,1 UA
- **Rayon** : 3,9 R⊕
- **Masse** : 17,1 M⊕
- **Géante de glace**, composition similaire Uranus
- **Couleur** : bleu profond (méthane)
- **Vents** : les plus rapides système solaire (2 100 km/h!)
- **Grande Tache Sombre** : anticyclone (disparu, réapparu ailleurs)
- **Chaleur interne** : rayonne 2,6× énergie reçue Soleil
- **Anneaux** : 5, ténus
- **14 lunes** :
  - **Triton** : grande lune, orbite rétrograde (capturé ceinture Kuiper?)
    - Geysers azote liquide
    - Surface jeune, active
    - Spirale vers Neptune (forces marée) → désintégration dans 3,6 Ga
- **Mission** : Voyager 2 (1989)

### Régions Externes

**Ceinture de Kuiper (30-50 UA)**
- Milliers objets glacés (H₂O, CH₄, NH₃)
- **Planètes naines** :
  - **Pluton** (2 377 km) : rétrogradé 2006, 5 lunes (Charon, Styx, Nix, Kerberos, Hydra)
    - New Horizons (2015) : montagnes glace, plaines azote, atmosphère ténue
  - **Makemake, Haumea, Eris** (plus massive que Pluton, causa reclassification)
- Objets classiques, résonants (Plutinos 2:3 avec Neptune)

**Nuage d'Oort (2 000-100 000 UA)**
- Sphère hypothétique comètes (milliards)
- Réservoir comètes longue période
- Limite gravitationnelle Soleil
- Jamais observé directement

**Comètes**
- "Boules neige sale" : glace + poussière + roche
- Origine : Kuiper (courte période) ou Oort (longue période)
- Approche Soleil → sublimation → coma + queue (ions, poussière)
- Célèbres : Halley (76 ans), Hale-Bopp, NEOWISE
- Missions : Rosetta/Philae (Tchourioumov-Guérassimenko, 2014)
