# Étoiles et Évolution Stellaire

### Classification Stellaire

**Diagramme Hertzsprung-Russell (HR)**
- Axes : Luminosité vs Température (ou Type spectral vs Magnitude absolue)
- 90% étoiles : **Séquence principale** (fusion H → He)
- **Géantes/Supergéantes** : étoiles évoluées, en haut à droite
- **Naines blanches** : résiduels, en bas à gauche

**Classification Spectrale (Harvard)**
- Ordre température décroissante : **O B A F G K M** (+ L, T, Y pour naines brunes)
- Mnémotechnique : "Oh Be A Fine Girl/Guy, Kiss Me"
- Sous-divisions : 0-9 (ex: G2 = Soleil)
- **Classe de luminosité** (Yerkes, MKK) : I (supergéantes), II, III (géantes), IV (sous-géantes), V (séquence principale), VI, VII (naines blanches)
  - Soleil : G2V

**Types**
- **O** : >30 000 K, bleues, massives (>16 M☉), rares, vie courte (<10 Ma)
  - Exemples : ζ Puppis, θ¹ Orionis
- **B** : 10 000-30 000 K, bleues-blanches
  - Rigel (β Ori), Spica (α Vir)
- **A** : 7 500-10 000 K, blanches
  - Sirius (α CMa, étoile la plus brillante ciel), Véga (α Lyr)
- **F** : 6 000-7 500 K, blanc-jaune
  - Procyon (α CMi)
- **G** : 5 200-6 000 K, jaunes
  - **Soleil**, α Centauri A
- **K** : 3 700-5 200 K, orange
  - Arcturus (α Boo), Aldébaran (α Tau)
- **M** : 2 400-3 700 K, rouges, les plus nombreuses (75%)
  - Bételgeuse (α Ori, supergéante), Proxima Centauri (naine, étoile la plus proche : 4,24 al)

### Formation Stellaire

**Nébuleuse Moléculaire**
- Nuages gaz froid (10-50 K), dense (H₂, He, CO, poussières)
- Masse : 10³-10⁶ M☉
- Exemples : Orion, Aigle (Piliers Création, Hubble)

**Effondrement Gravitationnel**
- Perturbation (onde choc supernova, collision nuages)
- **Critère Jeans** : masse minimale effondrement (densité, température)
- Fragmentation → multiples protostars
- **Disque d'accrétion** : rotation conservée

**Protoétoile**
- Contraction, T° ↑
- Phase T Tauri : jets bipolaires, vents stellaires violents
- Si M > 0,08 M☉ → fusion H (étoile)
- Si M < 0,08 M☉ → naine brune (pas fusion H, seulement D temporaire)

**Séquence Principale**
- Équilibre hydrostatique : pression radiation (fusion) = gravité
- 90% vie étoile
- **Durée** : ∝ M/L, mais L ∝ M³·⁵, donc durée ∝ 1/M²·⁵
  - Soleil (1 M☉) : ~10 Ga
  - 10 M☉ : ~20 Ma
  - 0,5 M☉ : ~50 Ga (> âge Univers!)

### Évolution Post-Séquence Principale

**Étoiles de Faible/Moyenne Masse (0,5-8 M☉)**

1. **Épuisement H cœur** → cesse fusion cœur
2. **Contraction cœur** → T° ↑ → fusion H en couche (shell)
3. **Expansion enveloppe** → **Géante rouge** (rayon ×10-100)
   - Exemple : Arcturus, Aldébaran
4. **Fusion He cœur** (flash He si <2 M☉) → He → C, O
5. **Fusion He couche** + **fusion H couche** (double shell burning)
6. **Branche asymptotique géantes (AGB)** : instable, pulsations
7. **Perte masse** : vents stellaires → enveloppe éjectée
8. **Nébuleuse planétaire** : enveloppe éjectée illuminée par cœur exposé
   - Exemples : Hélix, Anneau (M57), Dumbell, Nébuleuse Oeil de Chat
   - Durée : ~10 000 ans
9. **Naine blanche** : cœur résiduel, C-O (ou O-Ne-Mg si >8 M☉)
   - Taille Terre, masse ~0,6 M☉
   - Pas de fusion, rayonne chaleur résiduelle
   - Refroidissement lent (Ga)
   - **Limite Chandrasekhar** : 1,4 M☉ (au-delà → effondrement)

**Étoiles Massives (>8 M☉)**

1. **Fusions successives** : H → He → C → Ne → O → Si → Fe (oignon)
   - Chaque étape plus courte : Fe en quelques jours!
2. **Cœur Fe** : fusion Fe endothermique (absorbe énergie) → pas de support
3. **Effondrement cœur** : <1 seconde, densité nucléaire
4. **Supernova Type II** (effondrement cœur) :
   - Rebond choc → explosion externe
   - Luminosité : 10¹⁰ L☉, visible autres galaxies
   - Durée : semaines-mois
   - **Nucléosynthèse** : éléments > Fe (or, uranium, etc.)
   - Dispersion matière enrichie → futures générations étoiles
   - "Nous sommes poussière d'étoiles" (Sagan)
5. **Résidu** :
   - **Étoile à neutrons** si 1,4-3 M☉ (cœur)
   - **Trou noir** si >3 M☉ (cœur)

**Supernovae Type Ia**
- Naine blanche en système binaire
- Accrétion matière compagnon → dépasse limite Chandrasekhar (1,4 M☉)
- Fusion explosive C-O → désintégration totale
- **Luminosité standardisable** → chandelles standard cosmologie
