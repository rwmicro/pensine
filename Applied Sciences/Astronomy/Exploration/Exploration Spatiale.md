# Exploration Spatiale

### Missions Emblématiques

**Lune**
- **Apollo 11** (1969) : Armstrong, Aldrin, premiers humains Lune
- Apollo 12-17 (sauf 13) : 12 humains total
- **Artemis** : retour Lune prévu (2025+)

**Mars**
- **Viking 1 & 2** (1976) : atterrissage, recherche vie
- **Pathfinder** (1997) : rover Sojourner
- **Spirit & Opportunity** (2004) : rovers, Opportunity 15 ans!
- **Curiosity** (2012) : laboratoire roulant, Mont Sharp
- **Perseverance** (2021) : recherche biosignatures, Jezero (ancien lac), hélicoptère Ingenuity
- **Future** : retour échantillons, mission habitée (2030s-2040s)

**Voyager**
- **Voyager 1 & 2** (1977) : Grand Tour planètes externes
- Survol Jupiter, Saturne (+ Uranus, Neptune pour V2)
- **Voyager 1** : objet humain le plus lointain (~24 milliards km, 2024)
- Espace interstellaire (au-delà héliopause)
- Disques d'or (message humanité)

**Cassini-Huygens**
- Saturne (2004-2017)
- Découvertes : geysers Encelade, lacs Titan
- Plongée finale dans Saturne (protection lunes)

**New Horizons**
- Survol Pluton (2015) : révélations (cœur glace, montagnes, atmosphère)
- Arrokoth (Kuiper, 2019) : objet contact binaire

**Autres**
- **Rosetta** : atterrissage comète (Philae, 2014)
- **Juno** : Jupiter (2016-), structure interne
- **Parker Solar Probe** : frôle Soleil, couronne
- **BepiColombo** : Mercure (en route)

### Stations Spatiales

- **ISS** (International Space Station) : 1998-présent, 16 pays, laboratoire orbital, occupation continue
- **Tiangong** (Chine) : station modulaire, 2021-
- **Future** : Lunar Gateway (orbite lunaire), stations commerciales

### Future

- **Lune** : bases permanentes (Artemis, Chine-Russie)
- **Mars** : mission habitée (NASA, SpaceX, objectif 2030s-2040s)
- **Astéroïdes** : exploitation minière ?
- **Europe, Encelade** : missions vie (Europa Clipper, lancement 2024)
- **Télescopes géants** : ELT, TMT, GMT, Nancy Grace Roman (spatial)
