# Cycles Biogéochimiques


### Cycle de l'Eau (Hydrologique)

**Processus**
- **Évaporation** : océans, lacs, sols → vapeur
- **Transpiration** : plantes → vapeur (évapotranspiration)
- **Condensation** : vapeur → nuages
- **Précipitation** : pluie, neige
- **Ruissellement** : surface → rivières → océans
- **Infiltration** : eau → nappes phréatiques

**Réservoirs**
- Océans : 97%
- Glaces : 2%
- Eau douce liquide : 1% (dont majorité souterraine)

**Perturbations Humaines**
- Déforestation : ↓ évapotranspiration, ↑ ruissellement
- Barrages : modification flux naturels
- Surexploitation nappes : épuisement aquifères
- Imperméabilisation sols (villes) : ↓ infiltration

### Cycle du Carbone

**Processus**
- **Photosynthèse** : CO₂ atmosphère → matière organique (plantes)
- **Respiration** : matière organique → CO₂ (tous organismes)
- **Décomposition** : matière organique morte → CO₂ (bactéries, champignons)
- **Combustion** : matière organique → CO₂
- **Dissolution** : CO₂ atmosphère ↔ océans (équilibre chimique)
- **Sédimentation** : carbonates, fossiles → roches (long terme)

**Réservoirs**
- Atmosphère : 800 GtC (gigatonnes carbone)
- Océans : 38 000 GtC (surface + profondeur)
- Sols et végétation terrestre : 2 500 GtC
- Combustibles fossiles : 4 000+ GtC
- Roches sédimentaires : >60 000 000 GtC (long terme)

**Perturbations Anthropiques**
- **Combustion fossiles** : +9-10 GtC/an dans atmosphère
- **Déforestation** : libération carbone sols/végétation
- **Agriculture** : ↓ carbone sols
- **Résultat** : 280 ppm CO₂ (ère préindustrielle) → 420 ppm (2023)
  - Océans absorbent ~25% → acidification
  - Végétation absorbe ~25%
  - 50% reste atmosphère

### Cycle de l'Azote

**Processus**
- **Fixation** : N₂ atmosphère → NH₃/NH₄⁺
  - Bactéries (Rhizobium, cyanobactéries)
  - Foudre, industrie (Haber-Bosch)
- **Nitrification** : NH₄⁺ → NO₂⁻ → NO₃⁻ (bactéries)
- **Assimilation** : NO₃⁻ → protéines (plantes, algues)
- **Ammonification** : matière organique → NH₄⁺ (décomposition)
- **Dénitrification** : NO₃⁻ → N₂ (retour atmosphère, bactéries anaérobies)

**Perturbations Humaines**
- **Engrais synthétiques** (Haber-Bosch) : doublement fixation azote
- **Conséquences** :
  - Eutrophisation : algues → zones mortes (Golfe du Mexique, Baltique)
  - Émission N₂O (gaz à effet de serre, 300× CO₂)
  - Acidification sols
  - Pollution nappes (nitrates)

### Cycle du Phosphore

**Caractéristiques**
- Pas de phase gazeuse (atmosphère)
- Cycle très lent : roches → sols → organismes → sédiments → roches
- **Érosion** roches → phosphates solubles → plantes → animaux → décomposition
- **Sédimentation** océans → roches sédimentaires (millions d'années)

**Limitation**
- Souvent facteur limitant (lacs, océans)
- Extraction minière : engrais (réserves limitées, peak phosphorus)

**Perturbations**
- Engrais : eutrophisation lacs
- Érosion sols agricoles : pertes

### Cycle du Soufre

**Processus**
- Volcans, sources hydrothermales → SO₂ atmosphère
- Décomposition matière organique → H₂S
- Oxydation → SO₄²⁻ (sulfates, pluies)
- Assimilation plantes, algues
- Sédimentation (pyrite FeS₂)

**Perturbations**
- Combustion fossiles (charbon) → SO₂ → pluies acides
  - Acidification lacs scandinaves (1970-80)
  - Règlementation : amélioration
