# Niveaux d'Organisation


### Écologie des Populations

**Caractéristiques des Populations**
- **Effectif (N)** : nombre d'individus
- **Densité** : individus par surface/volume
- **Distribution** : uniforme, aléatoire, agrégée
- **Structure** : âge, sexe, taille
- **Croissance** : taux natalité, mortalité, immigration, émigration

**Dynamique des Populations**
- **Croissance exponentielle** : ressources illimitées
  - dN/dt = rN (r = taux croissance intrinsèque)
  - Courbe en J
- **Croissance logistique** : ressources limitées
  - dN/dt = rN(1 - N/K) (K = capacité de charge)
  - Courbe en S (sigmoïde)
- **Stratégies** :
  - **r-stratèges** : reproduction rapide, nombreuse, mortalité élevée (insectes, souris)
  - **K-stratèges** : reproduction lente, peu descendants, soins parentaux (éléphants, humains)

**Régulation des Populations**
- **Densité-dépendante** : compétition, prédation, maladies
- **Densité-indépendante** : climat, catastrophes
- **Cycles** : prédateur-proie (Lotka-Volterra)

### Écologie des Communautés

**Structure des Communautés**
- **Richesse spécifique** : nombre d'espèces
- **Équitabilité** : distribution abondances
- **Diversité** : richesse + équitabilité (indices Shannon, Simpson)
- **Dominance** : espèces abondantes vs rares

**Succession Écologique**
- **Primaire** : colonisation substrat vierge (lave, glacier retiré)
  - Lichens → mousses → herbes → arbustes → forêt
- **Secondaire** : recolonisation après perturbation (feu, coupe)
  - Plus rapide, sol présent
- **Climax** : communauté mature, stable (théorie discutée)

**Perturbations**
- **Hypothèse perturbation intermédiaire** : diversité maximale à niveaux modérés
  - Trop peu : dominance compétiteurs
  - Trop : seuls colonisateurs rapides
- Feux, tempêtes, herbivores maintiennent mosaïques

**Biogéographie Insulaire (MacArthur & Wilson)**
- Équilibre immigration ↔ extinction
- Grande île, proche continent : plus d'espèces
- Applications : conception réserves naturelles

### Écologie des Écosystèmes

**Définition**
- Communauté biotique + environnement abiotique
- Flux énergie + cycles matière
- Échelles variables : mare, forêt, océan, biosphère

**Productivité**
- **Productivité primaire brute (PPB)** : photosynthèse totale
- **Productivité primaire nette (PPN)** : PPB - respiration plantes
  - Biomasse disponible herbivores
- **Productivité secondaire** : biomasse consommateurs
- **Facteurs** : lumière, eau, nutriments, température
- **Zones très productives** : forêts tropicales, estuaires, récifs coralliens
- **Zones peu productives** : déserts, océans profonds
