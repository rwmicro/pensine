# Physiologie


### Définition

La physiologie étudie le fonctionnement normal des organes et systèmes du corps humain.

### Homéostasie

**Concept**
Maintien d'un environnement intérieur stable malgré variations externes.

**Mécanismes de Régulation**
- **Rétroaction Négative** : Le plus courant (thermostat)
  - Exemple : Régulation glucose sanguin (insuline/glucagon)
- **Rétroaction Positive** : Amplification (rare)
  - Exemple : Accouchement (ocytocine)

> [!important] Idée clé
> La rétroaction positive est rare précisément parce qu'elle est instable par construction : elle amplifie l'écart au lieu de le corriger, donc elle ne peut pas servir à *maintenir* un état stable — seulement à déclencher un événement qui doit se terminer vite (accouchement, cascade de coagulation, potentiel d'action). L'homéostasie, par définition, repose presque toujours sur la rétroaction négative.

**Variables Régulées**
- Température corporelle : 37°C (98.6°F)
- pH sanguin : 7.35-7.45
- Glycémie : 0.7-1.1 g/L à jeun
- Pression artérielle : ~120/80 mmHg
- Osmolarité : Balance eau/électrolytes

### Physiologie Cardiaque

**Cycle Cardiaque**
1. **Diastole** : Remplissage ventricules (relâchement)
2. **Systole** : Contraction ventricules (éjection sang)

**Conduction Électrique**
- **Nœud Sinusal** (SA) : Pacemaker naturel (60-100/min)
- **Nœud Auriculo-Ventriculaire** (AV) : Délai
- **Faisceau de His** → Fibres de Purkinje : Conduction ventricules
- **ECG** (Électrocardiogramme) : Enregistrement activité électrique

**Régulation**
- **Système Nerveux** : Sympathique (↑ FC), Parasympathique (↓ FC)
- **Hormones** : Adrénaline augmente fréquence/force

### Physiologie Respiratoire

**Mécanique Respiratoire**
- **Inspiration** : Diaphragme descend, pression ↓, air entre
- **Expiration** : Passive au repos, active si effort

**Échanges Gazeux**
- **Alvéoles** : O₂ diffuse vers sang, CO₂ vers alvéoles
- **Transport O₂** : Hémoglobine (97%), dissous (3%)
- **Transport CO₂** : Bicarbonate (70%), hémoglobine (23%), dissous (7%)

**Régulation**
- **Centres Respiratoires** : Bulbe rachidien, pont
- **Chimiorécepteurs** : Détectent CO₂, O₂, pH
- **Fréquence** : 12-20 respirations/min adulte repos

### Physiologie Digestive

**Digestion Mécanique et Chimique**
- **Bouche** : Mastication, amylase salivaire (amidon)
- **Estomac** : Brassage, HCl (pH 1.5-3.5), pepsine (protéines)
- **Intestin Grêle** : 
  - Duodénum : Bile (lipides), enzymes pancréatiques
  - Jéjunum/Iléum : Absorption nutriments (villosités)
- **Côlon** : Absorption eau, formation selles, flore intestinale

**Absorption**
- **Glucides** : Glucose, fructose, galactose
- **Protéines** : Acides aminés (voir [[Biology/Les acides aminés]])
- **Lipides** : Acides gras, monoglycérides (micelles)
- **Vitamines, Minéraux** : Divers mécanismes

### Physiologie Rénale

**Fonctions des Reins**
1. **Filtration** : Glomérule (pression hydrostatique)
2. **Réabsorption** : Tubule proximal (glucose, aa, eau, Na⁺)
3. **Sécrétion** : Tubule distal (H⁺, K⁺, médicaments)
4. **Concentration** : Anse de Henle (gradient osmotique)

**Régulation**
- **ADH** (Hormone Antidiurétique) : Rétention eau
- **Aldostérone** : Rétention Na⁺, excrétion K⁺
- **Système Rénine-Angiotensine** : Pression artérielle

### Physiologie Nerveuse

**Potentiel de Repos**
- **-70 mV** : Intérieur négatif / extérieur
- Pompe Na⁺/K⁺ : 3 Na⁺ out, 2 K⁺ in (ATP)

**Potentiel d'Action**
1. **Dépolarisation** : Na⁺ entre, +30 mV
2. **Repolarisation** : K⁺ sort, retour -70 mV
3. **Hyperpolarisation** : Brève, -90 mV
4. **Période Réfractaire** : Impossible nouveau PA

> [!warning] Piège
> Le potentiel d'action obéit à la loi du « tout ou rien » : en dessous du seuil de déclenchement, rien ne se passe ; au-dessus, l'amplitude est toujours la même, quelle que soit l'intensité du stimulus. L'information sur l'intensité n'est donc pas codée dans la taille du signal mais dans sa **fréquence** (plus le stimulus est fort, plus les PA se succèdent vite) — piège classique de confondre amplitude variable et fréquence variable.

**Synapse**
- **Électrique** : Jonctions gap (rare)
- **Chimique** : Neurotransmetteurs
  - Excitateurs : Glutamate, Acétylcholine
  - Inhibiteurs : GABA, Glycine
  - Modulateurs : Dopamine, Sérotonine, Noradrénaline

### Physiologie Endocrinienne

**Mécanismes d'Action Hormonale**
- **Hormones Hydrosolubles** : Récepteurs membrane (AMPc, IP3)
- **Hormones Liposolubles** : Récepteurs nucléaires (transcription)

**Axes Hormonaux**
- **Hypothalamo-Hypophysaire** : Contrôle central
- **Thyroïdien** : TRH → TSH → T3/T4
- **Surrénalien** : CRH → ACTH → Cortisol
- **Gonadique** : GnRH → LH/FSH → Hormones sexuelles

> [!tip] Méthode
> Les quatre axes suivent tous le même patron hiérarchique (hypothalamus → hypophyse → glande périphérique), avec un même mécanisme de rétrocontrôle négatif : l'hormone finale (cortisol, T3/T4, hormones sexuelles) inhibe en retour l'hypothalamus et l'hypophyse. Une fois ce schéma compris pour un axe, les trois autres se déduisent par analogie plutôt que par mémorisation séparée.
