# Anatomie


### Introduction

**Définition**
L'anatomie est l'étude de la structure du corps humain et de ses parties. Elle forme la base de la compréhension médicale.

**Niveaux d'Organisation**
1. **Chimique** : Atomes, molécules
2. **Cellulaire** : Cellules, organites
3. **Tissulaire** : Tissus (épithélial, conjonctif, musculaire, nerveux)
4. **Organes** : Structures avec fonctions spécifiques
5. **Systèmes** : Groupes d'organes travaillant ensemble
6. **Organisme** : Être humain complet

### Systèmes du Corps Humain

**Système Squelettique**
- **206 os** chez l'adulte
- **Fonctions** : Support, protection, production cellules sanguines (moelle), stockage minéraux
- **Types d'os** : Longs (fémur), courts (carpe), plats (crâne), irréguliers (vertèbres)
- **Articulations** : 
  - Synoviales (mobile) : Genou, épaule
  - Cartilagineuses (semi-mobile) : Vertèbres
  - Fibreuses (immobile) : Crâne

**Système Musculaire**
- **~640 muscles squelettiques**
- **Types** :
  - Squelettique : Volontaire, strié (biceps, quadriceps)
  - Lisse : Involontaire (intestins, vaisseaux)
  - Cardiaque : Involontaire, strié (cœur)
- **Contraction** : Filaments actine-myosine, ATP
- **Principaux Muscles** : 
  - Biceps/triceps (bras)
  - Quadriceps/ischio-jambiers (jambes)
  - Deltoïdes (épaules)
  - Abdominaux, dorsaux

**Système Cardiovasculaire**
- **Cœur** : Pompe musculaire, 4 cavités (2 oreillettes, 2 ventricules)
  - Débit cardiaque : ~5 L/min au repos
  - Fréquence : 60-100 bpm adulte repos
- **Vaisseaux** :
  - Artères : Sang oxygéné du cœur (sauf pulmonaire)
  - Veines : Sang désoxygéné vers cœur (sauf pulmonaire)
  - Capillaires : Échanges tissulaires
- **Sang** : ~5-6 litres chez adulte
  - Globules rouges (érythrocytes) : Transport O₂
  - Globules blancs (leucocytes) : Défense immunitaire
  - Plaquettes : Coagulation ([[Biology/Human/Hémophilie]])
  - Plasma : Liquide, protéines, nutriments

**Système Respiratoire**
- **Voies Aériennes** : Nez, pharynx, larynx, trachée, bronches
- **Poumons** : 2 organes (gauche: 2 lobes, droite: 3 lobes)
- **Alvéoles** : ~300 millions, échanges gazeux O₂/CO₂
- **Diaphragme** : Principal muscle respiratoire
- **Capacité** : ~6 litres (capacité pulmonaire totale)

**Système Digestif**
- **Tube Digestif** (~9 mètres) :
  - Bouche → Œsophage → Estomac → Intestin grêle (6m) → Côlon → Rectum
- **Glandes Annexes** :
  - Glandes salivaires
  - Foie : Bile, métabolisme
  - Pancréas : Enzymes, insuline
- **Fonctions** : Digestion, absorption nutriments, élimination déchets

**Système Nerveux**
- **Système Nerveux Central (SNC)** :
  - **Cerveau** : ~86 milliards de neurones
    - Cortex cérébral : Pensée, conscience
    - Cervelet : Coordination motrice
    - Tronc cérébral : Fonctions vitales
  - **Moelle Épinière** : Transmission signaux
- **Système Nerveux Périphérique (SNP)** :
  - Somatique : Contrôle volontaire
  - Autonome : Sympathique (stress), Parasympathique (repos)
- **Neurones** : Transmission électrique/chimique (voir [[Biology/Biologie#Neurobiologie]])

**Système Endocrinien**
- **Glandes** :
  - Hypophyse : "Glande maîtresse" (hormones régulation)
  - Thyroïde : Métabolisme (T3, T4)
  - Parathyroïdes : Calcium
  - Surrénales : Cortisol, adrénaline
  - Pancréas : Insuline, glucagon
  - Gonades : Hormones sexuelles (testostérone, œstrogène)
- **Communication** : Hormones dans sang

**Système Urinaire**
- **Reins** : 2 organes, filtration sang (~180 L/jour)
- **Néphrons** : ~1 million par rein, unités fonctionnelles
- **Uretères** : Transport urine vers vessie
- **Vessie** : Stockage (~400-600 mL)
- **Urètre** : Évacuation
- **Fonctions** : Élimination déchets, équilibre hydrique/électrolytique

**Système Reproducteur**
- **Masculin** :
  - Testicules : Production spermatozoïdes, testostérone
  - Prostate, vésicules séminales
- **Féminin** :
  - Ovaires : Ovules, œstrogène, progestérone
  - Utérus : Gestation
  - Cycle menstruel : ~28 jours

**Système Lymphatique**
- **Vaisseaux Lymphatiques** : Retour liquide interstitiel
- **Ganglions** : Filtration, défense immunitaire
- **Rate** : Filtration sang, stockage cellules immunitaires
- **Thymus** : Maturation lymphocytes T

**Système Tégumentaire**
- **Peau** : Plus grand organe (~2 m²)
  - Épiderme : Couche externe, kératine
  - Derme : Vaisseaux, nerfs, glandes
  - Hypoderme : Graisse
- **Annexes** : Cheveux, ongles, glandes sudoripares/sébacées
- **Fonctions** : Protection, thermorégulation, sensation
