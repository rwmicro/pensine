# Génétique Médicale


### Maladies Génétiques

**Transmission Autosomique Récessive**
- **Mucoviscidose** : CFTR (chlore), sécrétions épaisses
- **Drépanocytose** : Hémoglobine S, anémie (voir [[Biology/Biologie#Génétique]])
- **Phénylcétonurie** : Phénylalanine hydroxylase, retard mental si non traité

**Transmission Autosomique Dominante**
- **Maladie de Huntington** : Dégénérescence neuronale, âge adulte
- **Achondroplasie** : Nanisme
- **Syndrome de Marfan** : Tissu conjonctif (aorte, yeux, squelette)

**Transmission Liée à l'X**
- **Hémophilie A/B** : Coagulation (voir [[Biology/Human/Hémophilie]])
- **Daltonisme** : Vision couleurs
- **Dystrophie Musculaire Duchenne** : Dystrophine, faiblesse musculaire progressive

**Maladies Chromosomiques**
- **Trisomie 21** (Syndrome de Down) : 3 chromosomes 21
  - Retard mental, traits faciaux, cardiopathie
- **Syndrome de Turner** (45,X) : Femmes, petite taille, infertilité
- **Syndrome de Klinefelter** (47,XXY) : Hommes, hypogonadisme

**Maladies Mitochondriales**
- Transmission maternelle (mitochondries ovule)
- Neuropathies, myopathies

### Diagnostic Génétique

**Techniques**
- **Caryotype** : Visualisation chromosomes
- **PCR** : Amplification ADN spécifique
- **Séquençage** : NGS (Next-Generation Sequencing), whole exome/genome
- **FISH** : Hybridation in situ fluorescente
- **Micropuces ADN** : Détection variations

**Dépistage Prénatal**
- **Échographie** : Anomalies morphologiques
- **Marqueurs Sériques Maternels** : Trisomie 21
- **Amniocentèse** : Analyse liquide amniotique (15-20 semaines)
- **Biopsie Villosités Choriales** : 10-13 semaines
- **ADN Fœtal Libre Circulant** : Test sanguin maternel, non-invasif

**Conseil Génétique**
- Évaluation risques
- Information patients/familles
- Décisions éclairées (reproduction, traitement)

### Thérapie Génique

**Approches**
- **Ex Vivo** : Modification cellules hors corps, réintroduction
- **In Vivo** : Administration directe vecteur
- **Vecteurs** : Virus (AAV, lentivirus), non-viraux

**Applications**
- **Immunodéficiences** : DICS, ADA-SCID
- **Hémophilie** : Production facteurs coagulation
- **Maladies Rétiniennes** : Luxturna (cécité héréditaire)
- **Cancer** : CAR-T cells (lymphome)

**CRISPR-Cas9**
- Édition génome précise (voir [[Biology/Biologie#Génétique]])
- Potentiel thérapeutique énorme
- Questions éthiques (modification germinale)
