# Immunologie


### Introduction

**Définition**
Étude du système immunitaire et de ses mécanismes de défense contre pathogènes, cellules anormales.

### Immunité Innée

**Première Ligne de Défense**
- **Barrières Physiques** : Peau, muqueuses
- **Barrières Chimiques** : pH acide (estomac), lysozyme (larmes)
- **Flore Commensale** : Compétition avec pathogènes

**Cellules Innées**
- **Phagocytes** :
  - Macrophages : Tissus, présentation antigène
  - Neutrophiles : 50-70% leucocytes, première réponse
  - Cellules Dendritiques : Pont innée-adaptative
- **Cellules NK** (Natural Killer) : Détruisent cellules infectées/cancéreuses
- **Mastocytes, Basophiles, Éosinophiles** : Allergies, parasites

**Molécules Solubles**
- **Complément** : ~30 protéines, cascade activation
  - Lyse cellules, opsonisation, chimiotactisme
- **Cytokines** : Interleukines (IL), interférons (IFN), TNF
- **Protéines Phase Aiguë** : CRP (C-Reactive Protein)

**Reconnaissance**
- **PAMPs** (Pathogen-Associated Molecular Patterns)
- **PRRs** (Pattern Recognition Receptors) : TLRs (Toll-Like)

### Immunité Adaptative

**Caractéristiques**
- **Spécificité** : Reconnaissance précise antigènes
- **Mémoire** : Réponse plus rapide/forte lors réexposition
- **Diversité** : Millions d'antigènes reconnaissables
- **Auto/Non-auto** : Tolérance au soi

**Lymphocytes**

*Lymphocytes B*
- **Production** : Moelle osseuse
- **Maturation** : Moelle osseuse
- **Fonction** : Production anticorps (immunoglobulines)
- **Plasmocytes** : Cellules B activées sécrétant anticorps
- **Cellules B Mémoire** : Réponse secondaire rapide

*Lymphocytes T*
- **Production** : Moelle osseuse
- **Maturation** : Thymus
- **Types** :
  - **CD4+ (T helper)** : Coordination réponse immunitaire
    - Th1 : Réponse cellulaire (bactéries intracellulaires)
    - Th2 : Réponse humorale (parasites, allergies)
    - Th17 : Inflammation, auto-immunité
    - T reg : Régulation, tolérance
  - **CD8+ (T cytotoxique)** : Destruction cellules infectées/cancéreuses
- **Reconnaissance** : Récepteur TCR + CMH (Complexe Majeur Histocompatibilité)

**Anticorps (Immunoglobulines)**
- **Structure** : 2 chaînes lourdes + 2 chaînes légères (forme Y)
- **Classes** :
  - **IgG** : 75%, circulation, traverse placenta
  - **IgM** : Réponse primaire, pentamère
  - **IgA** : Muqueuses, sécrétions (salive, lait)
  - **IgE** : Allergies, parasites
  - **IgD** : Membrane lymphocytes B
- **Fonctions** : Neutralisation, opsonisation, activation complément

**Présentation Antigène**
- **CMH I** : Toutes cellules nucléées → CD8+
- **CMH II** : Cellules présentatrices (macrophages, dendritiques, B) → CD4+

### Réponse Immunitaire

**Réponse Primaire**
1. **Reconnaissance** : Antigène par lymphocytes
2. **Activation** : Prolifération clonale (sélection clonale)
3. **Différenciation** : Effecteurs + mémoire
4. **Effecteur** : Élimination pathogène
5. **Contraction** : Apoptose majorité effecteurs
6. **Mémoire** : Cellules longue durée

**Réponse Secondaire**
- Plus rapide (heures vs jours)
- Plus intense
- Plus durable
- Base de la vaccination

### Vaccination

**Principe**
Exposition contrôlée à antigène pour générer mémoire immunitaire sans maladie.

**Types de Vaccins**
- **Vivants Atténués** : ROR (rougeole-oreillons-rubéole), BCG
  - Avantages : Réponse forte, longue durée
  - Inconvénients : Contre-indiqués immunodéprimés
- **Inactivés** : Polio injectable, grippe
- **Sous-unités** : Hépatite B (protéine surface)
- **Conjugués** : Haemophilus influenzae b
- **ARNm** : COVID-19 (Pfizer, Moderna)
  - Innovation majeure, production rapide

**Calendrier Vaccinal**
- Nourrissons : DTaP (diphtérie-tétanos-coqueluche), ROR, hépatite B
- Adultes : Rappels tétanos (10 ans), grippe annuelle (>65 ans)
- Voyages : Fièvre jaune, typhoïde selon destination

### Pathologies Immunitaires

**Immunodéficiences**
- **Primaires** : Génétiques (DICS, agammaglobulinémie)
- **Secondaires** : VIH/SIDA, malnutrition, chimiothérapie

**Auto-immunité**
- **Organe-Spécifiques** :
  - Diabète Type 1 : Îlots pancréatiques
  - Thyroïdite Hashimoto : Thyroïde
  - Sclérose en Plaques : Myéline SNC
- **Systémiques** :
  - Lupus Érythémateux Disséminé : Multiples organes
  - Polyarthrite Rhumatoïde : Articulations
- **Mécanismes** : Perte tolérance au soi

**Allergies (Hypersensibilités)**
- **Type I** (Immédiate) : IgE, mastocytes (pollen, arachide, venin)
  - Anaphylaxie : Urgence vitale (adrénaline)
- **Type II** (Cytotoxique) : Anticorps contre cellules (transfusion incompatible)
- **Type III** (Complexes Immuns) : Dépôts (lupus)
- **Type IV** (Retardée) : Lymphocytes T (test tuberculine)

**Rejet de Greffe**
- **Hyperaigu** : Minutes (anticorps préformés)
- **Aigu** : Semaines (lymphocytes T)
- **Chronique** : Mois/années
- **Prévention** : Immunosuppresseurs (cyclosporine, tacrolimus)
