# Urbanisme


### Histoire Urbanisme

**Villes Antiques**
- **Grèce** : Plan hippodamien (grille orthogonale)
- **Rome** : Cardo/Decumanus, forums, aqueducs
- **Chine** : Villes fortifiées, axe N-S (Beijing, Xi'an)

**Moyen Âge**
- Villes organiques, ruelles étroites
- Place centrale (cathédrale, hôtel ville, marché)
- Remparts, portes fortifiées

**Renaissance et Baroque**
- Places, perspectives monumentales
- Axes radiaux (Rome : Place Saint-Pierre)

**XIXe - Haussmann (Paris)**
- **Georges-Eugène Haussmann** (1853-1870)
- Percées larges boulevards
- Hygiène (égouts), circulation, contrôle social
- Espaces verts (Bois Boulogne, Buttes-Chaumont)
- Façades uniformes haussmanniennes

**Cités-Jardins** (Ebenezer Howard, UK)
- Combinaison ville-campagne
- Letchworth (1903), première cité-jardin

### Urbanisme XXe Siècle

**Charte d'Athènes** (Le Corbusier, CIAM, 1933)
- Séparation fonctions : Habiter, Travailler, Circuler, Se Recréer
- Grands ensembles, tours
- Critiques : Zoning rigide, mort rue

**Villes Nouvelles**
- **Brasília** (Brésil, 1960, Oscar Niemeyer & Lúcio Costa)
  - Plan avion, modernisme
  - UNESCO, mais critiquée (échelle automobile, ségrégation)
- **Chandigarh** (Inde, Le Corbusier)
- Villes nouvelles France (Marne-la-Vallée, Évry)

**Suburbanisation** (USA)
- Étalement urbain, dépendance automobile
- Lotissements, malls, autoroutes

**Problèmes**
- Congestion, pollution
- Perte espaces verts, terres agricoles
- Ségrégation socio-spatiale

### Urbanisme Contemporain

**Développement Durable**
- **Compact, Dense** : Mixité fonctions, transports publics
- **TOD** (Transit-Oriented Development) : Autour transports
- **15-Minute City** (Carlos Moreno, Paris)
  - Tous besoins quotidiens <15min marche/vélo
  - Proximité, qualité vie

**Ville Intelligente (Smart City)**
- **Technologies** : IoT, capteurs, données temps réel
- **Applications** : Trafic, énergie, déchets, sécurité
- **Exemples** : Singapour, Barcelone, Copenhague
- **Critiques** : Surveillance, fracture numérique, complexité

**Résilience Urbaine**
- **Adaptation Climat** : Îlots chaleur, inondations
- **Solutions** :
  - Végétalisation (toits, murs, rues)
  - Gestion eaux pluviales (bassins, surfaces perméables)
  - Mobilité douce (vélo, piéton)

**Exemples Villes Durables**
- **Copenhague** : 62% déplacements vélo, objectif neutre carbone 2025
- **Curitiba** (Brésil) : BRT (Bus Rapid Transit), parcs
- **Singapour** : Ville-jardin, gestion eau exemplaire
- **Masdar City** (Abu Dhabi) : Ville zéro carbone (construction)

### Espaces Publics

**Importance**
- Lien social, démocratie, identité
- Santé (exercice, bien-être mental)
- Économie (commerces, tourisme)

**Types**
- **Places** : Rencontre, événements (Place de la Concorde, Times Square)
- **Parcs** : Nature, loisirs (Central Park, Hyde Park)
- **Rues** : Vie quotidienne, commerce

**Aménagement**
- **Piétonisation** : Priorité piétons (Barcelona, Copenhague)
- **Mobilier Urbain** : Bancs, fontaines, éclairage
- **Art Public** : Sculptures, fresques
