**Fréquence** : Faites 3 séries de 8 à 12 répétitions pour chaque exercice, avec 30 à 60 secondes de repos entre les séries.

**A. Développé épaules (Overhead Press)**
- Muscles ciblés : épaules, triceps.
- Instructions :
    1. Tenez une haltère dans chaque main à hauteur des épaules.
    2. Poussez les haltères vers le haut jusqu’à ce que vos bras soient complètement tendus.
    3. Revenez lentement à la position de départ.
![Développé épaules](https://www.docteur-fitness.com/wp-content/uploads/2022/02/developpe-epaule-halteres.gif)


**B. Rowing haltères (Bent-Over Rows)**
- Muscles ciblés : dos, biceps.
- Instructions :
    1. Inclinez le buste en avant à 45°, en gardant le dos droit.
    2. Tirez les haltères vers votre taille en serrant les omoplates.
    3. Redescendez lentement les haltères.

![Rowing haltères](https://www.docteur-fitness.com/wp-content/uploads/2022/10/bent-over-row-avec-halteres.gif)


**C. Élévations latérales**
- Muscles ciblés : épaules.
- Instructions :
    1. Tenez une haltère dans chaque main, bras le long du corps.
    2. Soulevez les bras sur les côtés jusqu'à ce qu'ils soient parallèles au sol.
    3. Redescendez lentement.

![Élévations latérales](https://www.docteur-fitness.com/wp-content/uploads/2000/08/elevations-laterales-exercice-musculation.gif)

**D. Pompes avec haltères (Renegade Rows)**
- Muscles ciblés : poitrine, dos, triceps, abdominaux.
- Instructions :
    1. Placez-vous en position de planche avec une main sur chaque haltère.
    2. Effectuez une pompe.
    3. Une fois remonté, tirez une haltère vers votre taille. Alternez les côtés.
![Renegade Rows](https://www.docteur-fitness.com/wp-content/uploads/2020/10/pompe-avec-halteres.gif)
**E. Développé Légérement incliné**
- Muscles ciblés : pectoraux
- Instructions :
    1. Placez-vous sur le dos, les haltères aux niveaux de la poitrine
    2. Poussez les haltères vers le haut
![Développé couché incliné](https://www.docteur-fitness.com/wp-content/uploads/2000/05/developpe-couche-halteres-exercice-musculation.gif)
