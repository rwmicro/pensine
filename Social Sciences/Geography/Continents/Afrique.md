# Afrique (30,4 millions km²)

**Caractéristiques Générales**
- **Population** : ~1,4 milliard (2024)
- **Pays** : 54 États souverains
- **Plus Grand** : Algérie (2,38 millions km²)
- **Plus Peuplé** : Nigeria (~220 millions)

**Géographie Physique**
- **Déserts** : Sahara (plus grand désert chaud, 9M km²), Kalahari, Namib
- **Fleuves** : Nil (plus long au monde, 6 650 km), Congo, Niger, Zambèze
- **Montagnes** : Kilimandjaro (5 895m, Tanzanie), Mont Kenya, Drakensberg
- **Grands Lacs** : Victoria, Tanganyika, Malawi (Rift africain)
- **Climat** : Équatorial (Congo), tropical, sahélien, méditerranéen (Nord/Sud), désertique

**Régions**

*Afrique du Nord* (Maghreb + Égypte)
- **Pays** : Maroc, Algérie, Tunisie, Libye, Égypte
- **Culture** : Arabo-berbère, islam dominant
- **Économie** : Pétrole (Libye, Algérie), tourisme (Égypte, Maroc)

*Afrique de l'Ouest*
- **Pays** : Nigeria, Ghana, Sénégal, Côte d'Ivoire, Mali
- **Économie** : Cacao (Côte d'Ivoire), pétrole (Nigeria)
- **Sahel** : Bande de transition Sahara-savane (insécurité, changement climatique)

*Afrique de l'Est*
- **Pays** : Kenya, Tanzanie, Éthiopie, Ouganda, Rwanda
- **Géographie** : Rift africain, hauts plateaux éthiopiens
- **Faune** : Grands mammifères (lions, éléphants, rhinocéros)
- **Économie** : Café, thé, tourisme safari

*Afrique Centrale*
- **Pays** : RD Congo, Cameroun, Gabon, République Centrafricaine
- **Forêt** : Bassin du Congo (2e forêt tropicale mondiale)
- **Ressources** : Minerais (coltan, cobalt, diamants - RDC)

*Afrique Australe*
- **Pays** : Afrique du Sud, Botswana, Namibie, Zimbabwe, Mozambique
- **Économie** : Afrique du Sud (économie la plus développée du continent)
- **Histoire** : Apartheid (1948-1994), Nelson Mandela

**Enjeux**
- **Démographie** : Croissance rapide, urbanisation
- **Développement** : Pauvreté, inégalités
- **Conflits** : Sahel, Grands Lacs, Somalie
- **Environnement** : Désertification, déforestation
- **Opportunités** : Ressources naturelles, dividende démographique, technologie (M-Pesa Kenya)
