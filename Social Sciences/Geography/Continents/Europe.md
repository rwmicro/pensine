# Europe (10,2 millions km²)


**Caractéristiques**
- **Continent le plus petit après Océanie**
- **Population** : ~750 millions
- **Pays** : ~50 (selon définitions)

**Europe de l'Ouest**

*France*
- **Superficie** : 643 801 km² (métropole), 1er UE avec outre-mer
- **Population** : ~68 millions
- **Capitale** : Paris (2,1M, 11M aire urbaine)
- **Géographie** : Alpes, Pyrénées, Massif Central, Loire (plus long fleuve, 1 006 km)
- **Économie** : 7e mondiale, agriculture, luxe, tourisme (1re destination)
- **Histoire** : [[History/France/XVI - François 1er/Renaissance et François 1er]], [[History/France/XIX - Colonisation de l'Algérie]]

*Royaume-Uni*
- **Superficie** : 242 495 km²
- **Population** : ~68 millions
- **Capitale** : Londres (9M, 14M aire urbaine)
- **Composition** : Angleterre, Écosse, Pays de Galles, Irlande du Nord
- **Brexit** : Sortie UE (2020)
- **Histoire** : Empire britannique (plus vaste empire histoire)

*Allemagne*
- **Population** : ~84 millions (2e Europe)
- **Capitale** : Berlin (3,6M)
- **Économie** : 1re UE, 4e mondiale, industrie (automobiles)
- **Histoire** : [[History/WW2/Montée du nazisme]], Réunification (1990)

*Espagne, Portugal*
- **Espagne** : 47M, Madrid, Barcelone, tourisme
- **Portugal** : 10M, Lisbonne, Porto, explorateurs (XVe-XVIe)

*Benelux*
- **Belgique** : Bruxelles (capitale UE), Flandre/Wallonie
- **Pays-Bas** : Amsterdam, polders, Rotterdam (1er port européen)
- **Luxembourg** : Finance, petit (2 600 km²)

*Irlande*
- **Dublin** : Hub tech européen (Google, Facebook)
- **Histoire** : Indépendance UK (1922), réunification débat (Irlande Nord)

*Suisse*
- **Neutralité** : Non UE, Non OTAN
- **Finance** : Banques, Genève (ONU, organisations internationales)
- **Géographie** : Alpes, 4 langues (allemand, français, italien, romanche)

*Autriche*
- **Vienne** : Capitale musicale, empire austro-hongrois

**Europe du Nord (Scandinavie)**
- **Norvège** : Fjords, pétrole (fonds souverain)
- **Suède** : Stockholm, social-démocratie, IKEA, Spotify
- **Finlande** : Helsinki, Nokia, saunas, frontière Russie
- **Danemark** : Copenhague, Lego, vélo
- **Islande** : Volcans, geysers, 370 000 habitants

**Europe du Sud**
- **Italie** : 60M, Rome, Vatican, Renaissance, gastronomie
- **Grèce** : Athènes, berceau civilisation occidentale, crise dette
- **Balkans** : Croatie, Serbie, Bosnie, Albanie, Macédoine du Nord, etc.
  - Yougoslavie éclatée (guerres 1990s)

**Europe de l'Est**
- **Pologne** : 38M, Varsovie, [[History/WW2/Invasion of Poland]]
- **Ukraine** : 41M (avant guerre), Kiev, grenier à blé, guerre Russie (2022-)
- **Russie** (partie européenne) : Moscou, Saint-Pétersbourg
  - Plus grand pays monde (17M km² total), [[History/Russia/XX - Empire Russe]]
- **Pays Baltes** : Estonie, Lettonie, Lituanie (ex-URSS, UE/OTAN)
- **République Tchèque, Slovaquie, Hongrie, Roumanie, Bulgarie**
- **Moldavie** : [[History/Pridnestrovie - Transnistrie]]

**Union Européenne**
- **Membres** : 27 pays (post-Brexit)
- **Institutions** : Bruxelles, Strasbourg (Parlement), Francfort (BCE)
- **Monnaie** : Euro (20 pays zone euro)
- **Libre circulation** : Schengen

**Enjeux Europe**
- **Démographie** : Vieillissement, déclin population (Italie, Allemagne)
- **Migration** : Afflux réfugiés (Syrie, Afrique)
- **Économie** : Dette (Grèce), inégalités Est-Ouest
- **Géopolitique** : Guerre Ukraine, relation Russie, OTAN
