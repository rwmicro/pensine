# Amérique (42,5 millions km²)


**Amérique du Nord** (24,7M km²)

*États-Unis*
- **Superficie** : 9,8M km² (3e ou 4e mondial)
- **Population** : ~335 millions
- **Capitale** : Washington D.C.
- **Villes** : New York (8,3M), Los Angeles, Chicago
- **Géographie** :
  - Montagnes Rocheuses (Ouest), Appalaches (Est)
  - Grandes Plaines (centre)
  - Grands Lacs (5 lacs frontaliers avec Canada)
  - Mississippi-Missouri (6 275 km)
- **Climat** : Varié (continental, subtropical, désertique, méditerranéen, tropical)
- **Économie** : 1re économie mondiale (PIB ~27 000 milliards $)
  - Tech (Silicon Valley), finance (Wall Street), agriculture, industrie
- **Culture** : Hollywood, jazz, hip-hop, melting pot

*Canada*
- **Superficie** : 9,98M km² (2e mondial)
- **Population** : ~39 millions
- **Capitale** : Ottawa
- **Villes** : Toronto, Montréal, Vancouver
- **Géographie** :
  - Forêt boréale (taïga), toundra arctique
  - Rocheuses canadiennes
  - Bouclier canadien (roche précambrienne)
- **Climat** : Continental humide (Sud), subarctique, arctique (Nord)
- **Langues** : Anglais, français (Québec)
- **Économie** : Ressources naturelles (pétrole, bois, minerais)

*Mexique*
- **Population** : ~128 millions
- **Capitale** : Mexico (plus grande ville nord-américaine, ~22M aire urbaine)
- **Géographie** : Plateau central, Sierra Madre, Yucatán
- **Culture** : Civilisations préhispaniques (Mayas, Aztèques), espagnol
- **Économie** : ALENA/USMCA, industrie automobile, tourisme

**Amérique Centrale**
- **Pays** : Guatemala, Honduras, Nicaragua, Costa Rica, Panama, Belize, El Salvador
- **Géographie** : Isthme étroit, volcans actifs
- **Canal de Panama** : Liaison Atlantique-Pacifique (80 km)
- **Économie** : Agriculture (café, bananes), tourisme
- **Enjeux** : Violence (gangs), migration vers USA

**Caraïbes**
- **Grandes Antilles** : Cuba, Haïti/République Dominicaine (Hispaniola), Jamaïque, Porto Rico
- **Petites Antilles** : Barbade, Grenade, Martinique (France), etc.
- **Économie** : Tourisme, agriculture (canne à sucre historiquement)
- **Histoire** : Esclavage, colonisation européenne

**Amérique du Sud** (17,8M km²)

*Brésil*
- **Superficie** : 8,5M km² (5e mondial)
- **Population** : ~216 millions (6e mondial)
- **Capitale** : Brasília (ville planifiée, 1960)
- **Villes** : São Paulo (12M), Rio de Janeiro
- **Géographie** :
  - **Amazonie** : Plus grande forêt tropicale (60% au Brésil)
  - Fleuve Amazone (6 400 km, 2e plus long)
  - Pantanal (plus grande zone humide)
  - Planalto (plateau central)
- **Langue** : Portugais (seul pays lusophone Amérique)
- **Économie** : Agriculture (soja, café, sucre), industrie, BRICS

*Argentine*
- **Population** : ~46 millions
- **Capitale** : Buenos Aires (3M, 15M aire urbaine)
- **Géographie** : Pampa (plaines fertiles), Andes (Aconcagua, 6 961m, plus haut hors Asie), Patagonie
- **Économie** : Agriculture (viande, vin, céréales)

*Colombie, Venezuela, Équateur*
- **Andes** : Chaîne montagneuse traverse 3 pays
- **Venezuela** : Pétrole (réserves importantes), crise humanitaire
- **Colombie** : Café, biodiversité, ex-conflit FARC

*Pérou, Bolivie*
- **Civilisation Inca** : Machu Picchu (Pérou)
- **Lac Titicaca** : Plus haut lac navigable (3 812m)
- **Bolivie** : Salar d'Uyuni (plus grand désert de sel), lithium

*Chili*
- **Forme** : Long et étroit (4 300 km × 180 km moyenne)
- **Géographie** : Désert Atacama (plus sec au monde), Andes, fjords sud
- **Économie** : Cuivre (1er producteur mondial)

**Enjeux Amérique**
- **Déforestation** : Amazonie (agriculture, élevage)
- **Inégalités** : Coefficient Gini élevé
- **Urbanisation** : Mégapoles (São Paulo, Mexico, Buenos Aires)
- **Migration** : Vers États-Unis
