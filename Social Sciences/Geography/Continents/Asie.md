# Asie (44,6 millions km²)


**Caractéristiques**
- **Continent le plus vaste**
- **Population** : ~4,7 milliards (60% humanité)
- **Pays** : 48-50 selon définitions

**Asie de l'Est**

*Chine*
- **Superficie** : 9,6M km² (3e ou 4e mondial)
- **Population** : ~1,4 milliard (2e, dépassée par Inde en 2023)
- **Capitale** : Pékin (Beijing, ~22M)
- **Villes** : Shanghai (25M), Guangzhou, Shenzhen
- **Géographie** :
  - Désert de Gobi, plateau tibétain
  - Fleuves : Yangzi Jiang (6 300 km), Huang He (fleuve Jaune)
  - Mont Everest (8 849m, frontière Népal-Tibet)
- **Économie** : 2e économie mondiale, "Usine du monde", route de la soie (BRI)
- **Système** : République populaire (parti unique communiste)

*Japon*
- **Population** : ~123 millions
- **Capitale** : Tokyo (14M, 37M aire urbaine - plus grande au monde)
- **Géographie** : Archipel 4 îles principales (Honshu, Hokkaido, Kyushu, Shikoku)
  - Volcanisme actif (mont Fuji, 3 776m)
  - Séismes fréquents (ceinture de feu Pacifique)
- **Économie** : 3e économie mondiale, technologie (Sony, Toyota, Nintendo)
- **Culture** : Anime, manga, samouraï, geishas

*Corée du Sud*
- **Population** : ~52 millions
- **Capitale** : Séoul (10M, 25M aire urbaine)
- **Économie** : Tech (Samsung, LG), K-pop, cinéma (Parasite)
- **Division** : DMZ avec Corée du Nord (1953)

*Corée du Nord*
- **Système** : Dictature, dynastie Kim (Kim Il-sung, Kim Jong-il, Kim Jong-un)
- **Isolement** : Peu d'échanges internationaux
- **Nucléaire** : Programme controversé

**Asie du Sud-Est**

*Indonésie*
- **Population** : ~277 millions (4e mondial)
- **Capitale** : Jakarta (Java, 11M, bientôt déplacée à Nusantara Bornéo)
- **Géographie** : Archipel 17 000 îles (Java, Sumatra, Bornéo/Kalimantan, Sulawesi, Nouvelle-Guinée ouest)
- **Langue** : Indonésien (bahasa Indonesia)
- **Religion** : Islam majoritaire (1er pays musulman par population)
- **Biodiversité** : Forêts tropicales, orangs-outans, tigres

*Thaïlande*
- **Capitale** : Bangkok (11M)
- **Tourisme** : Temples bouddhistes, plages, cuisine
- **Économie** : Riz, industrie

*Vietnam*
- **Histoire** : Guerre du Vietnam (1955-1975), [[History/France/XX - Guerre d'Algérie]] parallèle décolonisation
- **Capitale** : Hanoï
- **Économie** : Croissance rapide, textile

*Philippines, Malaisie, Singapour*
- **Singapour** : Cité-État, hub financier/technologique Asie
- **Malaisie** : Petronas Towers, diversité ethnique
- **Philippines** : Archipel 7 000 îles

**Asie du Sud**

*Inde*
- **Superficie** : 3,3M km² (7e)
- **Population** : ~1,43 milliard (1re depuis 2023)
- **Capitale** : New Delhi (33M aire urbaine)
- **Villes** : Mumbai (Bombay), Kolkata (Calcutta), Bangalore (tech)
- **Géographie** :
  - Himalaya (Nord), Gange (2 510 km, sacré)
  - Plateau du Deccan, Ghâts occidentaux/orientaux
- **Langues** : Hindi, anglais + 21 langues officielles
- **Religions** : Hindouisme (79%), islam (14%), sikhisme, bouddhisme (origine)
- **Économie** : Services (IT, Bangalore), agriculture, cinéma (Bollywood)
- **Système** : Démocratie (plus grande au monde)

*Pakistan*
- **Population** : ~231 millions (5e)
- **Capitale** : Islamabad
- **Création** : 1947 (partition Inde, base religieuse)
- **Conflit** : Cachemire avec Inde

*Bangladesh*
- **Population** : ~170 millions (8e)
- **Densité** : Très élevée (1 265 hab/km²)
- **Géographie** : Deltas Gange-Brahmapoutre, inondations fréquentes
- **Économie** : Textile (export)

*Népal, Sri Lanka, Bhoutan*
- **Népal** : Himalaya, Everest, bouddhisme/hindouisme
- **Sri Lanka** : Île, thé, bouddhisme, conflit tamoul (terminé 2009)
- **Bhoutan** : Bonheur National Brut (BNB)

**Asie Centrale**
- **Pays** : Kazakhstan, Ouzbékistan, Turkménistan, Tadjikistan, Kirghizistan
- **Ex-URSS** : Indépendance 1991
- **Géographie** : Steppes, déserts, mer d'Aral (catastrophe écologique)
- **Route de la Soie** : Historique Samarkand, Boukhara
- **Économie** : Gaz, pétrole (Kazakhstan, Turkménistan)

**Moyen-Orient / Asie de l'Ouest**

*Proche-Orient*
- **Israël / Palestine** : Conflit israélo-palestinien (1948-)
- **Liban** : Mosaïque confessionnelle, Beyrouth
- **Syrie** : Guerre civile (2011-), [[History/Syrie/Répartition Ethnique]]
- **Jordanie** : Pétra, stabilité relative

*Péninsule Arabique*
- **Arabie Saoudite** : Islam (La Mecque, Médine), pétrole (1er exportateur)
- **Émirats Arabes Unis** : Dubaï (gratte-ciels, tourisme), Abu Dhabi
- **Yémen** : Guerre civile, crise humanitaire
- **Oman, Qatar, Koweït, Bahreïn**

*Plateau Iranien*
- **Iran** : 86M habitants, perse (non arabe), chiite, nucléaire
- **Irak** : Mésopotamie historique, pétrole, Tigre-Euphrate
  - Guerre Irak (2003-2011)

*Turquie*
- **Position** : Charnière Europe-Asie (Istanbul sur Bosphore)
- **Population** : ~85 millions
- **Histoire** : Empire ottoman, [[History/Kurdes/Histoire]]
- **Économie** : Émergente, tourisme

*Caucase*
- **Arménie, Géorgie, Azerbaïdjan**
- **Russie** : Tchétchénie, Daghestan (Caucase Nord)

**Enjeux Asie**
- **Démographie** : Vieillissement (Japon, Corée), jeunesse (Asie Sud)
- **Économie** : Croissance rapide, inégalités
- **Environnement** : Pollution (Chine, Inde), submersion îles (Maldives)
- **Géopolitique** : Tensions mer de Chine, Cachemire, Moyen-Orient
