# Géopolitique


### Organisations Internationales

**ONU** (Organisation Nations Unies)
- **Création** : 1945 (après WWII)
- **Membres** : 193 États
- **Siège** : New York
- **Conseil Sécurité** : 5 permanents (USA, Russie, Chine, UK, France) + 10 non-permanents

**Union Européenne**
- **Membres** : 27 (post-Brexit)
- **Objectif** : Intégration économique/politique
- **Institutions** : Commission, Parlement, Conseil

**OTAN** (Organisation Traité Atlantique Nord)
- **Création** : 1949 (Guerre Froide)
- **Membres** : 32 (dont Finlande, Suède récemment)
- **Objectif** : Défense collective

**Autres**
- **G7** : USA, Canada, UK, France, Allemagne, Italie, Japon
- **G20** : G7 + pays émergents (Chine, Inde, Brésil, etc.)
- **BRICS** : Brésil, Russie, Inde, Chine, Afrique du Sud (+expansion)
- **ASEAN** : Association nations Asie Sud-Est

### Conflits et Tensions

**Actifs**
- **Ukraine** : Guerre Russie (2022-)
- **Gaza/Israël-Palestine** : Conflit depuis 1948
- **Syrie** : Guerre civile (2011-), [[History/Syrie/Répartition Ethnique]]
- **Yémen** : Guerre civile, crise humanitaire
- **Sahel** : Terrorisme islamiste (Mali, Burkina Faso, Niger)
- **Myanmar** : Coup d'État militaire (2021), Rohingyas

**Gelés**
- **Corées** : DMZ (1953)
- **Cachemire** : Inde-Pakistan
- **Chypre** : Partition (1974)
- **Transnistrie** : [[History/Pridnestrovie - Transnistrie]]

**Tensions**
- **Mer de Chine** : Revendications territoriales (Chine vs. voisins)
- **Taïwan** : Chine revendique, USA soutient
- **Arctique** : Ressources, routes maritimes (fonte glace)
