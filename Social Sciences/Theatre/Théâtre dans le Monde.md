# Théâtre dans le Monde


### Traditions Non-Occidentales

**Nô (Japon)**
- XIVe siècle, **Zeami** : théoricien
- Masques, chant, danse lente
- Symbolisme, épure
- Sujets : fantômes, esprits, histoire

**Kabuki (Japon)**
- XVIIe siècle, populaire
- Maquillage stylisé, costumes somptueux
- Onnagata : hommes jouant femmes
- Spectaculaire, émotionnel

**Kathakali (Inde)**
- Kerala, danse-théâtre
- Maquillage élaboré (couleurs symboliques)
- Mudras (gestes codés)
- Épopées (Mahabharata, Ramayana)

**Opéra de Pékin (Chine)**
- Synthèse chant, mime, acrobatie, arts martiaux
- Maquillage symbolique
- Conventions strictes

**Bunraku (Japon)**
- Théâtre de marionnettes
- 3 manipulateurs visibles par marionnette
- Chanteur-récitant (shamisen)

**Wayang (Indonésie)**
- Théâtre d'ombres (Java, Bali)
- Marionnettes cuir, épopées hindoues
- Dalang : maître marionnettiste

### Influences Croisées

- **Artaud** inspiré par Balinais (Exposition coloniale, Paris 1931)
- **Brecht** : théâtre chinois, distanciation
- **Brook**, **Mnouchkine** : incorporation techniques asiatiques
- **Interculturalité** : débat appropriation vs enrichissement
