# Phonétique et API — Référence Inter-langues

L'**Alphabet Phonétique International** (API, ou IPA en anglais) est un système universel pour transcrire les sons de **toutes** les langues du monde. Connaître ses symboles essentiels permet de comparer les sons entre langues sans confusion orthographique.

## Pourquoi l'API ?

| Problème | Solution API |
|----------|-------------|
| "ch" français /ʃ/ ≠ "ch" allemand /x/ ≠ "ch" italien /k/ | API distingue chaque son |
| "j" français /ʒ/ ≠ "j" anglais /dʒ/ ≠ "j" allemand /j/ | API désambiguïse |
| Une lettre = plusieurs sons (ex. "g" français : /g/, /ʒ/) | API = un symbole par son |
| Tons et intonation invisibles à l'écrit | API les note explicitement |

## Voyelles — le trapèze vocalique

```
            FRONT      CENTRAL      BACK
        +-----------+----------+-----------+
HAUT    |  i  y     |    ɨ ʉ   |   ɯ  u    |  fermées
        |           |          |           |
        |  ɪ  ʏ     |          |     ʊ     |
        |           |          |           |
MOYEN   |  e  ø     |    ə     |   ɤ  o    |  mi-fermées
        |           |          |           |
        |  ɛ  œ     |    ɜ     |   ʌ  ɔ    |  mi-ouvertes
        |           |          |           |
        |  æ        |    ɐ     |           |
BAS     |  a  ɶ     |          |   ɑ  ɒ    |  ouvertes
        +-----------+----------+-----------+
                                 (lèvres : non arrondies | arrondies)
```

### Voyelles longues vs brèves

L'allemand, le hindi, l'anglais distinguent voyelles **longues** /aː, eː, iː/ vs **brèves** /a, e, i/.

| Allemand | Sens | Voyelle |
|----------|------|---------|
| Mann /man/ | homme | brève |
| Mahn /maːn/ | rappel | longue |

Le symbole **ː** indique la longueur en API.

## Consonnes propres à certaines langues

### Rétroflexes (Mandarin, Hindi, Tamoul)

| API | Description | Mandarin | Hindi |
|-----|-------------|---------|-------|
| /ʈ/ | t rétroflexe | — | ट |
| /ɖ/ | d rétroflexe | — | ड |
| /ɳ/ | n rétroflexe | — | ण |
| /ʂ/ | sh rétroflexe | sh, ch, zh | ष |
| /ʈʂ/ | tch rétroflexe | zh | — |

> Le mandarin a **3 séries de "ch/s"** : palatale (j, q, x), rétroflexe (zh, ch, sh, r) et dentale (z, c, s).

### Aspirées (Hindi, Mandarin, Coréen)

| API | Description | Hindi | Mandarin |
|-----|-------------|-------|----------|
| /pʰ/ | p aspiré | फ ph | p (pinyin) |
| /tʰ/ | t aspiré | थ th | t (pinyin) |
| /kʰ/ | k aspiré | ख kh | k (pinyin) |

> En **mandarin et hindi**, p/b ne diffèrent **pas par la sonorité** (comme en français) mais par l'**aspiration** : /pʰ/ vs /p/. C'est un piège pour les francophones.

### Glottalisées et éjectives (Kabyle, Quechua)

| API | Description | Exemple |
|-----|-------------|---------|
| /pʼ/ | p éjectif | (langues caucasiennes) |
| /tʼ/ | t éjectif | (kabyle, géorgien) |

## Tons (langues tonales)

Les tons sont notés en API par des **lettres tonales** ou **diacritiques numériques**.

| Notation | Signification |
|----------|--------------|
| ˥ ou 5 | Ton très haut |
| ˦ ou 4 | Haut |
| ˧ ou 3 | Médian |
| ˨ ou 2 | Bas |
| ˩ ou 1 | Très bas |

## Mémoriser les symboles utiles

Concentration recommandée :
1. **Les 5 voyelles cardinales** /i e a o u/ — base universelle
2. **Schwa** /ə/ — voyelle la plus fréquente du monde
3. **Les 4 sons "ch/j"** /ʃ ʒ tʃ dʒ/ — distinction critique
4. **/x/, /ʁ/, /h/** — les 3 "h" / "r" gutturaux
5. **/ŋ/, /ɲ/** — nasales palatales et vélaires
6. **/θ, ð/** — les "th" anglais
7. **/y, ø, œ/** — voyelles arrondies françaises (utiles pour comparer aux Umlauts allemands)
