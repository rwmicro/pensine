## Expressions Utiles

### Demander le Métier

| Français | Formel | Informel |
| :------: | :----: | :------: |
| Quel est votre métier ? | Apa pekerjaan Anda? | Kerja apa? |
| Qu'est-ce que vous faites dans la vie ? | Apa profesi Anda? | Kamu kerja di mana? |
| Où travaillez-vous ? | Di mana Anda bekerja? | Kerja di mana? |

## Formation des Noms de Métiers

### Avec le préfixe PE-

| Verbe | Métier | Français |
| :---: | :----: | :------: |
| *tulis* (écrire) | **penulis** | écrivain |
| *nyanyi* (chanter) | **penyanyi** | chanteur |
| *tari* (danser) | **penari** | danseur |
| *main* (jouer) | **pemain** | joueur |
| *jual* (vendre) | **penjual** | vendeur |
| *beli* (acheter) | **pembeli** | acheteur |
| *dengar* (écouter) | **pendengar** | auditeur |
| *lukis* (peindre) | **pelukis** | peintre |

### Avec TUKANG (artisan/ouvrier)

| :--------: | :----: | :------: |
