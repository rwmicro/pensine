## Marqueurs de Temps Verbaux

| Français | Indonésien | Exemple |
| :------: | :--------: | :-----: |
| (passé accompli) | Sudah | Saya sudah makan = J'ai mangé |
| (en cours) | Sedang / Lagi | Saya sedang makan = Je mange (maintenant) |
| (futur) | Akan / Mau | Saya akan makan = Je vais manger |
| (pas encore) | Belum | Saya belum makan = Je n'ai pas encore mangé |
| (expérience) | Pernah | Saya pernah ke Bali = J'ai déjà été à Bali |
| (jamais) | Tidak pernah | Saya tidak pernah makan durian = Je n'ai jamais mangé de durian |

## Expressions Utiles

- **Sudah jam berapa?** = Quelle heure est-il ?
- **Jam sepuluh pagi** = 10h du matin
- **Sore nanti** = Cet après-midi
- **Minggu depan saya sibuk** = La semaine prochaine je suis occupé
- **Dia selalu terlambat** = Il est toujours en retard
- **Sampai kapan?** = Jusqu'à quand ?
- **Sejak kapan?** = Depuis quand ?
