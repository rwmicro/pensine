## Marqueurs de Temps Verbaux

| Français | Indonésien | Exemple |
| :------: | :--------: | :-----: |
| (passé accompli) | ==Sudah::id== | Saya sudah makan = J'ai mangé |
| (en cours) | ==Sedang::id== / ==Lagi::id== | Saya sedang makan = Je mange (maintenant) |
| (futur) | ==Akan::id== / ==Mau::id== | Saya akan makan = Je vais manger |
| (pas encore) | ==Belum::id== | Saya belum makan = Je n'ai pas encore mangé |
| (expérience) | ==Pernah::id== | Saya pernah ke Bali = J'ai déjà été à Bali |
| (jamais) | ==Tidak pernah::id== | Saya tidak pernah makan durian = Je n'ai jamais mangé de durian |

## Expressions Utiles

- **Sudah jam berapa?** = Quelle heure est-il ?
- **Jam sepuluh pagi** = 10h du matin
- **Sore nanti** = Cet après-midi
- **Minggu depan saya sibuk** = La semaine prochaine je suis occupé
- **Dia selalu terlambat** = Il est toujours en retard
- **Sampai kapan?** = Jusqu'à quand ?
- **Sejak kapan?** = Depuis quand ?
