## Classificateurs pour Animaux

En indonésien, on utilise **ekor** (queue) pour compter les animaux :

| Français | Indonésien |
| :------: | :--------: |
| Un chien | ==Satu ekor anjing::id== / ==Seekor anjing::id== |
| Deux chats | ==Dua ekor kucing::id== |
| Trois poissons | ==Tiga ekor ikan::id== |
| Combien d'animaux ? | ==Berapa ekor?::id== |

## Expressions avec des Animaux

| Expression | Traduction | Signification |
| :--------: | :--------: | :-----------: |
| **Seperti anjing dan kucing** | Comme chien et chat | Se disputer constamment |
| **Buaya darat** | Crocodile terrestre | Coureur de jupons |
| **Kambing hitam** | Mouton noir | Bouc émissaire |
| **Kuda hitam** | Cheval noir | Outsider (qui peut gagner) |
| **Bermuka dua** | Avoir deux visages | Hypocrite (comme un serpent) |
| **Darah biru** | Sang bleu | De sang royal |
| **Kutu buku** | Pou de livre | Rat de bibliothèque |
| **Lintah darat** | Sangsue terrestre | Usurier |
| **Monyet** | Singe | Idiot (insulte) |
| **Otak udang** | Cerveau de crevette | Stupide |
