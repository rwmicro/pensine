# Salutations (Salam)

## Salutations selon le Moment de la Journée

| Français | Formel | Informel | Prononciation |
| :------: | :----: | :------: | :-----------: |
| Bonjour (matin) | Selamat pagi | Pagi! | /sə.la.mat pa.ˈgi/ |
| Bonjour (midi) | Selamat siang | Siang! | /sə.la.mat si.ˈaŋ/ |
| Bonjour (après-midi) | Selamat sore | Sore! | /sə.la.mat so.ˈrə/ |
| Bonsoir / Bonne nuit | Selamat malam | Malam! | /sə.la.mat ma.ˈlam/ |

> **Note** : En informel, on utilise souvent juste le moment de la journée : "Pagi!", "Siang!", etc.

## Exemples de Dialogues

### Dialogue Formel
```
A: Selamat pagi, Pak.
B: Selamat pagi. Bagaimana kabar Anda?
A: Baik-baik saja, terima kasih. Bagaimana dengan Anda?
B: Saya juga baik. Terima kasih.
```

### Dialogue Informel
```
A: Hai! Apa kabar?
B: Baik! Kamu gimana?
A: Baik juga. Lagi ngapain?
B: Gak ngapa-ngapain. Mau nongkrong gak?
A: Oke! Sampai nanti ya!
B: Dadah!
```
