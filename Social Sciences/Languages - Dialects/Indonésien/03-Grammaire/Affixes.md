# Préfixes et Suffixes (Imbuhan)

> Le système d'affixes est **fondamental** en indonésien. Il transforme les racines (kata dasar) en verbes, noms, adjectifs, etc. C'est ce qui différencie l'indonésien formel de l'indonésien parlé.

## Vue d'ensemble

| Type | Affixe | Fonction Principale |
| :--: | :----: | :-----------------: |
| Préfixe | me-, ber-, di-, ter-, pe-, ke- | Former des verbes |
| Suffixe | -kan, -i, -an | Modifier le sens du verbe |
| Circonfixe | ke-...-an, pe-...-an, ber-...-an | Former des noms |

## Préfixe ME- (Actif Transitif)

> Le préfixe **me-** forme des verbes actifs. Il change de forme selon la première lettre de la racine.

### Règles de Transformation

| Première Lettre | Forme | Exemple |
| :-------------: | :---: | :-----: |
| l, m, n, r, w, y | me- | *lihat* → **melihat** (voir) |
| b, f, v | mem- | *baca* → **membaca** (lire) |
| c, d, j, z | men- | *cari* → **mencari** (chercher) |
| g, h, kh, a, i, u, e, o | meng- | *gambar* → **menggambar** (dessiner) |
| k → ∅ | meng- | *kirim* → **mengirim** (envoyer) |
| p → ∅ | mem- | *pukul* → **memukul** (frapper) |
| t → ∅ | men- | *tulis* → **menulis** (écrire) |
| s → ∅ | meny- | *sapu* → **menyapu** (balayer) |

### Exemples Détaillés

| Racine | Sens | Avec ME- | Exemple |
| :----: | :--: | :------: | :-----: |
| tulis | écrire | menulis | *Saya **menulis** surat* = J'écris une lettre |
| baca | lire | membaca | *Dia **membaca** buku* = Il lit un livre |
| makan | manger | memakan | *Kucing **memakan** ikan* = Le chat mange le poisson |
| ambil | prendre | mengambil | *Ibu **mengambil** tas* = Maman prend le sac |
| dengar | entendre | mendengar | *Saya **mendengar** suara* = J'entends un son |
| cium | embrasser | mencium | *Dia **mencium** ibunya* = Il embrasse sa mère |
| sapu | balayer | menyapu | *Adik **menyapu** lantai* = Le petit frère balaie le sol |

### Informel : Suppression du préfixe ME-

À l'oral, **me-** est souvent supprimé :

| Formel | Informel | Français |
| :----: | :------: | :------: |
| Saya **menulis** | Aku **nulis** | J'écris |
| Dia **membaca** | Dia **baca** | Il lit |
| Saya **menelepon** | Aku **nelpon** | J'appelle |
| Mereka **membeli** | Mereka **beli** | Ils achètent |
| Dia **mengirim** | Dia **kirim** | Il envoie |

## Préfixe BER- (Intransitif)

> **Ber-** forme des verbes intransitifs (sans objet direct) ou exprime un état/activité.

### Règles de Transformation

| Condition | Forme | Exemple |
| :-------: | :---: | :-----: |
| Standard | ber- | *jalan* → **berjalan** (marcher) |
| Racine commence par "r" | be- | *renang* → **berenang** (nager) |
| Racine commence par consonne + "er" | be- | *kerja* → **bekerja** (travailler) |

### Usages de BER-

#### 1. Porter / Avoir

| Racine | Avec BER- | Signification |
| :----: | :-------: | :-----------: |
| baju | berbaju | porter des vêtements |
| kacamata | berkacamata | porter des lunettes |
| sepatu | bersepatu | porter des chaussures |
| kumis | berkumis | avoir une moustache |
| anak | beranak | avoir des enfants |
| istri | beristri | avoir une femme |

*Dia **berkacamata*** = Il/Elle porte des lunettes

#### 2. Faire une activité

| Racine | Avec BER- | Signification |
| :----: | :-------: | :-----------: |
| nyanyi | bernyanyi | chanter |
| tanya | bertanya | demander |
| bicara | berbicara | parler |
| main | bermain | jouer |
| temu | bertemu | se rencontrer |
| jalan | berjalan | marcher |
| lari | berlari | courir |

*Mereka **bermain** sepak bola* = Ils jouent au football

#### 3. Utiliser un moyen de transport

| Racine | Avec BER- | Signification |
| :----: | :-------: | :-----------: |
| mobil | bermobil | aller en voiture |
| sepeda | bersepeda | faire du vélo |

## Préfixe DI- (Passif)

> **Di-** forme le passif. L'objet devient sujet.

### Formation

**Actif (me-)** → **Passif (di-)**

| Actif | Passif | Français |
| :---: | :----: | :------: |
| Saya **menulis** surat | Surat **ditulis** (oleh saya) | La lettre est écrite (par moi) |
| Ibu **memasak** nasi | Nasi **dimasak** (oleh ibu) | Le riz est cuisiné (par maman) |
| Dia **membeli** buku | Buku **dibeli** (oleh dia) | Le livre est acheté (par lui) |
| Polisi **menangkap** pencuri | Pencuri **ditangkap** (oleh polisi) | Le voleur est arrêté (par la police) |

## Préfixe TER- (Résultatif / Superlatif)

> **Ter-** a plusieurs usages : action involontaire, résultat, capacité, ou superlatif.

### 1. Action Involontaire / Accidentelle

| Racine | Avec TER- | Signification |
| :----: | :-------: | :-----------: |
| jatuh | terjatuh | tomber (par accident) |
| tidur | tertidur | s'endormir (involontairement) |
| bangun | terbangun | se réveiller (involontairement) |
| tawa | tertawa | éclater de rire |
| ingat | teringat | se souvenir soudainement |

*Saya **tertidur** di kelas* = Je me suis endormi en classe (sans le vouloir)

### 2. État Résultant

| Racine | Avec TER- | Signification |
| :----: | :-------: | :-----------: |
| buka | terbuka | ouvert |
| tutup | tertutup | fermé |
| tulis | tertulis | écrit |
| kenal | terkenal | célèbre (connu) |
| letak | terletak | situé |

*Pintu **terbuka*** = La porte est ouverte
*Jakarta **terletak** di pulau Jawa* = Jakarta est située sur l'île de Java

### 3. Superlatif (le plus)

| Racine | Avec TER- | Signification |
| :----: | :-------: | :-----------: |
| besar | terbesar | le plus grand |
| kecil | terkecil | le plus petit |
| baik | terbaik | le meilleur |
| buruk | terburuk | le pire |
| tinggi | tertinggi | le plus haut |
| murah | termurah | le moins cher |
| mahal | termahal | le plus cher |

*Ini restoran **terbaik*** = C'est le meilleur restaurant

## Préfixe PE- / PEN- / PEM- / PENG- / PENY- (Nominalisateur)

> **Pe-** forme des noms désignant une personne ou un outil. Suit les mêmes règles que **me-**.

### Personnes (Agent)

| Racine | Nom | Signification |
| :----: | :-: | :-----------: |
| tulis | **penulis** | écrivain |
| nyanyi | **penyanyi** | chanteur |
| dengar | **pendengar** | auditeur |
| beli | **pembeli** | acheteur |
| jual | **penjual** | vendeur |
| kerja | **pekerja** | travailleur |
| main | **pemain** | joueur |
| tari | **penari** | danseur |
| lukis | **pelukis** | peintre |
| curi | **pencuri** | voleur |

### Outils / Instruments

| Racine | Nom | Signification |
| :----: | :-: | :-----------: |
| potong | **pemotong** | coupeur / ciseaux |
| buka | **pembuka** | ouvre- (bouteille, etc.) |
| tutup | **penutup** | couvercle |
| garis | **penggaris** | règle (instrument) |
| hapus | **penghapus** | gomme |
| dingin | **pendingin** | climatiseur |

## Suffixe -KAN (Causatif / Bénéfactif)

> **-kan** indique qu'on fait l'action pour quelqu'un d'autre, ou qu'on cause quelque chose.

### Exemples

| Racine | Avec -KAN | Signification |
| :----: | :-------: | :-----------: |
| buka | bukakan | ouvrir (pour qqn) |
| tutup | tutupkan | fermer (pour qqn) |
| ambil | ambilkan | prendre (pour qqn) |
| beli | belikan | acheter (pour qqn) |
| buat | buatkan | faire (pour qqn) |
| masak | masakkan | cuisiner (pour qqn) |
| cuci | cucikan | laver (pour qqn) |
| bawa | bawakan | apporter (pour qqn) |
| cerita | ceritakan | raconter |
| jelas | jelaskan | expliquer |

**Exemples :**
- *Tolong **bukakan** pintu* = S'il te plaît, ouvre la porte (pour moi)
- *Ibu **masakkan** nasi goreng* = Maman cuisine du nasi goreng (pour nous)
- *Dia **ceritakan** pengalamannya* = Il raconte son expérience

### Informel : -IN (Jakarta)

À Jakarta, **-kan** devient **-in** :

| Formel | Informel Jakarta | Français |
| :----: | :--------------: | :------: |
| bukakan | buka**in** | ouvrir pour |
| belikan | beli**in** | acheter pour |
| masakkan | masak**in** | cuisiner pour |
| ambilkan | ambil**in** | prendre pour |
| carikan | cari**in** | chercher pour |
| perbaiki | benerin | réparer |

*Tolong **beliin** aku kopi* = S'il te plaît, achète-moi un café

## Suffixe -I (Locatif / Répétitif)

> **-i** indique souvent le lieu de l'action, ou une action répétée/intensive.

### Exemples

| Racine | Avec -I | Signification |
| :----: | :-----: | :-----------: |
| duduk | duduki | s'asseoir sur |
| masuk | masuki | entrer dans |
| tinggal | tinggali | habiter (un lieu) |
| datang | datangi | venir vers / visiter |
| ikut | ikuti | suivre |
| cinta | cintai | aimer |
| harga | hargai | apprécier |
| penuhi | penuhi | remplir |
| temui | temui | rencontrer |
| hadiri | hadiri | assister à |

**Exemples :**
- *Dia **menduduki** kursi* = Il/Elle s'assoit sur la chaise
- *Saya **mencintai** kamu* = Je t'aime
- *Mereka **mengikuti** kursus* = Ils suivent un cours

## Circonfixe KE-...-AN (État / Abstraction)

> **Ke-...-an** forme des noms abstraits exprimant un état, une qualité ou un lieu.

### États et Qualités

| Racine | Avec KE-...-AN | Signification |

| baik | kebaikan | bonté |

| sehat | kesehatan | santé |
| aman | keamanan | sécurité |

| susah | kesusahan | difficulté |
| senang | kesenangan | plaisir |

| dingin | kedinginan | avoir froid |

> **Ber-...-an** exprime une action réciproque ou collective.

*Mereka **berpelukan*** = Ils s'enlacent

## Tableau Récapitulatif

| Affixe | Fonction | Exemple |
| :----: | :------: | :-----: |
| **me-** | Verbe actif | *tulis* → *menulis* |
| **ber-** | Verbe intransitif | *jalan* → *berjalan* |
| **di-** | Verbe passif | *tulis* → *ditulis* |
| **ter-** | Résultat / Superlatif | *buka* → *terbuka* |
| **pe-** | Personne / Outil | *tulis* → *penulis* |
| **-kan** | Pour quelqu'un | *buka* → *bukakan* |
| **-i** | Lieu / Intensif | *masuk* → *masuki* |
| **-an** | Nom (résultat) | *makan* → *makanan* |
| **ke-...-an** | État abstrait | *baik* → *kebaikan* |
| **pe-...-an** | Processus / Lieu | *didik* → *pendidikan* |
| **ber-...-an** | Réciprocité | *peluk* → *berpelukan* |

## Formel vs Informel

| Contexte | Style | Exemple |
| :------: | :---: | :-----: |
| Écrit, officiel | Avec préfixes | *Saya **menulis** surat* |
| Oral, quotidien | Sans préfixes | *Aku **nulis** surat* |
| Jakarta | Suffixe -in | *Tolong **bukain** pintunya* |

> **Conseil** : Comprendre les affixes est essentiel pour lire l'indonésien formel (journaux, livres, administration). À l'oral, on peut souvent les omettre.
