# Communication Non-Verbale — Gestes et Codes Culturels

Apprendre une langue ne suffit pas — il faut aussi maîtriser les **codes non-verbaux** : gestes, distance physique, contact visuel, ponctualité, salutations physiques. Une erreur peut coûter une relation.

## Les 5 dimensions de la communication non-verbale

| Dimension | Description |
|-----------|-------------|
| **Kinésique** | Gestes, mimiques, posture |
| **Proxémique** | Distance physique entre interlocuteurs |
| **Haptique** | Contact physique (poignée, accolade, baisers) |
| **Chronémique** | Rapport au temps (ponctualité, attente) |
| **Paralangage** | Volume, ton, rythme, silences |

## Distance interpersonnelle (proxémique)

Edward T. Hall a défini 4 zones, qui varient fortement selon les cultures.

| Zone | Distance | Usage |
|------|---------|-------|
| Intime | 0–45 cm | Amour, famille proche, sport de contact |
| Personnelle | 45–120 cm | Amis, conversations personnelles |
| Sociale | 120–360 cm | Connaissances, négociations |
| Publique | 360+ cm | Conférence, public, formel |

### Variations culturelles — distance personnelle confortable

| Région | Distance habituelle | Caractéristique |
|--------|---------------------|----------------|
| Méditerranée (Espagne, Italie, Liban, Turquie) | 30-50 cm | Très proche, contact physique fréquent |
| France | 50-80 cm | Modérée |
| Allemagne, Suisse, Pays-Bas | 80-120 cm | Distance respectée, moins de contact |
| Royaume-Uni | 80-120 cm | Distance "réservée" |
| Asie de l'Est (Chine, Japon, Corée) | 100-150 cm | Distance grande, peu de contact |
| Inde | 60-90 cm | Variable selon caste / genre |
| Mondes arabes (entre hommes) | 30-50 cm | Très proche |
| Mondes arabes (mixte) | 100+ cm | Distance importante |

## Salutations physiques

### Poignée de main

| Région | Norme |
|--------|-------|
| France | Serrée, brève, ferme — chaque jour entre collègues |
| Allemagne | Très ferme, regard direct, rituel quotidien |
| Royaume-Uni / USA | Modérée, brève |
| Espagne, Italie | Souvent remplacée par accolade ou bise |
| Monde arabe (hommes) | Ferme + main droite sur cœur |
| Monde arabe (mixte) | Pas de poignée — geste de loin ou main sur cœur |
| Inde | Plutôt **Namaste** (mains jointes, légère inclinaison) |
| Japon | Plutôt **inclinaison** (jamais poignée traditionnelle) |
| Chine | Modérée, parfois deux mains pour le respect |

### Bises (faire la bise)

| Pays | Nombre |
|------|--------|
| France (selon région) | 1 (Bretagne, Normandie), 2 (Paris, IDF), 3 (Sud-Est, Provence), 4 (Loire) |
| Belgique | 1 ou 3 |
| Pays-Bas | 3 |
| Espagne | 2 (de droite à gauche) |
| Italie | 2 |
| Suisse | 3 |
| Liban (entre amis) | 3 (parfois 1) |
| Russie | 3 (entre proches, hommes inclus) |
| Amérique latine | 1 (à droite) |

> **Pour les hommes :** la bise entre hommes est **normale** dans le monde arabe, en Russie, en Italie du Sud, en France parfois (entre proches). Tabou en Allemagne, Royaume-Uni, USA.

### Inclinaison (bow)

| Pays | Profondeur |
|------|-----------|
| Japon | 15° (salutation), 30° (respect), 45° (excuses formelles) |
| Corée | Inclinaison à 30°, surtout aux aînés |
| Thaïlande | **Wai** (mains jointes + inclinaison), niveau selon hiérarchie |
| Inde | **Namaste** (mains jointes au cœur ou au front) |
| Chine | Légère inclinaison, plutôt pour générations âgées ou très formel |

### Toucher culturellement codé

| Geste | Signification |
|-------|--------------|
| Main droite sur le cœur (monde arabe, Iran) | Salutation respectueuse |
| Toucher la tête d'un enfant (Asie SE) | **Tabou** — la tête est sacrée |
| Tape sur l'épaule (Occident) | Amical, encouragement |
| Tape sur le dos (Russie, Espagne) | Très amical |
| Toucher un inconnu (Allemagne, Japon) | À éviter |

## Gestes universels et leurs faux amis

### Pouce levé (👍)

| Région | Sens |
|--------|------|
| Occident, Amérique latine | "OK", positif |
| Brésil, Russie | (Connoté positif) |
| Moyen-Orient (Iran, Iraq, Afghanistan) | **Insulte** (équivalent doigt majeur) |
| Australie | Insulte si remué de bas en haut |

### Pouce et index en cercle (👌)

| Région | Sens |
|--------|------|
| France | "Zéro", nul, raté |
| USA, Royaume-Uni | "OK" |
| Allemagne, Brésil | **Insulte** (parfois sexuelle) |
| Japon | "Argent" (forme de pièce) |

### Le V (✌️)

| Région | Sens |
|--------|------|
| USA, France | "Paix", "Victoire" |
| Royaume-Uni, Australie (paume vers soi) | **Insulte vulgaire** (équivalent doigt majeur) |
| Asie de l'Est | Geste de pose photo |

### Hochement de tête (oui/non)

| Pays | Hochement vertical | Hochement horizontal |
|------|--------------------|--------------------|
| Plupart du monde | Oui | Non |
| Bulgarie, Albanie, Grèce du Nord | **Non** | **Oui** |
| Inde | Tilt latéral spécifique = "OK / je comprends" |

> Le **head wobble** indien (mouvement latéral de la tête) est intraduisible — il signifie selon contexte "oui", "ok", "je comprends", "peut-être", "je t'écoute".

### Faire signe d'approcher (👋 inversé)

| Région | Geste |
|--------|-------|
| Occident | Paume vers soi, doigts qui appellent |
| Asie (Chine, Philippines, Vietnam) | Paume **vers le bas**, doigts qui appellent — utilisée pour les chiens en Occident |

> **Ne jamais utiliser** le geste occidental "viens" en Asie de l'Est — perçu comme grossier.

### "Stop" main levée

| Région | Sens |
|--------|------|
| Occident | Stop, arrêt |
| Grèce | **Insulte grave** (mountza) — paume face à quelqu'un = malédiction |

### Pointer du doigt

| Région | Norme |
|--------|-------|
| Occident | Toléré, pas idéal |
| Asie (surtout Japon) | **Tabou** — pointer une personne est très impoli |
| Inde | Pointer avec le **menton** ou la **main entière** est plus poli |
| Monde arabe | Pointer avec l'index est rude — préférer la main entière |

## Contact visuel

| Région | Norme |
|--------|-------|
| Occident (Europe, USA) | Contact visuel = honnêteté, attention |
| Allemagne, France | Soutenu mais sans fixer |
| Japon, Corée | Contact réduit avec aînés / supérieurs (signe de respect) |
| Chine | Modéré, intense = agression |
| Monde arabe (entre hommes) | Direct, prolongé |
| Monde arabe (entre genres) | Limité — tabou pour femmes envers hommes inconnus |
| Inde | Variable — moins de contact entre genres ou castes |
| Afrique de l'Ouest | Réduit avec aînés (respect) |

## Sourire — sa signification

| Région | Sens du sourire |
|--------|----------------|
| USA | Politesse de base, omniprésent |
| France | Plus rare avec inconnus, soupçon de malhonnêteté si trop large |
| Russie | **Suspect** si à un inconnu ; "le sourire bête" est l'expression |
| Asie de l'Est (Japon, Chine) | Politesse, peut masquer **embarras / désaccord** |
| Allemagne | Modéré, sincère — un service est rendu sans sourire forcé |
| Thaïlande | "Pays du sourire" — sourire pour tout, y compris colère |

> **En Thaïlande**, il existe ~13 types de sourires culturellement codés (Yim Cheun Chom = "sourire pour montrer que je suis content de te voir", Yim Yor = "sourire moqueur", etc.).

## Toucher (haptique)

### Toucher entre amis

| Région | Norme |
|--------|-------|
| Méditerranée, Amérique latine | Touche fréquente — bras, dos, épaule |
| France | Modérée |
| Allemagne, Royaume-Uni | Limitée |
| Asie de l'Est | Très limitée — tabou pour adultes (sauf famille) |
| Monde arabe (hommes ↔ hommes) | Touche fréquente — se tenir la main entre amis hommes |
| Monde arabe (mixte) | Tabou |

### Tabous de toucher

| Geste | Région où c'est tabou |
|-------|---------------------|
| Toucher la tête | Asie du Sud-Est (le sommet de la tête est sacré) |
| Pointer avec les pieds | Asie SE, monde arabe (pieds = impurs) |
| Donner / recevoir avec la main gauche | Inde, monde arabe (main gauche réservée à l'hygiène) |
| Embrasser un proche du sexe opposé en public | Monde arabe, Inde rurale |
| Croiser les jambes en montrant la semelle | Monde arabe, Asie SE |

## Rapport au temps (chronémique)

| Région | Style |
|--------|-------|
| Allemagne, Suisse, Japon | **Mono-chronique** : ponctualité absolue, planning rigoureux |
| Royaume-Uni, Pays-Bas | Ponctualité forte |
| France | Ponctualité ± 5-10 min |
| Espagne, Italie | "Quart d'heure de courtoisie" toléré |
| Amérique latine | "Hora latina" — 30 min de tolérance commune |
| Monde arabe | Polychronique — le temps est élastique, plusieurs choses simultanément |
| Inde | Très polychronique — IST = "Indian Stretchable Time" en blague |
| Afrique sub-saharienne | "African time" — flexibilité importante |

> **Conseil pratique :** en Allemagne, arriver à 14h00 pour 14h00 est **standard**. Arriver à 14h05 est en retard. En Espagne, arriver à 14h05 est ponctuel.

## Repas et table

| Pratique | Région | Note |
|---------|--------|------|
| Garder la main sur la table | France, Allemagne | Obligatoire |
| Mains sur les genoux | Anglo-saxon | Obligatoire |
| Manger avec la main droite uniquement | Inde, monde arabe | Strictement |
| Lever son verre en regardant dans les yeux | Allemagne (Prost!) | Obligatoire — sinon malheur |
| Finir son assiette | Chine, Japon | **Insulte au cuisinier** (signifie "il n'a pas assez donné") |
| Finir son assiette | Allemagne, Pays-Bas | **Politesse** |
| Roter en signe de satisfaction | Chine, Inde rurale | **Compliment** au cuisinier |
| Faire du bruit en mangeant nouilles | Japon | **Compliment** |
| Faire du bruit | Occident | Tabou |
| Pointer avec ses baguettes | Asie | Tabou |
| Planter ses baguettes verticalement | Chine, Japon | **Tabou — funéraire** |

## Cadeaux

| Région | Codes |
|--------|-------|
| Japon | Cadeau emballé soigneusement, offert et reçu à deux mains |
| Chine | Refuser 2-3 fois avant d'accepter ; ne pas ouvrir devant l'offreur |
| Monde arabe | Pas d'alcool, pas de viande de porc |
| Inde | Préférer cadeaux ne contenant pas de cuir (vache sacrée chez hindous) |
| Russie | Fleurs en nombre **impair** (pair = funérailles) |
| Occident | Ouvrir devant l'offreur en signe de gratitude |

## Habillement et présentation

| Région | Norme |
|--------|-------|
| Asie du Sud-Est | Pas de shorts dans temples, mosquées, pagodes |
| Monde arabe | Modeste — épaules et genoux couverts (femmes) |
| Iran | Hijab obligatoire pour femmes en public |
| Allemagne | Décontracté en informel, business strict en formel |
| Japon | Très soigné, costume sombre standard professionnel |

## Silences

| Région | Sens du silence |
|--------|----------------|
| Japon, Finlande | Silence naturel, pas inconfortable |
| France, USA | Silence à remplir, pause inconfortable |
| Méditerranée | Conversations chevauchées, peu de silences |
| Asie de l'Est | Silence = réflexion ou désaccord |

## Erreurs typiques à éviter

| Erreur | Conséquence |
|--------|------------|
| Pouce levé en Iran | Insulte grave |
| Toucher la tête d'un enfant en Thaïlande | Choque |
| Refuser le thé en Turquie | Affront |
| Tutoiement allemand sans avoir attendu | Choquant |
| Embrasser une femme arabe sur la joue | Inapproprié |
| Donner un cadeau de la main gauche en Inde | Insulte |
| Arriver "à l'heure" en Espagne | Trop tôt, met l'hôte en stress |
| Arriver "à l'heure latine" en Allemagne | Manque de respect |
| Sourire à un Russe inconnu | Bizarre, jugé "bête" |
| Faire le V (paume vers soi) au Royaume-Uni | Insulte vulgaire |

## Pour bien apprendre la communication non-verbale

| Stratégie | Détail |
|-----------|--------|
| **Observer avant d'agir** | Au début, regardez ce que font les natifs |
| **Demander aux locaux** | "Comment je devrais saluer ?" est toujours apprécié |
| **Vidéos en immersion** | Regarder des films / interviews en notant les gestes |
| **Chaînes YouTube** | "Easy German", "Easy Spanish", "Easy Languages" — inclut le gestuel |
| **Erreurs comme apprentissage** | Tout le monde fait des fauxpas — accepter et apprendre |
| **Voyage** | Rien ne remplace l'immersion réelle |
