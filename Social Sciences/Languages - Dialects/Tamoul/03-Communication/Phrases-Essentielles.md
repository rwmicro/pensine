# Phrases Essentielles — Tamoul

Phrases de survie en tamoul **parlé** (koccai tamiḻ), plus utile que le tamoul littéraire. Les deux versions sont données quand elles diffèrent significativement.

## Salutations

| Français | Tamoul (phonétique) | Tamoul script | Niveau |
|----------|---------------------|---------------|--------|
| Bonjour / Salut | Vaṇakkam | ==வணக்கம்::ta== | F — universel, matin comme soir |
| Bienvenue | Vāṅka | ==வாங்க::ta== | C — "entrez, venez" |
| Comment allez-vous ? | Eppaṭi irukkīrkaḷ? | ==எப்படி இருக்கீங்க::ta==? | F |
| Comment vas-tu ? | Eppaṭi irukka? | ==எப்படி இருக்க::ta==? | I |
| Je vais bien | Nallā irukkeṉ | ==நல்லா இருக்கேன்::ta== | C (parlé) |
| Oui | Ām | ==ஆம்::ta== | C |
| Non | Illai | ==இல்லை::ta== | C |
| Merci | Naṉṟi | ==நன்றி::ta== | C |
| Merci beaucoup | Mikka naṉṟi | ==மிக்க நன்றி::ta== | F |
| S'il vous plaît | Tayavu ceytu | ==தயவு செய்து::ta== | F |
| De rien / Pas grave | Paravāyillai | ==பரவாயில்லை::ta== | C |
| Excusez-moi | Maṉṉikkavum | ==மன்னிக்கவும்::ta== | F |
| Pardon (informel) | Cāri | ==சாரி::ta== | I (emprunt anglais) |
| Au revoir (temporaire) | Pōy vāreṉ | ==போய் வாரேன்::ta== | C — "je vais et reviens" |

## Se présenter

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Quel est votre nom ? | Uṅkaḷ peyar eṉṉa? | ==உங்கள் பெயர் என்ன::ta==? |
| Mon nom est... | Eṉ peyar ... | ==என் பெயர்::ta== ... |
| D'où venez-vous ? | Nīṅkaḷ eṅkiruntu varīrkaḷ? | ==நீங்க எங்கிருந்து வரீங்க::ta==? |
| Je viens de France | Nāṉ Pirāṉcil iruntu vantēṉ | ==நான் பிரான்சிலிருந்து வந்தேன்::ta== |
| J'apprends le tamoul | Nāṉ tamiḻ kaṟṟukiṟēṉ | ==நான் தமிழ் கற்றுக்கிறேன்::ta== |
| Je ne parle pas bien tamoul | Eṉakku tamiḻ sariyanā teriyātu | ==எனக்கு தமிழ் சரியா தெரியாது::ta== |

## Orientation

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Où est... ? | ... eṅkē? | ... ==எங்கே::ta==? |
| Comment aller à... ? | ... eppaṭi pōvatu? | ... ==எப்படி போவது::ta==? |
| À gauche | Iṭatu puramāka | ==இடது புரமாக::ta== |
| À droite | Valattu puramāka | ==வலது புரமாக::ta== |
| Tout droit | Nērē pōṅkaḷ | ==நேரே போங்கள்::ta== |
| C'est loin ? | Itu tūramā irukku? | ==இது தூரமா இருக்கு::ta==? |
