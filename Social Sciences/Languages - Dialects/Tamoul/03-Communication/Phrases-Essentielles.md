# Phrases Essentielles — Tamoul

Phrases de survie en tamoul **parlé** (koccai tamiḻ), plus utile que le tamoul littéraire. Les deux versions sont données quand elles diffèrent significativement.

## Salutations

| Français | Tamoul (phonétique) | Tamoul script | Niveau |
|----------|---------------------|---------------|--------|
| Bonjour / Salut | Vaṇakkam | வணக்கம் | F — universel, matin comme soir |
| Bienvenue | Vāṅka | வாங்க | C — "entrez, venez" |
| Comment allez-vous ? | Eppaṭi irukkīrkaḷ? | எப்படி இருக்கீங்க? | F |
| Comment vas-tu ? | Eppaṭi irukka? | எப்படி இருக்க? | I |
| Je vais bien | Nallā irukkeṉ | நல்லா இருக்கேன் | C (parlé) |
| Oui | Ām | ஆம் | C |
| Non | Illai | இல்லை | C |
| Merci | Naṉṟi | நன்றி | C |
| Merci beaucoup | Mikka naṉṟi | மிக்க நன்றி | F |
| S'il vous plaît | Tayavu ceytu | தயவு செய்து | F |
| De rien / Pas grave | Paravāyillai | பரவாயில்லை | C |
| Excusez-moi | Maṉṉikkavum | மன்னிக்கவும் | F |
| Pardon (informel) | Cāri | சாரி | I (emprunt anglais) |
| Au revoir (temporaire) | Pōy vāreṉ | போய் வாரேன் | C — "je vais et reviens" |

## Se présenter

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Quel est votre nom ? | Uṅkaḷ peyar eṉṉa? | உங்கள் பெயர் என்ன? |
| Mon nom est... | Eṉ peyar ... | என் பெயர் ... |
| D'où venez-vous ? | Nīṅkaḷ eṅkiruntu varīrkaḷ? | நீங்க எங்கிருந்து வரீங்க? |
| Je viens de France | Nāṉ Pirāṉcil iruntu vantēṉ | நான் பிரான்சிலிருந்து வந்தேன் |
| J'apprends le tamoul | Nāṉ tamiḻ kaṟṟukiṟēṉ | நான் தமிழ் கற்றுக்கிறேன் |
| Je ne parle pas bien tamoul | Eṉakku tamiḻ sariyanā teriyātu | எனக்கு தமிழ் சரியா தெரியாது |

## Communication

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Je ne comprends pas | Eṉakku puriyavillai | எனக்கு புரியவில்லை |
| Répétez s'il vous plaît | Mīṇṭum colluṅkaḷ | மீண்டும் சொல்லுங்கள் |
| Plus lentement | Metu metuvāka pēcuṅkaḷ | மெது மெதுவாக பேசுங்கள் |
| Qu'est-ce que ça veut dire ? | Itu eṉṉa artam? | இது என்ன அர்தம்? |
| Parlez-vous français ? | Nīṅkaḷ Pirāṉcu pēcuvīrkaḷā? | நீங்க பிரான்சு பேசுவீங்களா? |

## Orientation

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Où est... ? | ... eṅkē? | ... எங்கே? |
| Comment aller à... ? | ... eppaṭi pōvatu? | ... எப்படி போவது? |
| À gauche | Iṭatu puramāka | இடது புரமாக |
| À droite | Valattu puramāka | வலது புரமாக |
| Tout droit | Nērē pōṅkaḷ | நேரே போங்கள் |
| C'est loin ? | Itu tūramā irukku? | இது தூரமா இருக்கு? |

## Achats et restaurant

| Français | Tamoul (parlé) | Script |
|----------|----------------|--------|
| Combien ça coûte ? | Itu evvaḷavu? | இது எவ்வளவு? |
| Trop cher | Romba vilai ākiratu | ரொம்ப விலை ஆகிறது |
| Je voudrais... | Eṉakku ... vēṇum | எனக்கு ... வேணும் |
| Je suis végétarien(ne) | Nāṉ saiva āhāram sāpiṭuveṉ | நான் சைவ ஆகாரம் சாப்பிடுவேன் |
| Pas de piment | Miḷakāy potāmal | மிளகாய் போடாமல் |
| L'addition | Bil kōṅkaḷ | பில் கோங்கள் |
| Délicieux | Romba nalla irukkatu | ரொம்ப நல்லா இருக்கது |
