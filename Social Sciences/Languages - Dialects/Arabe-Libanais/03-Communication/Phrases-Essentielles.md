# Phrases Essentielles — Arabe Libanais

Translittération : `2` = ء/ق (coup de glotte), `3` = ع, `kh` = خ, `7` = ح, `sh` = ش, `gh` = غ. Emphatiques non distinguées en écriture.
Registres : **F** = formel / **C** = courant / **I** = informel
