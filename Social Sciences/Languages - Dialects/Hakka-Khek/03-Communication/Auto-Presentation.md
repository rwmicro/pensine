# How to Introduce Yourself in Hakka

## Example Introduction

### In Hakka:
```
Halo ngai miang Ali ☺
Ngai nyi sip nyi se (22), ngai Prancis bi hek.
Li ha ngai kuliah Paris e bi, tapi sangha ngai jiu co se.
Ngai sam (3) hiungthi. Ngai thi nyi lai ci.
Ngai jiu jit cak ako jit cak lo thai.
Ngai oi hok Bahasa khek.
Ngai an nyen sit Nasi Goreng Abu.
Nasi Goreng Abu an ho sit.
```

### English Translation:
```
Hello, my name is Ali ☺
I am 22 years old, I live in France.
Right now I study in Paris, but sometimes I work.
I have 3 siblings. I'm the second child.
I have one older brother and one younger brother.
I want to learn Hakka.
I like to eat Nasi Goreng Abu.
Nasi Goreng Abu is very good.
```

### French Translation:
```
Bonjour, je m'appelle Ali ☺
J'ai 22 ans, je vis en France.
En ce moment, j'étudie à Paris, mais parfois je travaille.
J'ai 3 frères et sœurs. Je suis le deuxième enfant.
J'ai un frère aîné et un frère cadet.
Je veux apprendre le Hakka.
J'aime manger du Nasi Goreng Abu.
Le Nasi Goreng Abu est très bon.
```

## Key Phrases for Introductions

| English                          | Hakka                    |
|----------------------------------|--------------------------|
| My name is...                    | Ngai miang...            |
| I am [age] years old             | Ngai [number] se         |
| I live in...                     | Ngai [place] bi hek      |
| Right now I...                   | Li ha ngai...            |
| I study in...                    | Ngai kuliah [place] e bi |
| Sometimes I...                   | Sangha ngai...           |
| I work                           | Ngai jiu co se           |
| I have [number] siblings         | Ngai [number] hiungthi   |
| I am the [ordinal] child         | Ngai thi [number] lai ci |
| I have                           | Ngai jiu                 |
| I want to learn...               | Ngai oi hok...           |
| I like to eat...                 | Ngai an nyen sit...      |
| [Food] is very good              | [Food] an ho sit         |

## Essential Vocabulary

### Personal Information
- **Ngai** = I/me
- **Nyi** = you
- **Miang** = name
- **Se** = years old
- **Bi hek** = live

### Time and Frequency
- **Li ha** = right now, at the moment
- **Sangha** = sometimes

### Family
- **Hiungthi** = siblings
- **Ako/Koko** = older brother
- **Lo thai** = younger brother
- **Thi** = (indicates ordinal position)
- **Lai ci** = child

### Actions
- **Kuliah** = study (at university)
- **Jiu co se** = work
- **Oi** = want
- **Hok** = learn
- **Nyen** = like
- **Sit** = eat

### Descriptions
- **An** = very
- **Ho sit** = good (for food)
- **An ho sit** = very good/delicious
