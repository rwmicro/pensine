# Transportation and Clothing

## Transportation

| English | Hakka    |
| ------- | -------- |
| Walking | hang lu  |
| Car     | hi cha   |
| Train   | fo cha   |
| Bike    | kiok cha |
| Plane   | fui ki   |
| Taxi    | taksi    |

| ----------------- | --------------------------- |

| Clothes (general) | sam-khu  衫褲                 |

## Related Verbs

| English | Hakka   |
|---------|---------|
| Walk    | hang lu |

## Notes

- **Cha** (車) = vehicle/car
- Many transportation words use **cha** as a suffix
- **Hang lu** = walk (literally "walk road")
