## Common Patterns

### Using "An" (Very)
- **An ho** = very good
- **An thai** = very big
- **An sau** = very hot
- **An fon hi** = very happy
- **An ciang** = very beautiful
- **An tuki** = very hungry

### Using "Thet" (Too/So)
- **Thet sau** = too hot
- **Sau to** = so hot

## Examples in Context
1. **Li kian su tiam an thai**
   - This bookstore is very big
1. **Nyi an ciang**
   - You are very beautiful
1. **An ho sit**
   - Very delicious
1. **Kinyit chit fun sau**
   - Today is very hot
1. **Li pun su an jiu ji si**
   - This book is very interesting
