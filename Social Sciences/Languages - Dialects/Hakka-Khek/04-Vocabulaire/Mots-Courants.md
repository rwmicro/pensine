# Common Words and Basic Vocabulary

**Dialect Note:** This vocabulary is primarily **West Kalimantan/Pontianak Indonesian Hakka [WK]**. See Resources/Regional-Dialects.md for detailed dialect information.

## Pronouns

| English        | Hakka                                   | Dialect Notes                          |
| -------------- | --------------------------------------- | -------------------------------------- |
| I / Me         | ngai                                    | [Universal] All dialects               |
| You (singular) | nyi [WK] / ngi                          | nyi more common in WK; both acceptable |
| He / She / It  | ki [WK] / khi                           | Regional variation                     |
| We             | ngai-tew-sa [WK] / nga ngin             | -tew-sa = plural marker                |
| Us             | tjhi'-ka / jhi ka                       | Regional variations                    |
| You (plural)   | nyi-tew-sa [WK]                         | nyi + plural marker                    |
| They           | ki-tew-sa [WK] / khi teu / khi teu ngin | Multiple forms used                    |

## Common Patterns

### Asking "Have you...?"
- **[Verb] + pau + mang?** = Have you [verb] yet?
- Example: **Sit pau mang?** = Have you eaten?

### Making Questions
- **[Statement] + mo?** = [Statement]?
- Example: **Nyi ho mo?** = Are you well?

### Saying "For you"
- **[Verb] + pun nyi** = [Verb] for you
- Example: **Mai pun nyi** = Buy for you

### Expressing "Very"
- **An + [adjective]** = very [adjective]
- Example: **An ho** = very good

## Examples in Context

1. **Ngai nyi phenjiu café e bi**
   - I met my friend at the café

2. **Li ha ngai buk kha**
   - Right now I'm at home

3. **Mak kai tu jiu**
   - Everything is available

4. **Ten jit ha**
   - Wait a minute

5. **Nyi nai bui?**
   - Where are you?
