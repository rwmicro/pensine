# Calendar and Time in Hakka

**Dialect Note:** This is **West Kalimantan/Pontianak Indonesian Hakka [WK]**. Calendar terms are generally universal across Hakka dialects.

## Days of the Week

| English   | Hakka    |
|-----------|----------|
| Monday    | Pai jit  |
| Tuesday   | Pai nyi  |
| Wednesday | Pai sam  |
| Thursday  | Pai si   |
| Friday    | Pai ng   |
| Saturday  | Pai liuk |
| Sunday    | Lipai    |

**Pattern:** Pai + number (1-6), except Sunday = Lipai

## Months of the Year

| Month | English   | Hakka         |
|-------|-----------|---------------|
| 1     | January   | jit nyiet     |
| 2     | February  | nyi nyiet     |
| 3     | March     | sam nyiet     |
| 4     | April     | si nyiet      |
| 5     | May       | ng nyiet      |
| 6     | June      | liuk nyiet    |
| 7     | July      | chit nyiet    |
| 8     | August    | pat nyiet     |
| 9     | September | kiu nyiet     |
| 10    | October   | sip nyiet     |
| 11    | November  | sip jit nyiet |
| 12    | December  | sip nyi nyiet |

**Pattern:** number + nyiet (month)

## Times of Day

| English          | Hakka     |
|------------------|-----------|
| Morning          | co        |
| Noon/Midday      | tong-ciu  |
| Afternoon        | ha-ciu    |
| Evening          | am        |
| Night            | am-pu     |
| Midnight         | pan-ja    |

## Time Expressions

| English                  | Hakka                      |
|--------------------------|----------------------------|
| Today                    | kinyit / kin-nyit / kin pu nyit |
| Yesterday                | chu punyit                 |
| Tomorrow                 | sau-co                     |
| Now / Right now          | li ha / kin-to / kin-ha    |
| Sometimes                | sangha                     |
| It is still morning      | an an co                   |
| It is already afternoon  | ciu liau                   |
| Return in the evening    | am con                     |
| Already (completed)      | ho liau / pau              |
| What time?               | kit to tiam                |
| At 3 o'clock             | sam tiam                   |
| At 8 pm                  | pat tiam am                |

## Notes

- **Tiam** can mean "time" or "o'clock" depending on context
- **Pau** = completed/accomplished/already
