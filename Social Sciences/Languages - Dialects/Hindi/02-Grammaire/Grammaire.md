# Grammaire Hindi

## Introduction

Le **hindi** (हिन्दी, *hindī*) est une langue indo-aryenne parlée par ~600 millions de locuteurs, principalement en Inde du Nord. C'est l'une des 22 langues officielles de l'Inde et la langue la plus parlée après le mandarin.

**Écriture :** [[Alphabet]] - **Devanagari** (देवनागरी)

**Caractéristiques :**
- Ordre des mots : **SOV** (Sujet-Objet-Verbe)
- Genre grammatical : Masculin/Féminin
- Système de cas : Postpositions
- Absence d'articles (le/la/un/une)

## Structure de la Phrase

### Ordre des Mots : SOV

| Français (SVO) | Hindi (SOV) | Translittération |
|---------------|------------|-----------------|
| **Je** mange une pomme | **मैं** सेब खाता हूँ | **Main** seb khātā hūn |
| Sujet + Verbe + Objet | Sujet + Objet + Verbe | S + O + V |

**Exemple détaillé :**
- **Français :** Marie **lit** un livre
- **Hindi :** मारिया किताब **पढ़ती** है
- **Translittération :** Māriyā kitāb **paṛhtī** hai
- **Structure :** Marie (S) + livre (O) + lit (V)

## Pronoms Personnels

### Pronoms Sujets

| Français | Hindi | Translittération | Prononciation |
|---------|-------|-----------------|--------------|
| Je | मैं | main | maïn |
| Tu (informel) | तू | tū | tou |
| Tu (formel) | तुम | tum | toum |
| Vous (très formel) | आप | āp | aap |
| Il/Elle (proche) | यह | yah | ya |
| Il/Elle (loin) | वह | vah | wo |
| Nous | हम | ham | ham |
| Vous (pluriel) | आप | āp | aap |
| Ils/Elles (proches) | ये | ye | yé |
| Ils/Elles (loin) | वे | ve | wé |

**Niveaux de politesse :**
- **तू (tū)** : Très informel, enfants, amis très proches (peut être insultant)
- **तुम (tum)** : Informel, amis, famille
- **आप (āp)** : Formel, politesse, personnes âgées, inconnus

### Pronoms Possessifs

| Français | Hindi (Masculin) | Hindi (Féminin) | Translittération M/F |
|---------|-----------------|----------------|---------------------|
| Mon/Ma | मेरा / मेरी | merā / merī |
| Ton/Ta (informel) | तेरा / तेरी | terā / terī |
| Ton/Ta (formel) | तुम्हारा / तुम्हारी | tumhārā / tumhārī |
| Votre | आपका / आपकी | āpkā / āpkī |
| Son/Sa (proche) | इसका / इसकी | iskā / iskī |
| Son/Sa (loin) | उसका / उसकी | uskā / uskī |
| Notre | हमारा / हमारी | hamārā / hamārī |

**Accord :**
- Le possessif s'accorde en **genre** et **nombre** avec l'objet possédé, pas le possesseur

**Exemple :**
- मेरा भाई (merā bhāī) = Mon frère (भाई masculin → मेरा)
- मेरी बहन (merī bahan) = Ma sœur (बहन féminin → मेरी)

## Genre Grammatical

Tous les noms en hindi sont soit **masculins**, soit **féminins** (pas de neutre).

### Règles Générales

#### Noms Masculins
**Terminaisons courantes :**
- **-ā** (आ) : लड़का (laṛkā, garçon), कमरा (kamrā, chambre)
- Consonnes : घर (ghar, maison), पानी (pānī, eau - exception)

#### Noms Féminins
**Terminaisons courantes :**
- **-ī** (ई) : लड़की (laṛkī, fille), रोटी (roṭī, pain)
- **-iyā** : चिड़िया (ciṛiyā, oiseau)
- Exceptions nombreuses : किताब (kitāb, livre - féminin)

**Attention :** Beaucoup d'exceptions, nécessite mémorisation.

## Nombre : Singulier et Pluriel

### Formation du Pluriel

#### Noms Masculins en -ā
- **Singulier -ā → Pluriel -e**
- लड़का (laṛkā, garçon) → लड़के (laṛke, garçons)
- कमरा (kamrā, chambre) → कमरे (kamre, chambres)

#### Noms Masculins (autres)
- **Invariables**
- घर (ghar, maison) → घर (ghar, maisons)
- आदमी (ādmī, homme) → आदमी (ādmī, hommes)

#### Noms Féminins
- **Singulier → Pluriel + -ēṁ** (souvent)
- लड़की (laṛkī, fille) → लड़कियाँ (laṛkiyāṁ, filles)
- रोटी (roṭī, pain) → रोटियाँ (roṭiyāṁ, pains)

## Système de Cas et Postpositions

Le hindi n'a **pas de prépositions** (comme "à", "de", "dans"), mais des **postpositions** (placées après le nom).

### Postpositions Courantes

| Français | Hindi | Exemple |
|---------|-------|---------|
| Dans | में (mẽ) | घर में (ghar mẽ, dans la maison) |
| Sur | पर (par) | मेज़ पर (mez par, sur la table) |
| De (depuis) | से (se) | दिल्ली से (Dillī se, de Delhi) |
| À (direction) | को (ko) | स्कूल को (skūl ko, à l'école) |
| Avec | के साथ (ke sāth) | मेरे साथ (mere sāth, avec moi) |
| Sans | के बिना (ke binā) | तुम्हारे बिना (tumhāre binā, sans toi) |
| Pour | के लिए (ke liye) | आपके लिए (āpke liye, pour vous) |

### Cas Oblique

Quand un nom est suivi d'une postposition, il prend la **forme oblique**.

**Masculins en -ā :**
- Singulier : लड़का (laṛkā) → Oblique : लड़के (laṛke)
- Pluriel : लड़के (laṛke) → Oblique : लड़कों (laṛkõ)

**Exemple :**
- लड़का (le garçon) → लड़के को (au garçon, laṛke ko)
- लड़के (les garçons) → लड़कों को (aux garçons, laṛkõ ko)

## Verbes

### Infinitif

**Formation :** Racine + **-nā** (ना)

| Hindi | Translittération | Français |
|-------|-----------------|----------|
| होना | honā | Être |
| खाना | khānā | Manger |
| पीना | pīnā | Boire |
| जाना | jānā | Aller |
| आना | ānā | Venir |
| करना | karnā | Faire |
| देखना | dekhnā | Voir |
| पढ़ना | paṛhnā | Lire/Étudier |
| बोलना | bolnā | Parler |
| सोना | sonā | Dormir |

### Présent Simple (Habituel)

**Structure :** Racine + Terminaison de genre/nombre + होना (auxiliaire)

#### Conjugaison de खाना (khānā, manger)

**Masculin :**

| Pronom | Forme | Translittération |
|--------|-------|-----------------|
| मैं (je) | खाता हूँ | khātā hūṁ |
| तुम (tu) | खाता हो | khātā ho |
| आप (vous) | खाते हैं | khāte haĩ |
| वह (il) | खाता है | khātā hai |
| हम (nous) | खाते हैं | khāte haĩ |
| वे (ils) | खाते हैं | khāte haĩ |

**Féminin :**

| Pronom | Forme | Translittération |
|--------|-------|-----------------|
| मैं (je) | खाती हूँ | khātī hūṁ |
| तुम (tu) | खाती हो | khātī ho |
| आप (vous) | खाती हैं | khātī haĩ |
| वह (elle) | खाती है | khātī hai |
| हम (nous) | खाती हैं | khātī haĩ |
| वे (elles) | खाती हैं | khātī haĩ |

**Terminaisons :**
- Masculin singulier : **-tā** (ता)
- Masculin pluriel : **-te** (ते)
- Féminin : **-tī** (ती)

### Présent Progressif (En train de)

**Structure :** Racine + रहा/रही/रहे (rahā/rahī/rahe) + होना

**Exemple avec खाना (manger) :**
- मैं खा रहा हूँ (main khā rahā hūṁ) = Je suis en train de manger (masculin)
- मैं खा रही हूँ (main khā rahī hūṁ) = Je suis en train de manger (féminin)

### Passé Simple

**Structure :** Racine + **-ā/-ī/-e** (selon genre/nombre)

**Exemple avec जाना (jānā, aller) :**

| Sujet | Masculin | Féminin |
|-------|----------|---------|
| मैं (je) | गया (gayā) | गई (gaī) |
| तुम (tu) | गया (gayā) | गई (gaī) |
| वह (il/elle) | गया (gayā) | गई (gaī) |
| हम (nous) | गए (gae) | गईं (gaīṁ) |
| वे (ils/elles) | गए (gae) | गईं (gaīṁ) |

**Accord :** Le verbe s'accorde en genre et nombre avec le **sujet** si le verbe est **intransitif**.

### Futur

**Structure :** Racine + **-ūṅgā/-ūṅgī/-oge/-egī** (selon pronom et genre)

**Exemple avec जाना (aller) :**

| Pronom | Masculin | Féminin |
|--------|----------|---------|
| मैं | जाऊँगा (jāūṅgā) | जाऊँगी (jāūṅgī) |
| तुम | जाओगे (jāoge) | जाओगी (jāogī) |
| आप | जाएँगे (jāeṅge) | जाएँगी (jāeṅgī) |
| वह | जाएगा (jāegā) | जाएगी (jāegī) |
| हम | जाएँगे (jāeṅge) | जाएँगी (jāeṅgī) |
| वे | जाएँगे (jāeṅge) | जाएँगी (jāeṅgī) |

## Le Verbe Être (होना - honā)

### Présent

| Français | Hindi | Translittération |
|---------|-------|-----------------|
| Je suis | मैं हूँ | main hūṁ |
| Tu es (informel) | तू है | tū hai |
| Tu es (formel) | तुम हो | tum ho |
| Vous êtes | आप हैं | āp haĩ |
| Il/Elle est | वह है | vah hai |
| Nous sommes | हम हैं | ham haĩ |
| Ils/Elles sont | वे हैं | ve haĩ |

**Usage :**
- मैं छात्र हूँ (main chātra hūṁ) = Je suis étudiant
- यह किताब है (yah kitāb hai) = Ceci est un livre

### Passé

| Français | Hindi (M) | Hindi (F) | Translittération M/F |
|---------|----------|----------|---------------------|
| J'étais | मैं था | मैं थी | main thā / main thī |
| Tu étais | तू था | तू थी | tū thā / tū thī |
| Il/Elle était | वह था | वह थी | vah thā / vah thī |
| Nous étions | हम थे | हम थीं | ham the / ham thīṁ |

## Questions

### Formation des Questions

**Particule interrogative :** क्या (kyā) au début de la phrase

**Exemple :**
- **Affirmation :** तुम छात्र हो (tum chātra ho) = Tu es étudiant
- **Question :** क्या तुम छात्र हो? (kyā tum chātra ho?) = Es-tu étudiant ?

### Mots Interrogatifs

| Français | Hindi | Translittération |
|---------|-------|-----------------|
| Qui ? | कौन? | kaun? |
| Quoi ? | क्या? | kyā? |
| Où ? | कहाँ? | kahāṁ? |
| Quand ? | कब? | kab? |
| Pourquoi ? | क्यों? | kyõ? |
| Comment ? | कैसे? | kaise? |
| Combien ? | कितना? | kitnā? |
| Quel/Quelle ? | कौन सा? | kaun sā? |

**Exemples :**
- तुम कहाँ हो? (tum kahāṁ ho?) = Où es-tu ?
- यह क्या है? (yah kyā hai?) = Qu'est-ce que c'est ?
- तुम कैसे हो? (tum kaise ho?) = Comment vas-tu ?

## Négation

**Particule de négation :** नहीं (nahīṁ)

**Placement :** Avant le verbe

**Exemples :**
- मैं **नहीं** जाता (main **nahīṁ** jātā) = Je ne vais pas
- यह किताब **नहीं** है (yah kitāb **nahīṁ** hai) = Ce n'est pas un livre
- मैं हिंदी **नहीं** बोलता (main hindī **nahīṁ** boltā) = Je ne parle pas hindi

## Adjectifs

### Accord des Adjectifs

Les adjectifs s'accordent en **genre**, **nombre** et **cas** avec le nom.

**Adjectifs variables (terminaison -ā) :**

| | Masculin Singulier | Masculin Pluriel | Féminin (S+P) |
|-|-------------------|-----------------|--------------|
| **Beau** | सुंदर (sundar) - invariable | | |
| **Grand** | बड़ा (baṛā) | बड़े (baṛe) | बड़ी (baṛī) |
| **Petit** | छोटा (choṭā) | छोटे (choṭe) | छोटी (choṭī) |
| **Bon** | अच्छा (acchā) | अच्छे (acche) | अच्छी (acchī) |

**Exemple :**
- बड़ा घर (baṛā ghar) = Grande maison (masculin)
- बड़ी किताब (baṛī kitāb) = Grand livre (féminin)
- बड़े घर (baṛe ghar) = Grandes maisons (masculin pluriel)

**Adjectifs invariables :**
- सुंदर (sundar, beau/belle) : Même forme pour tous
- खुश (khush, heureux/heureuse)

### Placement
**Généralement AVANT le nom** (comme en français)
- अच्छा लड़का (acchā laṛkā) = Bon garçon

## Comparatifs et Superlatifs

### Comparatif

**Structure :** X, Y **से** (se) + Adjectif + है (hai)

**Exemple :**
- राम श्याम **से** बड़ा है (Rām Shyām **se** baṛā hai)
- = Ram est plus grand **que** Shyam

### Superlatif

**Structure :** सबसे (sabse, "de tous") + Adjectif

**Exemple :**
- राम सबसे बड़ा है (Rām sabse baṛā hai) = Ram est le plus grand
