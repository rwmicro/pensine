# Phrases Essentielles — Hindi

Phrases de survie en hindi courant (parlé). Translittération simplifiée.

## Salutations

| Français | Hindi | Translittération | Niveau |
|----------|-------|-----------------|--------|
| Bonjour / Namaste | ==नमस्ते::hi== | Namaste | F/C — universel, intemporel |
| Bonjour (religieux, salut) | ==सलाम::hi== | Salām | Milieux musulmans |
| Comment allez-vous ? | ==आप कैसे हैं::hi==? | Āp kaise haĩ? | F |
| Comment vas-tu ? | ==तुम कैसे हो::hi==? | Tum kaise ho? | C |
| Je vais bien | ==मैं ठीक हूँ::hi== | Main ṭhīk hūṁ | C |
| Très bien, merci | ==बहुत अच्छा::hi==, ==शुक्रिया::hi== | Bahut acchā, shukriyā | C |
| Au revoir | ==नमस्ते::hi== / ==फिर मिलेंगे::hi== | Namaste / Phir mileṅge | C |
| Bonne nuit | ==शुभ रात्रि::hi== | Shubh rātri | F |
| Oui | ==हाँ::hi== / ==जी हाँ::hi== | Hāṁ / Jī hāṁ | C / F |
| Non | ==नहीं::hi== / ==जी नहीं::hi== | Nahīṁ / Jī nahīṁ | C / F |
| Merci | ==शुक्रिया::hi== / ==धन्यवाद::hi== | Shukriyā / Dhanyavād | C / F |
| S'il vous plaît | ==कृपया::hi== | Kripayā | F |
| De rien | ==कोई बात नहीं::hi== | Koī bāt nahīṁ | C |
| Excusez-moi | ==माफ़ कीजिए::hi== | Māf kījie | F |
| Pardon | ==माफ़ करना::hi== | Māf karnā | C |
