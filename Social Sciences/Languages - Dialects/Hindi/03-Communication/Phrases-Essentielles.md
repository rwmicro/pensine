# Phrases Essentielles — Hindi

Phrases de survie en hindi courant (parlé). Translittération simplifiée.

## Salutations

| Français | Hindi | Translittération | Niveau |
|----------|-------|-----------------|--------|
| Bonjour / Namaste | नमस्ते | Namaste | F/C — universel, intemporel |
| Bonjour (religieux, salut) | सलाम | Salām | Milieux musulmans |
| Comment allez-vous ? | आप कैसे हैं? | Āp kaise haĩ? | F |
| Comment vas-tu ? | तुम कैसे हो? | Tum kaise ho? | C |
| Je vais bien | मैं ठीक हूँ | Main ṭhīk hūṁ | C |
| Très bien, merci | बहुत अच्छा, शुक्रिया | Bahut acchā, shukriyā | C |
| Au revoir | नमस्ते / फिर मिलेंगे | Namaste / Phir mileṅge | C |
| Bonne nuit | शुभ रात्रि | Shubh rātri | F |
| Oui | हाँ / जी हाँ | Hāṁ / Jī hāṁ | C / F |
| Non | नहीं / जी नहीं | Nahīṁ / Jī nahīṁ | C / F |
| Merci | शुक्रिया / धन्यवाद | Shukriyā / Dhanyavād | C / F |
| S'il vous plaît | कृपया | Kripayā | F |
| De rien | कोई बात नहीं | Koī bāt nahīṁ | C |
| Excusez-moi | माफ़ कीजिए | Māf kījie | F |
| Pardon | माफ़ करना | Māf karnā | C |
