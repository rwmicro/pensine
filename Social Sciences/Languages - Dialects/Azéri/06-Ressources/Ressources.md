## Parcours recommandé

```
Phase 1 — Phonologie et alphabet (2 semaines)
  → Maîtriser Ə, Ğ, X, I/İ, Ö, Ü
  → Harmonie vocalique : règle simple mais à automatiser
  → Écoute de sons natifs (Forvo, YouTube)

Phase 2 — Grammaire de base (2 mois)
  → Pronoms personnels
  → Suffixes de possession
  → Cas : nominatif, locatif, datif, ablatif
  → Présent progressif (-ir), passé (-dı), futur (-acaq)

Phase 3 — Vocabulaire + phrases (3 mois)
  → 500 mots les plus fréquents
  → Manuel Peace Corps + Dilmara
  → Phrases-clés par situation

Phase 4 — Immersion (6 mois+)
  → Radio Azadlıq ou BBC Azerbaijani (actualités clairs)
  → Séries azéries avec sous-titres azéris
  → italki — conversation hebdomadaire
  → Lecture de journaux (Azadlıq, Trend)

Phase 5 — Perfection (1 an+)
  → Passer à l'azéri d'Iran (écriture perso-arabe) si intérêt pour la diaspora
  → Lecture littéraire (Nizami, Fuzuli)
  → Variantes régionales (Karabakh, Nakhichevan)
```

## Atout de la proximité turque

Un apprenant du turc gagne environ **60–70 % du chemin** pour l'azéri. Les différences principales sont :

| Aspect | Détail |
|--------|--------|
| Alphabet | Azéri a Ə, Q, X — Turc n'en a pas |
| Sons | Azéri /æ/ (Ə), /x/, /ɡ/ (Q) — Turc ne les a pas |
| Lexique | ~15 % de vocabulaire spécifique à l'azéri (emprunts russes, persans) |
| Syntaxe | Très proche — SOV, agglutination, harmonie vocalique identique |

Inversement, un apprenant de l'azéri a accès au turc avec un effort modéré.
