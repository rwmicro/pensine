# Salutations — Azéri

## Salutations de base

| Azéri | Sens | Usage |
|-------|------|-------|
| ==Salam::az== | Salut / Bonjour | Universel — toute la journée |
| ==Salam əleyküm::az== | Paix sur toi | Formel / religieux |
| ==Əleyküm salam::az== | Paix sur toi aussi | Réponse à *salam əleyküm* |
| ==Sabahınız xeyir::az== | Bonjour (matin) | Formel, matin |
| ==Sabah xeyir::az== | Bonjour (matin) | Informel |
| ==Günortanız xeyir::az== | Bon après-midi | Formel, midi |
| ==Axşamınız xeyir::az== | Bonsoir | Formel, soir |
| ==Gecəniz xeyir::az== | Bonne nuit | Formel |
| ==Gecən xeyrə::az== | Bonne nuit | Informel |

> **Salam** est utilisé partout — entre amis, inconnus, à l'arrêt de bus, au marché, au bureau. C'est la salutation par défaut.

## Salutation islamique

L'Azerbaïdjan est à majorité musulmane (chiite ~85 %, sunnite ~15 %) mais laïc. Le *salam əleyküm* arabe coexiste avec le *salam* courant.

| Formule | Réponse | Contexte |
|---------|---------|---------|
| Salam əleyküm | Əleyküm salam | Religieux, formel, générations âgées |
| Salam | Salam | Séculier, universel |

## Tu vs Vous — sən vs siz

| Pronom | Usage | Verbe |
|--------|-------|-------|
| sən | Amis, famille, enfants | *necəsən?* |
| siz | Inconnus, âgés, supérieurs (et pluriel) | *necəsiniz?* |

## Politesse — remerciements

| Azéri | Sens | Niveau |
|-------|------|--------|
| ==Sağ olun::az== | Merci | Formel (litt. "soyez sain") |
| ==Sağ ol::az== | Merci | Informel |
| ==Çox sağ olun::az== | Merci beaucoup | Formel emphatique |
| ==Təşəkkür edirəm::az== | Je remercie | Formel, plus élaboré |
| ==Dəyməz::az== | De rien | Courant |
| ==Buyurun::az== | De rien / Je vous en prie / Tenez | Très polyvalent |
| ==Xahiş edirəm::az== | S'il vous plaît / Je vous prie | Formel |
| ==Bağışlayın::az== | Excusez-moi / Pardon | Formel |
| ==Üzr istəyirəm::az== | Je suis désolé | Formel |

> **Buyurun** est un mot-clé de la politesse azérie. Il sert à inviter à entrer, tendre un objet, céder la parole, proposer quelque chose.

## Hospitalité — formules essentielles

L'hospitalité est une valeur cardinale en Azerbaïdjan. Refuser l'invitation est perçu comme une offense.

| Azéri | Sens |
|-------|------|
| ==Xoş gəlmisiniz::az== | Bienvenue (formel) |
| ==Xoş gəldin::az== | Bienvenue (informel) |
| ==Xoş gördük::az== | Ravi de vous voir (réponse à *xoş gəlmisiniz*) |
| ==Keçin::az== | Entrez / Passez |
| ==Əyləşin::az== | Asseyez-vous |
| ==Çay içərsiniz?::az== | Vous prendrez du thé ? |
| ==Nuş olsun::az== | Bon appétit (avant / après manger) |
| ==Yeməyiniz yağlı olsun::az== | Que votre repas soit "gras" (= bon appétit traditionnel) |
| ==Əllərinizə sağlıq::az== | "Santé à vos mains" — compliment au cuisinier |
