# Grammaire — Azéri

## Caractéristiques générales

L'azéri est une langue **agglutinante** : on empile les suffixes sur une racine pour exprimer grammaire et sens. C'est l'inverse du français qui utilise des mots séparés et des auxiliaires.

| Caractéristique | Détail |
|----------------|--------|
| Ordre des mots | SOV (sujet–objet–verbe) : *Mən kitab oxuyuram* — "Je livre lis" |
| Pas de genre grammatical | Masculin/féminin indifférencié — *o* = il / elle / ça |
| Pas d'articles | *kitab* = "un livre" ou "le livre" selon contexte |
| Agglutination | Suffixes empilés : **ev-lər-im-də** = *ev* (maison) + *lər* (pluriel) + *im* (mon) + *də* (à/dans) |
| Harmonie vocalique | Voyelles des suffixes accordées avec la racine |

> Comme en français, le *siz* sert à la fois de vouvoiement singulier et de pluriel. Le *sən* est réservé aux amis, à la famille, aux enfants et animaux.

## Cas nominal — 6 cas

L'azéri marque la fonction du nom par des suffixes de cas, avec harmonie vocalique.

| Cas | Suffixe | Fonction | Exemple |
|-----|---------|---------|---------|
| Nominatif | — (rien) | Sujet | **ev** — une maison |
| Génitif | -ın / -in / -un / -ün | Possession | **evin** — de la maison |
| Datif | -a / -ə | Direction | **evə** — à/vers la maison |
| Accusatif | -ı / -i / -u / -ü | Objet défini | **evi** — la maison (COD) |
| Locatif | -da / -də | Lieu | **evdə** — dans la maison |
| Ablatif | -dan / -dən | Provenance | **evdən** — de la maison |

## Possession — suffixes possessifs

L'azéri exprime la possession par un **suffixe sur l'objet possédé**, pas par un pronom à part.

| Personne | Suffixe | Exemple (*ev* = maison) |
|----------|---------|------------------------|
| Mon | -im / -ım / -um / -üm | **evim** — ma maison |
| Ton | -in / -ın / -un / -ün | **evin** — ta maison |
| Son | -i / -ı / -u / -ü | **evi** — sa maison |
| Notre | -imiz / -ımız / -umuz / -ümüz | **evimiz** — notre maison |
| Votre | -iniz / -ınız / -unuz / -ünüz | **eviniz** — votre maison |
| Leur | -ləri / -ları | **evləri** — leur maison |

## Verbe *être* — suffixes prédicatifs

L'azéri n'a pas de verbe "être" autonome. La copule est exprimée par des suffixes.

| Personne | Suffixe | Exemple |
|----------|---------|---------|
| Je suis | -am / -əm | **tələbəyəm** — je suis étudiant |
| Tu es | -san / -sən | **tələbəsən** — tu es étudiant |
| Il est | -dır / -dir / -dur / -dür | **tələbədir** — il est étudiant |
| Nous sommes | -ıq / -ik / -uq / -ük | **tələbəyik** — nous sommes étudiants |
| Vous êtes | -sınız / -siniz / -sunuz / -sünüz | **tələbəsiniz** — vous êtes étudiants |
| Ils sont | -dırlar / -dirlər | **tələbədirlər** — ils sont étudiants |

> Le suffixe de la 3ᵉ personne (*-dır/-dir*) est souvent omis dans la langue parlée : *O, tələbə.* (Il est étudiant.)

## Négation verbale — -ma / -mə

Le suffixe négatif s'insère entre la racine et les suffixes de temps.

| Positif | Négatif | Sens |
|---------|---------|------|
| gəlirəm | gəl**mir**əm | je ne viens pas |
| gördüm | gör**mə**dim | je n'ai pas vu |
| yazacaq | yaz**ma**yacaq | il n'écrira pas |

## Pluriel — -lar / -lər

Règle unique : *-lar* après voyelle postérieure, *-lər* après voyelle antérieure.

| Singulier | Pluriel | Sens |
|-----------|---------|------|
| kitab | kitablar | livres |
| ev | evlər | maisons |
| uşaq | uşaqlar | enfants |
| gül | güllər | fleurs |

> Quand le nom est précédé d'un nombre, le pluriel est généralement omis : *üç kitab* (trois livres), pas *üç kitablar*.

## Postpositions (pas de prépositions)

L'azéri utilise des **postpositions** (après le nom) là où le français a des prépositions.

| Postposition | Sens | Exemple |
|--------------|------|---------|
| ilə | avec | Dostum **ilə** — avec mon ami |
| üçün | pour | Sənin **üçün** — pour toi |
| kimi | comme | Sənin **kimi** — comme toi |
| qədər | jusqu'à | Sabaha **qədər** — jusqu'à demain |
| sonra | après | Dərsdən **sonra** — après le cours |
| əvvəl | avant | Dərsdən **əvvəl** — avant le cours |
