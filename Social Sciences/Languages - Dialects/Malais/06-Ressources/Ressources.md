### Stratégie films
1. Activer sous-titres en malais (bukan français) — lire pendant l'écoute
2. Repérer les particules **lah**, **mah**, **kan** dans les dialogues
3. Revenir sur les scènes avec Manglish — noter les emprunts anglais

## Parcours recommandé

```
Débutant (0–3 mois)
  → Alphabet + prononciation (toutes les lettres sonnent comme elles s'écrivent)
  → Vocabulaire de base (MalayPod101 + Ling)
  → Phrases-clés (salutations, nombres, couleurs, famille)

Intermédiaire (3–9 mois)
  → Système des affixes (meN-, di-, ber-, -kan, -an)
  → Classificateurs numéraux
  → Dialogues du quotidien (Situations.md)
  → Écoute active : RTM, Hot FM

Avancé (9 mois+)
  → Manglish et particules (lah, mah, kan, lor)
  → Films sans sous-titres
  → Lecture de journaux (Berita Harian, Utusan)
  → Conversation avec locuteurs natifs (italki, Discord)
```
