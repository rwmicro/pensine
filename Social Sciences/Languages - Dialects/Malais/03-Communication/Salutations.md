# Salutations — Bahasa Malaysia

## Système Selamat

Le système **Selamat** (litt. "paix / sécurité") est la base des salutations formelles malaisiennes.

| Salutation | Sens | Usage |
|-----------|------|-------|
| Selamat pagi | Bonjour (matin) | Jusqu'à 12h |
| Selamat tengah hari | Bonjour (milieu de journée) | 12h-14h environ |
| Selamat petang | Bonsoir (après-midi) | 14h-18h |
| Selamat malam | Bonne nuit / Bonsoir | Après 18h |
| Selamat datang | Bienvenue | Accueil |
| Selamat jalan | Au revoir (à celui qui part) | litt. "bonne route" |
| Selamat tinggal | Au revoir (à celui qui reste) | litt. "bon séjour" |
| Selamat hari jadi | Joyeux anniversaire | — |
| Selamat berjaya | Bonne chance / succès | Avant un examen, projet |

## Salutation islamique — obligatoire en contexte malais

La grande majorité des Malais (Melayu) sont musulmans. Le salam islamique est la salutation par défaut dans tous les contextes professionnels et formels.

| Salutation | Réponse |
|-----------|---------|
| Assalamualaikum | Waalaikumsalam |
| (Que la paix soit sur vous) | (Et sur vous la paix) |

> Ne pas répondre à un salam peut être perçu comme un manque de respect. Les non-musulmans peuvent répondre en malais standard ou simplement par "Waalaikumsalam".

## Échange rituel — Comment vas-tu ?

| Question | Sens |
|---------|------|
| Apa khabar? | Comment vas-tu ? (universel) |
| Bagaimana keadaan awak? | Comment allez-vous ? (formel) |
| Dah makan? | Tu as mangé ? (affectionnel, informel) |
| Sihat? | Tu vas bien ? (lit. "en santé ?") |

| Réponse | Sens |
|---------|------|
| Khabar baik, terima kasih | Bien, merci |
| Baik-baik saja | Bien, juste bien |
| Alhamdulillah, sihat | Dieu merci, en bonne santé |
| Boleh tahan | Comme ci comme ça (lit. "peut tenir") |
| Tak terlalu baik | Pas très bien |

## Particules de politesse

| Particule | Usage | Note |
|---------|-------|------|
| lah | Adoucit une affirmation | "OK lah." (d'accord) |
| mah | Évidence, explication | "Dia tak tahu mah." (Il sait pas, évidemment) |
| kan | Recherche d'accord | "Cantik kan?" (C'est beau, non ?) |
| lor | Résignation légère | "Terpaksa lor." (Faut bien.) |
| hor | Confirmation attendue | "Besok kita jumpa, hor?" (On se voit demain, hein ?) |

## Adresses — appeler quelqu'un

Le malais utilise des termes d'adresse différents selon l'âge et le statut :

| Terme | Usage |
|-------|-------|
| Encik (M.) / Puan (Mme.) | Adulte formel (équivalent Mr/Mrs) |
| Tuan / Puan | Très formel (lettres, administrations) |
| Abang (bang) | Homme légèrement plus âgé — affectif |
| Kakak (kak) | Femme légèrement plus âgée — affectif |
| Adik | Plus jeune (frère/sœur cadet) |
| Pak / Mak | Père / Mère — aussi pour personnes d'âge |
| Datuk / Datin | Personne très âgée ou titrée |
