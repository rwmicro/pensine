# Phrases Essentielles — Malais (Bahasa Melayu)

Le malais standard (Bahasa Melayu) est très proche de l'indonésien — un locuteur de l'un comprend largement l'autre. Les différences notables sont signalées.

## Salutations

| Français | Malais | Indonésien (comparaison) | Niveau |
|----------|--------|--------------------------|--------|
| Bonjour | ==Selamat pagi::ms== / ==tengah hari::ms== / ==petang::ms== / ==malam::ms== | Identique | C |
| Salut | ==Hai::ms== / ==Helo::ms== | Identique | I |
| Comment allez-vous ? | ==Apa khabar?::ms== | Apa kabar? | C |
| Bien, merci | ==Khabar baik, terima kasih::ms== | Kabar baik, terima kasih | C |
| Au revoir | ==Selamat tinggal::ms== / ==Selamat jalan::ms== | Identique | C |
| Bonne nuit | ==Selamat malam::ms== | Identique | C |
| Oui | ==Ya::ms== / ==Ye::ms== | Ya / Iya | C |
| Non | ==Tidak::ms== / ==Tak::ms== | Tidak / Nggak | C |
| Merci | ==Terima kasih::ms== | Identique | C |
| Merci (informel) | ==Terima kasih::ms== / ==Tq::ms== | Makasih | I |
| S'il vous plaît | ==Tolong::ms== / ==Sila::ms== | Tolong / Silakan | C/F |
| De rien | ==Sama-sama::ms== / ==Tak mengapa::ms== | Sama-sama | C |
| Pardon | ==Maaf::ms== | Maaf | C |
| Excusez-moi | ==Maafkan saya::ms== / ==Tumpang lalu::ms== | Permisi | F/C |
