# Phrases Essentielles — Malais (Bahasa Melayu)

Le malais standard (Bahasa Melayu) est très proche de l'indonésien — un locuteur de l'un comprend largement l'autre. Les différences notables sont signalées.

## Salutations

| Français | Malais | Indonésien (comparaison) | Niveau |
|----------|--------|--------------------------|--------|
| Bonjour | Selamat pagi/tengah hari/petang/malam | Identique | C |
| Salut | Hai / Helo | Identique | I |
| Comment allez-vous ? | Apa khabar? | Apa kabar? | C |
| Bien, merci | Khabar baik, terima kasih | Kabar baik, terima kasih | C |
| Au revoir | Selamat tinggal / Selamat jalan | Identique | C |
| Bonne nuit | Selamat malam | Identique | C |
| Oui | Ya / Ye | Ya / Iya | C |
| Non | Tidak / Tak | Tidak / Nggak | C |
| Merci | Terima kasih | Identique | C |
| Merci (informel) | Terima kasih / Tq (SMS) | Makasih | I |
| S'il vous plaît | Tolong / Sila | Tolong / Silakan | C/F |
| De rien | Sama-sama / Tak mengapa | Sama-sama | C |
| Pardon | Maaf | Maaf | C |
| Excusez-moi | Maafkan saya / Tumpang lalu | Permisi | F/C |

## Se présenter

| Français | Malais |
|----------|--------|
| Je m'appelle... | Nama saya ... |
| Quel est votre nom ? | Siapa nama awak? / Nama anda siapa? |
| D'où venez-vous ? | Awak dari mana? |
| Je viens de France | Saya dari Perancis |
| J'apprends le malais | Saya sedang belajar bahasa Melayu |
| Je parle un peu malais | Saya boleh cakap sikit bahasa Melayu |

## Communication

| Français | Malais |
|----------|--------|
| Je ne comprends pas | Saya tidak faham |
| Répétez s'il vous plaît | Tolong ulang semula |
| Plus lentement | Tolong cakap perlahan sikit |
| Qu'est-ce que ça veut dire ? | Apa maksudnya? |
| Parlez-vous français ? | Awak boleh cakap Perancis? |
