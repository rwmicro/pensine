# Salutations — Espagnol

## Salutations de base

| Espagnol | Sens | Usage |
|----------|------|-------|
| Hola | Salut / Bonjour | Universel, toute la journée |
| Buenos días | Bonjour (matin) | Jusqu'à midi environ |
| Buenas tardes | Bonjour / Bon après-midi | Midi–19h |
| Buenas noches | Bonsoir / Bonne nuit | Après 19h (salut + départ) |
| Buenas | Salut (abrégé) | Informel, universel |
| ¿Qué tal? | Quoi de neuf ? / Comment ça va ? | Informel, courant |

> **Hola** est le salut universel. **Buenos días / buenas tardes / buenas noches** peuvent s'ajouter pour plus de politesse. Au pluriel en espagnol, pas au singulier !

## Tu vs Vous — *tú* vs *usted*

| Pronom | Usage | Verbe |
|--------|-------|-------|
| tú | Amis, famille, jeunes, contexte informel | *¿cómo estás?* |
| usted | Inconnus, supérieurs, personnes âgées, contexte professionnel | *¿cómo está?* |
| vosotros | Pluriel informel (Espagne uniquement) | *¿cómo estáis?* |
| ustedes | Pluriel formel et informel (Amérique latine) | *¿cómo están?* |

### Tutoiement selon les cultures

| Région | Usage de *tú* |
|--------|--------------|
| Espagne | Tutoiement rapide, même avec inconnus jeunes |
| Mexique | Plus formel — *usted* plus fréquent |
| Colombie | *Usted* très courant, même en famille |
| Argentine | *Vos* — registre informel unique (voseo) |
| Chili | *Tú* standard, *usted* formel |

## Échange rituel — Comment vas-tu ?

| Espagnol | Sens | Registre |
|----------|------|---------|
| ¿Cómo estás? | Comment vas-tu ? | Informel |
| ¿Cómo está usted? | Comment allez-vous ? | Formel |
| ¿Qué tal? | Ça va ? | Courant |
| ¿Cómo te va? | Comment ça va pour toi ? | Informel, Amérique |
| ¿Qué pasa? | Quoi de neuf ? | Très informel |
| ¿Qué onda? | Quoi de neuf ? | Mexique, argot jeune |

| Réponse | Sens |

| Bien, gracias | Bien, merci |
| Muy bien | Très bien |
| Bien, ¿y tú? / ¿y usted? | Bien, et toi ? / et vous ? |
| Más o menos | Comme ci comme ça |

| Regular | Moyen |
| No muy bien | Pas très bien |
