# Grammaire — Mandarin

## Caractéristiques générales

La grammaire mandarine est radicalement différente des langues européennes. Elle est **isolante** (chaque mot reste invariable) et **analytique** (la grammaire passe par l'ordre des mots et des particules).

| Caractéristique | Détail |
|----------------|--------|
| Ordre des mots | SVO — sujet-verbe-objet |
| Pas de conjugaison | Le verbe ne change jamais — peu importe le temps, la personne, le nombre |
| Pas de pluriel | Le nom ne change jamais — un livre / des livres = même mot |
| Pas de genre | Aucun genre grammatical |
| Pas d'articles | Pas de "le/la/les", pas de "un/une" |
| Particules grammaticales | Marquent aspect, mode, fonction |
| Classificateurs obligatoires | Entre nombre et nom : *yí gè rén* (une [classif.] personne) |
| Tête finale | Modificateurs avant ce qu'ils modifient |

## Pronoms personnels

| Français | Mandarin (caractère) | Pinyin |
|----------|---------------------|--------|
| Je / moi | ==我::zh== | wǒ |
| Tu / toi | ==你::zh== | nǐ |
| Vous (formel sg.) | ==您::zh== | nín |
| Il / elle | ==他::zh== / ==她::zh== | tā / tā (prononcé pareil) |
| Ça / cela | ==它::zh== | tā |
| Nous (inclusif) | ==咱们::zh== | zánmen |
| Nous (exclusif) | ==我们::zh== | wǒmen |
| Vous (pluriel) | ==你们::zh== | nǐmen |
| Ils / elles | ==他们::zh== / ==她们::zh== | tāmen |

> Le suffixe **们 (men)** marque le pluriel **uniquement pour les pronoms et les humains** : *wǒmen* (nous), *péngyoumen* (les amis). On ne dit pas *shūmen* pour "des livres".

## Structure de phrase de base

| Structure | Exemple | Sens |
|-----------|---------|------|
| Sujet + Verbe | ==我吃::zh== (wǒ chī) | Je mange |
| Sujet + Verbe + Objet | ==我吃饭::zh== (wǒ chī fàn) | Je mange (litt. je mange du riz) |
| Sujet + Adverbe + Verbe | ==我也吃::zh== (wǒ yě chī) | Je mange aussi |
| Sujet + Lieu + Verbe | ==我在家吃::zh== (wǒ zài jiā chī) | Je mange à la maison |
| Sujet + Temps + Verbe | ==我今天吃::zh== (wǒ jīntiān chī) | Je mange aujourd'hui |
| Sujet + Temps + Lieu + Verbe + Objet | ==我今天在家吃饭::zh== | Je mange à la maison aujourd'hui |

> **Règle essentielle :** le temps et le lieu se placent **avant le verbe**, jamais après comme en français.

## Les particules — cœur de la grammaire

Le mandarin remplace les conjugaisons par des **particules**. Apprendre les particules = apprendre la grammaire.

### Les six particules essentielles

| Particule | Fonction | Exemple |
|-----------|---------|---------|
| ==的::zh== (de) | Possessif / qualificatif | ==我的书::zh== (wǒ **de** shū) — mon livre |
| ==了::zh== (le) | Action accomplie / changement | ==我吃了::zh== (wǒ chī **le**) — j'ai mangé |
| ==过::zh== (guo) | Expérience passée | ==我去过::zh== (wǒ qù **guo**) — j'y suis déjà allé |
| ==着::zh== (zhe) | État continu | ==门开着::zh== (mén kāi **zhe**) — la porte est ouverte |
| ==吗::zh== (ma) | Question oui/non | ==你好吗::zh==? (nǐ hǎo **ma**?) — Comment vas-tu ? |
| ==呢::zh== (ne) | Question de relais / situation | ==你呢::zh==? (nǐ **ne**?) — Et toi ? |

### Particule 了 — la plus complexe

了 est la particule la plus importante et la plus délicate. Elle a deux usages principaux :

| Usage | Position | Exemple |
|-------|---------|---------|
| Action complète (perfectif) | Après le verbe | ==我买了书::zh== (j'ai acheté un livre) |
| Changement d'état | À la fin de la phrase | ==我懂了::zh== (j'ai compris maintenant) |

### Particule 过 — l'expérience

了 dit "c'est arrivé une fois" ; 过 dit "j'ai déjà fait ça dans ma vie".

| Phrase | Sens |
|--------|------|
| ==我吃了北京烤鸭::zh== | J'ai mangé du canard laqué (action passée précise) |
| ==我吃过北京烤鸭::zh== | J'ai déjà goûté au canard laqué (expérience générale) |

## Pas de temps verbaux — l'aspect prime

Le mandarin n'a pas de "passé/présent/futur" comme en français. Il a des **aspects** marqués par particules + mots de temps.

### Exprimer le passé

| Méthode | Exemple |
|---------|---------|
| Particule ==了::zh== | ==我吃了::zh== (j'ai mangé) |
| Mot de temps | ==昨天我吃饭::zh== (hier je mange = j'ai mangé) |
| Particule ==过::zh== | ==我去过中国::zh== (j'ai déjà été en Chine) |

### Exprimer le présent

| Méthode | Exemple |
|---------|---------|
| Verbe seul | ==我吃饭::zh== (je mange) |
| ==在::zh== + verbe (action en cours) | ==我在吃饭::zh== (je suis en train de manger) |
| ==着::zh== (état continu) | ==他笑着::zh== (il sourit, en sourire) |

### Exprimer le futur

| Méthode | Exemple |
|---------|---------|
| Mot de temps | ==明天我吃饭::zh== (demain je mange = je mangerai) |
| ==会::zh== (huì) — futur certain | ==他会来::zh== (il viendra) |
| ==要::zh== (yào) — intention | ==我要去::zh== (je vais y aller / je veux y aller) |

## Négation — 不 et 没

Le mandarin a deux négations distinctes selon le verbe et l'aspect.

| Négation | Usage | Exemple |
|----------|-------|---------|
| ==不::zh== (bù) | Action habituelle, future, état permanent | ==我不喜欢::zh== (je n'aime pas) |
| ==没::zh== (méi) | Action passée non advenue, possession (*==没有::zh==*) | ==我没去::zh== (je ne suis pas allé) |

### Tableau d'usage

| Verbe / contexte | Négation correcte |
|-----------------|------------------|
| Je ne mange pas (régulier) | ==我不吃::zh== (wǒ bù chī) |
| Je n'ai pas mangé | ==我没吃::zh== (wǒ méi chī) |
| Je n'ai pas | ==我没有::zh== (wǒ méi yǒu) |
| Je ne suis pas | ==我不是::zh== (wǒ bú shì) |
| Je n'irai pas | ==我不去::zh== (wǒ bú qù) |

> 不 + 4ᵉ ton → *bú* (sandhi). Ex. *bú shì*, *bú qù*.

## Questions — 4 méthodes

### 1. Avec 吗 (ma) — question oui/non

| Affirmatif | Question |
|-----------|---------|
| ==你好::zh== (nǐ hǎo) | ==你好吗::zh==? (nǐ hǎo **ma**?) |
| ==他来::zh== (tā lái) | ==他来吗::zh==? |

### 2. Question alternative — V不V (verbe-pas-verbe)

| Question | Sens |
|----------|------|
| ==你去不去::zh==? | Tu y vas (ou pas) ? |
| ==这个好不好::zh==? | C'est bien ou pas ? |

### 3. Mots interrogatifs (à la position de la réponse)

| Mot interrogatif | Pinyin | Sens |
|-----------------|--------|------|
| ==什么::zh== | shénme | quoi |
| ==谁::zh== | shéi / shuí | qui |
| ==哪::zh== / ==哪里::zh== / ==哪儿::zh== | nǎ / nǎlǐ / nǎr | où |
| ==什么时候::zh== | shénme shíhou | quand |
| ==怎么::zh== | zěnme | comment |
| ==为什么::zh== | wèishéme | pourquoi |
| ==多少::zh== / ==几::zh== | duōshao / jǐ | combien |
| ==哪个::zh== | nǎge | lequel |

> Différence française : le mot interrogatif **reste à la place** de l'objet/sujet. *Ce qu'il mange* = 他吃**什么** (tā chī **shénme**), pas en début de phrase.

### 4. Avec 呢 (ne) — question contextuelle

| Phrase | Sens |
|--------|------|
| ==我很好::zh==,==你呢::zh==? | Je vais bien, et toi ? |
| ==我的书呢::zh==? | Et mon livre ? (où est-il ?) |

## Adjectifs et la copule

En mandarin, **les adjectifs sont des verbes d'état**. Ils n'ont pas besoin de "être".

| Mandarin | Sens littéral | Traduction |
|----------|--------------|-----------|
| ==我好::zh== (wǒ hǎo) | "Je bon" | Je vais bien |
| ==这个贵::zh== (zhège guì) | "Ce cher" | C'est cher |
| ==中国大::zh== | "Chine grande" | La Chine est grande |

> Avec un adjectif, **on ajoute généralement 很 (hěn — "très")** par souci d'équilibre rythmique, sans valeur d'intensité forte : *我很好* = "Je vais bien" (pas "Je vais TRÈS bien").

## La copule 是 (shì)

是 sert à relier deux noms (X est Y), pas avec les adjectifs.

| Phrase | Sens |
|--------|------|
| ==我是法国人::zh== | Je suis français |
| ==这是书::zh== | C'est un livre |
| ==他是医生::zh== | Il est médecin |

> **Erreur fréquente :** ✗ *我是好* (wǒ shì hǎo) — incorrect. ✓ *我很好* — correct.

## Possession — la particule 的 (de)

| Structure | Exemple | Sens |
|-----------|---------|------|
| Pronom + ==的::zh== + nom | ==我的书::zh== | mon livre |
| Nom + ==的::zh== + nom | ==老师的书::zh== | le livre du professeur |
| Adjectif (long) + ==的::zh== + nom | ==漂亮的女孩::zh== | la jolie fille |

### Quand 的 est omis

| Cas | Exemple |
|-----|---------|
| Famille proche | ==我妈妈::zh== (ma mère) — pas ==我的妈妈::zh== |
| Adjectif court | ==好朋友::zh== (un bon ami) — pas ==好的朋友::zh== |
| Lieu d'origine | ==中国朋友::zh== (un ami chinois) |

## Verbes modaux essentiels

| Verbe | Pinyin | Sens |
|-------|--------|------|
| ==会::zh== | huì | savoir faire / pouvoir (futur certain) |
| ==能::zh== | néng | pouvoir physiquement |
| ==可以::zh== | kěyǐ | pouvoir (permission) |
| ==要::zh== | yào | vouloir / aller (intention) |
| ==想::zh== | xiǎng | vouloir / penser à |
| ==应该::zh== | yīnggāi | devoir (obligation morale) |
| ==必须::zh== | bìxū | devoir (nécessité) |
| ==喜欢::zh== | xǐhuan | aimer |

## Comparaisons

| Structure | Exemple | Sens |
|-----------|---------|------|
| A ==比::zh== B + adjectif | ==我比他高::zh== (wǒ bǐ tā gāo) | Je suis plus grand que lui |
| A ==没有::zh== B + adjectif | ==我没有他高::zh== | Je ne suis pas aussi grand que lui |
| A ==跟::zh== B ==一样::zh== + adjectif | ==我跟他一样高::zh== | Je suis aussi grand que lui |

## Structure 把 (bǎ) — disposition

Une particularité du mandarin : la structure **把** déplace l'objet avant le verbe pour insister sur le résultat.

| Standard | Avec 把 | Sens |
|----------|---------|------|
| ==我吃了苹果::zh== | ==我把苹果吃了::zh== | J'ai mangé la pomme (toute) |
| ==他打开了门::zh== | ==他把门打开了::zh== | Il a ouvert la porte (effet) |

> 把 est obligatoire dans certaines constructions de "faire quelque chose à quelque chose" pour signaler que l'objet est entièrement affecté.
