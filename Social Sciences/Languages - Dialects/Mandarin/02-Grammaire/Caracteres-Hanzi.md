# Caractères Chinois (Hanzi) — Mandarin

## Le système d'écriture chinois

Les caractères chinois (汉字 *hànzì*) constituent l'un des plus anciens systèmes d'écriture encore en usage — ~3500 ans d'histoire continue. Contrairement à un alphabet, chaque caractère représente une syllabe + un sens.

| Fait | Détail |
|------|--------|
| Type d'écriture | Logographique — un caractère = une syllabe + un sens |
| Caractères existants | ~50 000 enregistrés, ~7 000 en usage moderne |
| Caractères pour lire un journal | ~3 000 |
| Caractères courants HSK 6 | ~2 600 |
| Caractères pour les bases (HSK 1-3) | ~600 |

## Simplifié vs Traditionnel

Depuis 1956, la Chine continentale utilise les **caractères simplifiés** (简体字 *jiǎntǐzì*), tandis que **Taïwan, Hong Kong et Macao** conservent les **caractères traditionnels** (繁體字 *fántǐzì*).

| Concept | Simplifié | Traditionnel |
|---------|-----------|-------------|
| Pays | 国 | 國 |
| Voir | 见 | 見 |
| Apprendre | 学 | 學 |
| Marcher | 车 | 車 |
| Aimer | 爱 | 愛 |
| Long / chef | 长 | 長 |
| Cheval | 马 | 馬 |
| Langue | 语 | 語 |
| Manger | 饭 | 飯 |
| Étranger / extérieur | 外 | 外 (identique) |

> Tous les caractères ne sont **pas** simplifiés — environ 30 % seulement. Les autres sont identiques. La transition est plus facile qu'il n'y paraît.

## Anatomie d'un caractère

Un caractère chinois est composé de **traits** (笔画 *bǐhuà*) organisés en **composants** (部件 *bùjiàn*), dont l'un est généralement un **radical** (部首 *bùshǒu*).

### Les 8 traits de base

| Trait | Exemple | Nom |
|-------|---------|-----|
| 一 (horizontal) | dans 一 (un) | héng |
| 丨 (vertical) | dans 十 (dix) | shù |
| 丿 (oblique gauche) | dans 人 (personne) | piě |
| 丶 (point) | dans 不 (non) | diǎn |
| 乀 (oblique droit) | dans 八 (huit) | nà |
| 乙 (crochet) | dans 九 (neuf) | gōu |
| 提 (montant) | dans 江 (rivière) | tí |
| 折 (brisé) | dans 口 (bouche) | zhé |

### Ordre des traits — règles

L'ordre d'écriture est important pour bien former le caractère :

1. **De haut en bas** : 三 (san — trois) — du haut vers le bas
2. **De gauche à droite** : 川 (chuān — fleuve) — de la gauche vers la droite
3. **Horizontal avant vertical** : 十 (shí — dix) — d'abord 一 puis 丨
4. **Extérieur avant intérieur** : 国 (guó — pays) — encadré d'abord, puis l'intérieur
5. **Au centre avant le bas** : 小 (xiǎo — petit) — point central, puis ailes
6. **Fermer la boîte en dernier** : 回 (huí — retourner) — fermer le carré final

## Les 214 radicaux

Chaque caractère contient (presque toujours) un **radical** qui donne un indice sémantique. Connaître les ~50 radicaux les plus courants permet de **deviner le sens** de nombreux caractères.

## Les 6 catégories de caractères

Selon la tradition (六书 *liùshū*), les caractères se classent en 6 types :

### 1. Pictogrammes (象形 xiàngxíng) — ~600 caractères

Représentations stylisées d'objets.

| Caractère | Sens | Origine |
|----------|------|---------|
| 山 | montagne | dessin de 3 sommets |
| 水 | eau | courants de rivière |
| 木 | arbre | tronc + branches + racines |
| 日 | soleil | cercle avec point |
| 月 | lune | croissant |
| 人 | personne | silhouette debout |
| 口 | bouche | rectangle ouvert |
| 目 | œil | rectangle avec deux barres |

### 2. Idéogrammes simples (指事 zhǐshì)

Concepts abstraits représentés graphiquement.

| Caractère | Sens | Logique |
|----------|------|---------|
| 一 二 三 | un, deux, trois | nombre de traits |
| 上 | au-dessus | trait au-dessus de la ligne |
| 下 | en-dessous | trait en-dessous |
| 中 | milieu | barre traversant un carré |

### 3. Idéogrammes composés (会意 huìyì)

Combinaison de pictogrammes pour créer un sens.

| Caractère | Décomposition | Sens |
|----------|--------------|------|
| 林 | 木 + 木 (deux arbres) | forêt |
| 森 | 木 + 木 + 木 | bois (massif) |
| 明 | 日 (soleil) + 月 (lune) | clair, lumineux |
| 好 | 女 (femme) + 子 (enfant) | bon |
| 休 | 人 (personne) + 木 (arbre) | se reposer |
| 男 | 田 (champ) + 力 (force) | homme |

### 4. Phono-sémantiques (形声 xíngshēng) — ~85 % des caractères

**La grande majorité** des caractères. Une moitié donne le sens (radical), l'autre donne la prononciation.

| Caractère | Pinyin | Sens (radical) | Phonétique |
|----------|--------|---------------|-----------|
| 妈 | mā | 女 (femme) | 马 (mǎ — cheval) |
| 河 | hé | 氵 (eau) | 可 (kě → hé) |
| 请 | qǐng | 讠 (parole) | 青 (qīng) |
| 想 | xiǎng | 心 (cœur) | 相 (xiāng) |
| 清 | qīng | 氵 (eau) | 青 (qīng) — eau claire |
| 情 | qíng | 忄 (cœur) | 青 (qīng) — sentiment |

> **Astuce d'apprentissage :** quand vous croisez un nouveau caractère phono-sémantique, le composant "à droite" indique souvent la prononciation, le "gauche" le sens.

### 5. Loanwords (假借 jiǎjiè) et 6. Transferts (转注 zhuǎnzhù)

Catégories rares — ne pas s'en préoccuper en début d'apprentissage.

## Stratégie d'apprentissage des caractères

### Phase 1 — Les 100 premiers (4–6 semaines)

Apprendre les caractères fréquents un par un, en se concentrant sur :
- L'**ordre des traits** (utiliser une app de stroke order)
- Le **radical** (deviner le sens)
- Le **pinyin avec ton**
- L'**utilisation dans 2-3 mots**

### Phase 2 — De 100 à 1000 (6–18 mois)

Passer aux **chengyu** (composés à 2 caractères) — le mandarin moderne combine massivement deux caractères pour former des mots.

| Caractère | Lui-même | Combinaisons |
|----------|---------|--------------|
| 学 (xué — apprendre) | étudier | 学校 (école), 学生 (étudiant), 学习 (apprendre), 数学 (maths) |
| 电 (diàn — électricité) | électricité | 电话 (téléphone), 电脑 (ordinateur), 电视 (télé), 电影 (film) |

### Phase 3 — De 1000 à 3000 (2–4 ans)

Lecture extensive avec apps comme **Du Chinese**, **The Chairman's Bao**. À ce stade, on apprend les caractères **par contexte**, plus en isolation.

## Principes mémoriels

| Principe | Application |
|---------|-------------|
| Spaced repetition (Anki, Pleco) | Réviser à intervalles croissants |
| Décomposition en radicaux | "Voir" la structure plutôt que mémoriser bêtement |
| Histoires mnémoniques | *Heisig* — associer une image absurde au caractère |
| Écriture à la main | Les premiers 200 caractères : écrire 5–10 fois chacun |
| Lecture extensive | À partir de 500 caractères : lire pour consolider |
| Audio + caractère | Toujours associer son et image |
