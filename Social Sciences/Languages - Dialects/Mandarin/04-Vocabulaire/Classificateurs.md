# Classificateurs (Mots de Mesure) — Mandarin

## Le principe — pourquoi des classificateurs ?

En mandarin, on ne dit jamais directement "trois livres" ou "deux personnes". On insère un **classificateur** (量词 *liàngcí*) entre le nombre (ou démonstratif) et le nom.

| Structure | Exemple | Sens |
|-----------|---------|------|
| Nombre + Classificateur + Nom | ==三::zh==**==本::zh==**==书::zh== (sān **běn** shū) | trois livres |
| Démonstratif + Classificateur + Nom | ==这::zh==**==本::zh==**==书::zh== (zhè **běn** shū) | ce livre |
| Combien + Classificateur + Nom | ==几::zh==**==本::zh==**==书::zh== (jǐ **běn** shū) ? | combien de livres ? |

> Les classificateurs sont **obligatoires**. *sān shū* (sans classificateur) est agrammatical en mandarin moderne.

## Le classificateur universel — 个 (gè)

Le classificateur **个** est le passe-partout. Il fonctionne pour les personnes, les objets, les concepts abstraits — bref, presque tout, à défaut d'un classificateur spécifique.

| Exemple | Sens |
|---------|------|
| ==一::zh==**==个::zh==**==人::zh== (yí **gè** rén) | une personne |
| ==三::zh==**==个::zh==**==问题::zh== | trois questions |
| ==这::zh==**==个::zh==**==苹果::zh== | cette pomme |
| ==那::zh==**==个::zh==**==地方::zh== | cet endroit |
| ==一::zh==**==个::zh==**==朋友::zh== | un ami |

> En cas de doute, utiliser **个**. Vous serez compris à 100 %, même si un classificateur plus précis existe.

## Comparaison directe avec les noms français

Le mandarin force ce que le français fait optionnellement avec "feuille de", "tranche de", "morceau de" :

| Français | Mandarin |
|---------|---------|
| trois feuilles de papier | ==三::zh==**==张::zh==**==纸::zh== |
| une tranche de pain | ==一::zh==**==片::zh==**==面包::zh== |
| un grain de riz | ==一::zh==**==粒::zh==**==米::zh== |
| une paire de chaussures | ==一::zh==**==双::zh==**==鞋::zh== |
| un bol de soupe | ==一::zh==**==碗::zh==**==汤::zh== |
| un livre | ==一::zh==**==本::zh==**==书::zh== (pas de classificateur en français !) |
| une voiture | ==一::zh==**==辆::zh==**==车::zh== |
| un chien | ==一::zh==**==条::zh==**==狗::zh== |

> Le français a des classificateurs implicites pour certaines matières ("trois pièces de"), mais les omet pour les objets. Le mandarin les exige toujours.

## Astuces mnémotechniques

### Visualiser la forme

Le classificateur reflète souvent **la forme physique** de l'objet :

- **本** (běn) — chose épaisse et reliée → livre, magazine, dictionnaire
- **张** (zhāng) — chose plate et large → feuille, billet, photo, table, lit, peau
- **条** (tiáo) — chose longue et flexible → poisson, route, fleuve, jambe, pantalon
- **根** (gēn) — chose longue et rigide → bâton, ficelle, banane, cheveu
- **粒** (lì) — petit grain → riz, sable, pilule, perle

## L'exception : 两 vs 二 (deux)

Pour le chiffre **2**, le mandarin distingue :

| Forme | Pinyin | Usage |
|-------|--------|-------|
| ==二::zh== | èr | Pour compter (1, 2, 3) ou les ordinaux (==二月::zh== = février) |
| ==两::zh== | liǎng | Devant un classificateur (deux unités d'un objet) |

| Correct | Incorrect |
|---------|-----------|
| ==两个人::zh== (deux personnes) | ✗ ==二个人::zh== |
| ==两本书::zh== (deux livres) | ✗ ==二本书::zh== |
| ==第二个::zh== (le deuxième) | ✗ ==第两个::zh== |
