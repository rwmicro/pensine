# Ressources — Mandarin

Le mandarin est une langue exigeante (FSI catégorie V — ~2200 h pour un anglophone). La sélection des ressources est plus importante que leur quantité.

## Le système HSK — votre boussole

Le **HSK** (汉语水平考试 *Hànyǔ Shuǐpíng Kǎoshì*) est le test officiel de mandarin. Il structure l'apprentissage en niveaux clairs.

| Niveau | Caractères | Vocabulaire | Capacités |
|--------|-----------|-------------|-----------|
| HSK 1 | ~150 | 150 mots | Phrases simples, présentations |
| HSK 2 | ~300 | 300 mots | Conversations basiques |
| HSK 3 | ~600 | 600 mots | Quotidien, voyage |
| HSK 4 | ~1200 | 1200 mots | Discussion abstraite |
| HSK 5 | ~2500 | 2500 mots | Journaux, films |
| HSK 6 | ~5000+ | 5000+ mots | Niveau avancé / professionnel |

> Le **HSK 3.0** (réforme 2021) ajoute un niveau 7-8-9 unifié pour le très avancé. La plupart des apprenants visent HSK 4 (~1200 mots) comme premier objectif sérieux.

## Pleco — l'outil indispensable

**Pleco** est l'outil chinois le plus important au monde. Toute personne apprenant le mandarin doit l'installer dès le jour 1.

| Fonction | Utilité |
|----------|--------|
| Dictionnaire offline | Recherche par pinyin, caractère, anglais |
| Saisie manuscrite (handwriting) | Dessiner un caractère pour le chercher |
| OCR | Pointer la caméra sur un texte chinois pour le lire |
| Stroke order | Animation de l'ordre des traits |
| Audio natif | Prononciation enregistrée |
| Flashcards | Module SRS intégré (payant) |
| Document Reader | Lire des PDF chinois avec dico contextuel |

> Pleco est gratuit dans sa version de base. Les modules payants (OCR, flashcards) sont rentables si on étudie sérieusement.

## Parcours recommandé

```
Phase 1 — Fondations (mois 1–3)
  → Pinyin + 4 tons (2 semaines, écoute massive)
  → 100 caractères les plus fréquents
  → HelloChinese sections 1–4
  → Pleco installé et utilisé quotidiennement
  → Pas encore de conversation

Phase 2 — Décollage (mois 3–9)
  → 300–600 caractères (HSK 2–3)
  → Anki HSK + Du Chinese (lecture graduée)
  → Mandarin Corner pour l'écoute
  → Premières conversations avec italki
  → ChinesePod débutant

Phase 3 — Plateau actif (mois 9–24)
  → 1200 caractères (HSK 4)
  → Séries TV chinoises avec sous-titres pinyin
  → Lecture extensive sur Du Chinese
  → italki 1–2x/semaine
  → Tenter le HSK 3 ou 4 officiel

Phase 4 — Avancé (2 ans+)
  → Lecture autonome de blogs, news
  → Films sans sous-titres
  → Conversations naturelles
  → Spécialisation : business, médecine, littérature, etc.
```

## Conseils stratégiques pour francophones

| Conseil | Raison |
|---------|--------|
| Maîtriser les tons d'abord | Pas de raccourci — sans tons, pas de mandarin |
| Apprendre par radicaux | Décompose les caractères en éléments mémorisables |
| Privilégier la fréquence | 300 mots fréquents > 3000 mots aléatoires |
| Lecture extensive | À partir de 500 caractères, lire bcp est plus efficace que mémoriser |
| Audio chaque jour | Au moins 30 min d'écoute par jour, dès le début |
| Patience sur l'écriture | Reconnaître ≫ écrire à la main (la saisie pinyin est partout) |
| Culture en parallèle | Films, podcasts, contexte — pas que de la grammaire |
