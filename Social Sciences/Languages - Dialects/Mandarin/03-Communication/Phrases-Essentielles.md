# Phrases Essentielles — Mandarin

## Oui / Non / Affirmations

| Caractères | Pinyin  | Sens                   |
| ---------- | ------- | ---------------------- |
| ==是::zh== | shì | Oui (être) |
| ==对::zh== | duì | Correct / Oui |
| ==是的::zh== | shì de | Oui (formel) |
| ==好::zh== | hǎo | OK / Bien |
| ==不::zh== | bù | Non |
| ==不是::zh== | bú shì | Non (négation de être) |
| ==不对::zh== | bú duì | Faux / Non |
| ==没有::zh== | méiyǒu | Non (négation passé) |
| ==也许::zh== | yěxǔ | Peut-être |
| ==当然::zh== | dāngrán | Bien sûr |
哈哈 | | ahahah

> Le mandarin n'a pas de "oui/non" universels comme en français. On répond avec **le verbe** ou sa négation. Question avec 是? → réponse 是 ou 不是.
