# Phrases Essentielles — Tok Pisin

Le Tok Pisin est un créole anglais (lingua franca de Papouasie-Nouvelle-Guinée). Phonologie simple, grammaire régulière, vocabulaire largement d'origine anglaise.

## Salutations

| Français | Tok Pisin | Étymologie |
|----------|-----------|------------|
| Bonjour | Gude | "Good day" |
| Bonjour (matin) | Moning | "Morning" |
| Bonsoir | Apinun | "Afternoon" |
| Comment vas-tu ? | Yu orait? | "You alright?" |
| Je vais bien | Mi orait | "I'm alright" |
| Comment ça va ? (famille) | Olgeta orait? | "Everyone alright?" |
| Au revoir | Lukim yu | "See you" (à bientôt) |
| Bonne nuit | Gut nait | "Good night" |
| Oui | Yes / Em nau | |
| Non | Nogat | "No got" |
| Merci | Tenkyu | "Thank you" |
| Merci beaucoup | Tenkyu tumas | "Thank you too much" |
| S'il vous plaît | Plis | "Please" |
| De rien | Ino samting | "It's nothing" |
| Pardon | Sori | "Sorry" |
| Excuse-moi | Skiusmi | "Excuse me" |

## Se présenter

| Français | Tok Pisin |
|----------|-----------|
| Je m'appelle... | Nem bilong mi ... |
| Quel est votre nom ? | Wanem nem bilong yu? |
| D'où venez-vous ? | Yu kam we? |
| Je viens de France | Mi kam long Frens |
| J'apprends le Tok Pisin | Mi lanim Tok Pisin |
| Enchanté | Mi amamas long mitim yu |

## Communication

| Français | Tok Pisin |
|----------|-----------|
| Je ne comprends pas | Mi no save |
| Répétez s'il vous plaît | Tok gen, plis |
| Plus lentement | Tok isi-isi |
| Qu'est-ce que ça veut dire ? | Em i min wanem? |
| Comment dit-on ... en Tok Pisin ? | Yumi tok ... olsem wanem long Tok Pisin? |

## Orientation

| Français | Tok Pisin |
|----------|-----------|
| Où est... ? | ... i stap we? |
| À gauche | Long lep | "On the left" |
| À droite | Long rait | "On the right" |
| Tout droit | Stret | "Straight" |
| C'est loin ? | I longwe? |
| Aidez-moi | Helpim mi |

## Restaurant et vie quotidienne

| Français | Tok Pisin |
|----------|-----------|
| J'ai faim | Bel bilong mi i hangre | "My belly is hungry" |
| J'ai soif | Mi mangal | "I'm thirsty" |
| Délicieux | I swit tumas | "Too sweet/tasty" |
| Je voudrais... | Mi laik ... |
| Combien ? | Hamas mani? | "How much money?" |
| C'est cher | I dia tumas | "Too dear" |
