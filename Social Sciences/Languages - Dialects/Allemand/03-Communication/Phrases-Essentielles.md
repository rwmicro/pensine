## Achats

| Allemand | Sens |
|----------|------|
| Ich möchte das | Je voudrais ceci |
| Kann ich das anprobieren? | Puis-je l'essayer ? |
| Haben Sie das in einer anderen Farbe? | L'avez-vous dans une autre couleur ? |
| Haben Sie das in einer anderen Größe? | L'avez-vous dans une autre taille ? |
| Gibt es einen Rabatt? | Y a-t-il une réduction ? |
| Das ist zu teuer | C'est trop cher |
| Können Sie mir einen Preis machen? | Pouvez-vous me faire un prix ? |
| Akzeptieren Sie Karte? | Acceptez-vous la carte ? |
| Ich zahle bar | Je paie en espèces |
| Die Quittung, bitte | Le reçu, s'il vous plaît |
| Ich nehme es | Je le prends |

> **Note culturelle :** beaucoup de petits commerces allemands acceptent **uniquement** le cash (*Nur Bargeld*). C'est en train de changer mais reste fréquent.
