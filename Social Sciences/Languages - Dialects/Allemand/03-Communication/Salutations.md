# Salutations — Allemand

## Salutations selon le moment de la journée

| Allemand | Sens | Période |
|----------|------|---------|
| Guten Morgen | Bonjour (matin) | Avant 11h |
| Guten Tag | Bonjour (journée) | 11h–18h |
| Guten Abend | Bonsoir | Après 18h |
| Gute Nacht | Bonne nuit | Avant de dormir |
| Hallo | Salut | Universel, informel |
| Tschüss | Salut (départ) | Informel |
| Servus | Salut (Bavière, Autriche) | Régional |
| Grüß Gott | Bonjour (litt. "salue Dieu") | Sud — Bavière, Autriche, formel |
| Moin / Moin moin | Salut | Nord de l'Allemagne — toute la journée |
| Grüezi | Bonjour | Suisse alémanique |

> **Hallo** est le salut universel courant. **Guten Tag** est plus formel, idéal en commerce ou avec des inconnus.

## Tu vs Vous — du vs Sie

| Pronom | Usage | Exemple |
|--------|-------|---------|
| du (informel) | Amis, famille, jeunes, entre étudiants | *Wie geht's dir?* |
| Sie (formel) | Inconnus, supérieurs, contexte professionnel | *Wie geht es Ihnen?* |
| ihr (pluriel informel) | Groupe d'amis, famille | *Wie geht's euch?* |

> En Allemagne, le **Sie** est plus systématique qu'en France. Avec un commerçant, un médecin, un voisin que vous ne connaissez pas — **Sie** par défaut. Le passage au **du** doit être proposé explicitement (*Sollen wir uns duzen?* = "Faut-il se tutoyer ?").

### Du-Kultur vs Sie-Kultur

- **Allemagne :** Sie strict, surtout pour les +30 ans, en milieu professionnel
- **Suisse :** Sie omniprésent
- **Autriche :** Sie + titre (*Herr Doktor*, *Frau Professorin*)
- **Berlin et milieux jeunes / startups :** du plus rapide
- **IKEA, certaines entreprises** : du systématique

## Comment vas-tu ?

| Allemand | Sens | Registre |
|----------|------|---------|
| Wie geht's? | Comment ça va ? | Très informel |
| Wie geht es dir? | Comment vas-tu ? | Informel |
| Wie geht es Ihnen? | Comment allez-vous ? | Formel |
| Was machst du so? | Quoi de neuf ? | Informel |
| Alles klar? | Tout va bien ? | Familier |
| Alles gut? | Tout va bien ? | Très courant |
| Wie war dein Tag? | Comment était ta journée ? | Affectueux |

| Réponse | Sens |
|---------|------|
| Mir geht es gut | Je vais bien (formel) |
| Gut, danke | Bien, merci |
| Sehr gut | Très bien |
| Es geht | Ça va, comme ci comme ça |
| Nicht so gut | Pas si bien |
| Ganz okay | Plutôt bien |
| Und dir? / Und Ihnen? | Et toi ? / Et vous ? |

> Attention culturelle : *Wie geht's?* en allemand est souvent une **vraie question**, pas une formule vide. Une réponse honnête (incluant un problème) est attendue, pas le "ça va" automatique français.

## Politesse — remerciements

| Allemand | Sens |
|----------|------|
| Danke | Merci |
| Danke schön | Merci beaucoup |
| Vielen Dank | Merci infiniment |
| Tausend Dank | Mille mercis |
| Bitte | S'il te/vous plaît / De rien / Voici |
| Bitte schön | Avec plaisir / De rien |
| Gern geschehen | Avec plaisir |
| Keine Ursache | De rien (litt. "pas de cause") |
| Entschuldigung | Pardon / Excusez-moi |
| Entschuldigen Sie | Excusez-moi (formel) |
| Es tut mir leid | Je suis désolé(e) |
| Schade | Dommage |

> **Bitte** est extrêmement polyvalent : *s'il vous plaît*, *de rien*, *je vous en prie*, *voici*, *pardon ?* — selon contexte et intonation.

## Hospitalité — formules essentielles

| Allemand | Sens |
|----------|------|
| Willkommen! | Bienvenue ! |
| Herzlich willkommen! | Cordialement bienvenue ! (formel) |
| Komm rein! / Kommen Sie rein! | Entre / Entrez |
| Setz dich / Setzen Sie sich | Assieds-toi / Asseyez-vous |
| Möchtest du etwas trinken? | Veux-tu quelque chose à boire ? |
| Hast du Hunger? | As-tu faim ? |
| Mach es dir gemütlich | Mets-toi à l'aise |
| Fühl dich wie zu Hause | Sens-toi chez toi |
| Guten Appetit! | Bon appétit ! |
| Mahlzeit! | Bon appétit ! (collègues à midi) |
| Prost! / Zum Wohl! | Santé ! (toast) |

> Le toast allemand exige **regard direct dans les yeux** pendant le *Prost!* — sinon tradition dit "7 ans de mauvais sexe".

| Allemand | Sens |
|----------|------|
| Ja | Oui |
| Nein | Non |
| Doch | Si (réponse positive à une question négative) |

| Natürlich | Naturellement |
| Vielleicht | Peut-être |

> **Doch** est une particule essentielle : il sert à contredire, insister, ou simplement répondre positivement après une négation. *Magst du das nicht? — Doch!* (= Si, je l'aime).
