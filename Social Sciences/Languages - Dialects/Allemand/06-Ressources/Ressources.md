# Ressources — Allemand

L'allemand est très bien servi en ressources d'apprentissage — institutionnelles, communautaires et payantes. Le défi est la **sélection**, pas la disponibilité.

## Le système CECR / Goethe — votre boussole

Le **Goethe-Institut** est l'organisme officiel de promotion de la langue allemande, équivalent de l'Alliance française. Ses certifications sont alignées sur le CECR.

| Niveau | Vocabulaire | Capacités |
|--------|-------------|-----------|
| A1 | ~650 mots | Phrases simples, présentations |
| A2 | ~1300 mots | Conversations basiques quotidiennes |
| B1 | ~2400 mots | Voyage, situations courantes, opinions |
| B2 | ~4000 mots | Discussion abstraite, journaux |
| C1 | ~6000 mots | Universitaire, professionnel |
| C2 | ~10000 mots | Maîtrise quasi-native |

> Niveaux requis usuels : **B1** pour la naturalisation allemande, **B2** pour études universitaires, **C1** pour médecine ou droit en Allemagne.

## La référence absolue : Nicos Weg (Deutsche Welle)

**Nicos Weg** (deutsche-welle.de) est probablement **la meilleure ressource gratuite au monde** pour apprendre l'allemand.

| Caractéristique | Détail |
|----------------|--------|
| Niveaux | A1, A2, B1 (couvre toute l'initiation) |
| Format | Série télévisée + exercices interactifs |
| Histoire | Suit Nico, jeune Espagnol qui s'installe en Allemagne |
| Coût | 100 % gratuit |
| Source | Deutsche Welle (radio publique allemande) |
| Avantage | Allemand de tous les jours, parlé naturellement |

> Compléter Nicos Weg = un cours structuré équivalent A1-B1. Vraiment exceptionnel.

## Parcours recommandé

```
Phase 1 — Fondations (mois 1-3)
  → Nicos Weg A1 (Deutsche Welle) — le manuel complet
  → Anki — German Top 1000 mots avec audio
  → Easy German Super Easy playlist
  → Apprendre les genres avec un système de couleurs (der=bleu, die=rouge, das=vert)

Phase 2 — Décollage (mois 3-9)
  → Nicos Weg A2 + B1
  → Babbel ou Pimsleur pour la grammaire des cas
  → Easy German interviews
  → Coffee Break German (podcast)
  → Premiers livres simplifiés (Easy Readers)

Phase 3 — Plateau actif (mois 9-24)
  → Aspekte neu B2
  → Séries comme Dark ou Tatort avec sous-titres allemands
  → Auf Deutsch gesagt! (podcast)
  → italki — 1-2 fois par semaine
  → Goethe-Zertifikat B1 — premier objectif

Phase 4 — Avancé (2 ans+)
  → Lecture autonome (Der Vorleser, Tschick)
  → Tagesschau quotidien sans sous-titres
  → Conversations naturelles
  → Décider d'une variante : Deutschland / Österreich / Schweiz
  → Goethe-Zertifikat B2 ou C1
```

## Atouts pour les francophones

| Avantage | Détail |
|---------|--------|
| Cognats germaniques avec l'anglais | Si vous savez l'anglais, des milliers de mots allemands ressemblent (Apfel/apple, Wasser/water) |
| Logique grammaticale claire | Cas et déclinaisons sont rigides mais prévisibles |
| Orthographe phonétique | Une fois les règles connues, on prononce ce qu'on lit |
| Subjonctif simple | Beaucoup moins utilisé qu'en français |

### Pièges pour francophones

| Piège | Note |
|-------|------|
| Genre des noms | À mémoriser un par un — pas prévisible |
| 4 cas | Le défi central — y consacrer du temps |
| Verbes séparables | Particule à la fin de phrase principale |
| V2 (verbe en 2ᵉ position) | Inversion sujet/verbe quand un complément est en tête |
| Subordonnée à la fin | *weil*, *dass*, *wenn* renvoient le verbe à la fin |
| ß vs ss | Importer en orthographe — pas en Suisse |
| Faux amis | *Gift* (poison), *Rente* (retraite, pas rente), *bald* (bientôt) |
