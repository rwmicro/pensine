# Culture — Monde Germanophone

## Le monde germanophone — diversité et identité

L'allemand n'est pas la culture d'un seul pays mais de **plusieurs nations distinctes** qui partagent une langue tout en cultivant leurs spécificités.

| Pays | Population | Capitale | Statut linguistique |
|------|-----------|----------|---------------------|
| Allemagne (Deutschland) | 84 millions | Berlin | Langue officielle |
| Autriche (Österreich) | 9 millions | Vienne | Langue officielle |
| Suisse (Schweiz) | 8,8 millions | Berne | Langue officielle (avec FR, IT, RM) |
| Liechtenstein | 40 000 | Vaduz | Langue officielle |
| Luxembourg | 660 000 | Luxembourg | Langue officielle (avec FR, LB) |
| Belgique (région East) | 80 000 | — | Langue officielle régionale |
| Tyrol du Sud (Italie) | 500 000 | Bolzano | Statut spécial |

> En agrégat, l'allemand est **la langue la plus parlée d'Europe** (~95 millions de natifs), devant le français et l'anglais britannique.

## Allemagne, Autriche, Suisse — trois cultures distinctes

| Aspect | Allemagne | Autriche | Suisse |
|--------|-----------|----------|--------|
| Auto-image | Efficace, structurée, directe | Charmante, mélancolique (*Gemütlichkeit*) | Neutre, méticuleuse, multilingue |
| Cuisine | Bratwurst, Sauerkraut, Schnitzel | Wiener Schnitzel, Sachertorte, café viennois | Fondue, Raclette, Rösti, chocolat |
| Boisson nationale | Bière (Bayern, Cologne) | Vin (Wachau), café | Vin, kirsch |
| Politique | Démocratie fédérale, économie majeure | Démocratie parlementaire, neutralité historique | Démocratie directe (référendums fréquents) |
| Identité | Pluralité régionale (16 Länder) | Cohérente, post-impériale | Plurinationale (4 langues, 26 cantons) |

## Vergangenheitsbewältigung — assumer le passé

L'Allemagne est le pays qui a probablement le plus systématiquement **assumé son passé**. La culture mémorielle est centrale.

| Concept | Description |
|--------|-------------|
| Vergangenheitsbewältigung | "Faire face au passé" — terme intraduisible |
| Mémoriaux | Berlin (Holocauste), camps préservés (Dachau, Sachsenhausen) |
| Stolpersteine | "Pavés du souvenir" — pavés dorés devant les anciennes adresses des déportés |
| Éducation | L'histoire nazie est enseignée à l'école obligatoirement |
| Tabous légaux | Symboles nazis interdits (croix gammée, salut hitlérien) |
| Berlin Holocaust Mahnmal | Mémorial monumental au cœur de Berlin (2005) |

## Concepts culturels emblématiques

| Concept | Description |
|--------|-------------|
| **Gemütlichkeit** | Bien-être convivial — entre amis, dans un café — quasi-intraduisible |
| **Ordnung** | Ordre — règle de vie, infrastructures impeccables |
| **Pünktlichkeit** | Ponctualité — arriver à l'heure n'est pas un compromis |
| **Gründlichkeit** | Méticulosité — faire les choses à fond |
| **Sehnsucht** | Mélancolie nostalgique — émotion romantique allemande |
| **Wanderlust** | Envie de voyager — concept exporté |
| **Schadenfreude** | Joie du malheur d'autrui — un trait reconnu |
| **Heimat** | "Patrie / chez-soi" — attachement émotionnel à un lieu d'origine |
| **Feierabend** | Moment où le travail s'arrête — sacralisé |
| **Mietshaus** | Immeuble de location — modèle d'habitat majoritaire |

### Le Lied

Le **Lied** (chant) est un genre musical spécifiquement allemand : poésie + piano. Schubert (Winterreise), Schumann, Brahms, Mahler en sont les maîtres.
