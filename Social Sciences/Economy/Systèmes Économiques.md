# Systèmes Économiques


### Capitalisme

**Caractéristiques**
- **Propriété Privée** : Moyens de production (capital) privés
- **Marché** : Allocation ressources via prix
- **Profit** : Moteur activité économique
- **Concurrence** : Entre entreprises
- **Liberté Économique** : Entreprendre, contracter

**Variantes**

*Capitalisme Libéral (Anglo-Saxon)*
- **Exemples** : USA, UK
- **État Minimal** : Régulation faible, protections sociales limitées
- **Flexibilité** : Marché travail flexible
- **Innovation** : Forte, entrepreneuriat encouragé
- **Inégalités** : Élevées

*Capitalisme Rhénan (Social-Démocrate)*
- **Exemples** : Allemagne, Scandinavie
- **État-Providence** : Protection sociale forte
- **Partenariat Social** : Syndicats, cogestion
- **Régulation** : Marchés encadrés
- **Égalité** : Redistribution importante

*Capitalisme d'État*
- **Exemples** : Chine, Singapour
- **État Actif** : Contrôle entreprises stratégiques
- **Planification** : Orientations économiques dirigées
- **Marché** : Existe mais sous contrôle politique

**Avantages**
- **Efficacité Allocative** : Prix signalent rareté
- **Innovation** : Incitations profit
- **Croissance** : Historiquement forte
- **Liberté** : Choix consommateurs, entrepreneurs

**Critiques**
- **Inégalités** : Concentration richesse (1% le plus riche)
- **Crises** : Instabilité financière (2008)
- **Externalités** : Pollution, changement climatique
- **Aliénation** : Travail, consumérisme
- **Court-Termisme** : Profit immédiat vs. soutenabilité
- Voir [[Capitalisme de la finitude]] : Limites écologiques

### Socialisme

**Caractéristiques**
- **Propriété Collective** : Moyens de production (État, coopératives)
- **Planification** : Allocation centralisée ressources
- **Égalité** : Objectif prioritaire
- **Besoins vs. Profit** : Production pour usage, pas profit

**Variantes**

*Socialisme Marxiste-Léniniste*
- **Exemples** : URSS, Cuba, Corée du Nord
- **Dictature Prolétariat** : Parti unique communiste
- **Planification Centrale** : Plans quinquennaux
- **Collectivisation** : Agriculture, industrie

*Socialisme Démocratique*
- **Exemples** : Scandinavie (débat terminologie)
- **Démocratie** : Multipartisme
- **Propriété Mixte** : Secteurs clés publics, reste privé
- **Redistribution** : Fiscalité progressive, services publics

*Socialisme Autogestionnaire*
- **Exemples** : Yougoslavie (titisme), Rojava (Kurdistan syrien)
- **Autogestion** : Travailleurs contrôlent entreprises
- **Décentralisation** : Planification participative

**Avantages (Théoriques)**
- **Égalité** : Réduction inégalités
- **Besoins Essentiels** : Logement, santé, éducation garantis
- **Stabilité** : Moins crises (pas spéculation)
- **Cohésion Sociale** : Solidarité

**Critiques**
- **Inefficacité** : Manque incitations, bureaucratie
- **Innovation** : Faible (pas concurrence, profit)
- **Libertés** : Régimes autoritaires (URSS, Chine maoïste)
- **Pénuries** : Planification imparfaite (URSS)
- **Échecs** : Effondrement bloc soviétique (1991)

### Économie Mixte

**Définition**
Combinaison éléments capitalistes (marché, propriété privée) et socialistes (intervention État, services publics).

**Caractéristiques**
- **Secteur Privé** : Majorité économie
- **Secteur Public** : Services essentiels (santé, éducation), infrastructures
- **Régulation** : État encadre marchés
- **Protection Sociale** : Chômage, retraites, santé

**Exemples**
- **Majorité Pays Développés** : France, Allemagne, Japon, Canada
- **Degré Variable** : USA (moins État) vs. France (plus État)

**Justifications**
- **Défaillances Marché** : Externalités, biens publics, monopoles naturels
- **Équité** : Redistribution revenus
- **Stabilisation** : Politiques contra-cycliques
