# Commerce International


### Fondements

**Avantage Absolu (Adam Smith)**
- Pays produit bien à coût moindre qu'autre pays
- Spécialisation → gains commerce

**Avantage Comparatif (David Ricardo)**
- **Clé** : Pays doit se spécialiser dans production où coût d'opportunité le plus faible
- **Même si** : Moins efficace absolument
- **Résultat** : Tous pays gagnent au commerce
- **Exemple** : Portugal vin, Angleterre textile (même si Portugal meilleur aux deux)

### Balance des Paiements

**Structure**
- **Compte Courant** :
  - Balance commerciale (biens)
  - Balance services
  - Revenus (investissements)
  - Transferts (aide, remises migrants)
- **Compte Capital et Financier** :
  - Investissements directs (IDE)
  - Investissements portefeuille
  - Autres flux

**Équilibre**
- Compte Courant + Compte Capital = 0 (en principe)
- Déficit Courant ↔ Entrée capitaux (financement)

**Taux de Change**
- **Nominal** : Prix monnaie en autre monnaie (EUR/USD)
- **Réel** : Ajusté niveaux prix
- **Appréciation** : Monnaie gagne valeur
- **Dépréciation** : Perd valeur
- **Déterminants** : Taux intérêt, inflation, balance commerciale, spéculation

### Politique Commerciale

**Libre-Échange**
- **Principe** : Réduction/élimination barrières commerciales
- **Arguments** :
  - Avantages comparatifs
  - Efficacité allocative
  - Concurrence → innovation
  - Choix consommateurs ↑, prix ↓
- **Institutions** : OMC (Organisation Mondiale Commerce), accords bilatéraux

**Protectionnisme**
- **Outils** :
  - **Tarifs Douaniers** : Taxes importations
  - **Quotas** : Limites quantitatives
  - **Subventions** : Aide industries nationales
  - **Normes** : Barrières non-tarifaires (sanitaires, techniques)
- **Arguments** :
  - **Industries Naissantes** : Protection temporaire développement
  - **Emploi** : Préserver emplois nationaux
  - **Sécurité** : Indépendance secteurs stratégiques (défense, agriculture)
  - **Dumping** : Concurrence déloyale
- **Critiques** :
  - Prix ↑ consommateurs
  - Inefficacité (ressources mal allouées)
  - Représailles commerciales (guerre commerciale)

**Accords Commerciaux**
- **Multilatéraux** : OMC (164 membres)
- **Régionaux** :
  - UE : Marché unique, union douanière
  - USMCA : USA-Mexique-Canada (ex-ALENA)
  - RCEP : Asie-Pacifique (Chine, Japon, Corée, ASEAN)
  - CPTPP : Trans-Pacifique (sans USA)

### Globalisation

**Dimensions**
- **Économique** : Commerce, IDE, chaînes valeur mondiales
- **Financière** : Flux capitaux, marchés intégrés
- **Technologique** : Diffusion innovations
- **Culturelle** : Échanges idées, médias

**Avantages**
- **Croissance** : Pays émergents (Chine, Inde)
- **Pauvreté** : Réduction pauvreté extrême (Banque Mondiale)
- **Innovation** : Diffusion rapide
- **Choix** : Produits diversifiés, moins chers

**Critiques**
- **Inégalités** : Intra-pays (classes moyennes déclassées), inter-pays
- **Délocalisation** : Emplois industriels perdus (désindustrialisation Ouest)
- **Environnement** : Empreinte carbone transport, course au moins-disant écologique
- **Souveraineté** : Dépendance (chaînes approvisionnement COVID)
- **Culture** : Uniformisation (McDonaldisation)

**Tensions Actuelles**
- **Guerre Commerciale USA-Chine** : Tarifs, technologie
- **Brexit** : UK quitte UE (2020)
- **Régionalisation** : "Friend-shoring", "near-shoring"
