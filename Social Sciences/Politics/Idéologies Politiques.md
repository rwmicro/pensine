# Idéologies Politiques

### Gauche et Droite

**Origine**
- **Révolution Française** (1789) : Assemblée Nationale
  - **Gauche** : Révolutionnaires, changement
  - **Droite** : Conservateurs, tradition

**Clivage Économique**
- **Gauche** : Égalité, redistribution, intervention État
- **Droite** : Liberté économique, propriété privée, marché

**Clivage Sociétal**
- **Gauche** : Progrès, laïcité, droits minorités
- **Droite** : Tradition, religion, ordre moral

**Limites**
- **Réducteur** : Multiples dimensions
- **Relatif** : Varie selon pays, époque
- **Écologie, Populisme** : Difficiles à classer


### Libéralisme

**Principes**
- **Liberté Individuelle** : Valeur suprême
- **Droits Naturels** : Vie, liberté, propriété (Locke)
- **État Limité** : Protection droits, pas paternalisme
- **État de Droit** : Lois, constitution, séparation pouvoirs
- **Tolérance** : Pluralisme, diversité opinions

**Variantes**

*Libéralisme Classique*
- **Économie** : Marché libre, propriété privée (Adam Smith)
- **Politique** : Démocratie représentative, droits civils
- **XIXe Siècle** : Bourgeoisie, anti-monarchie absolue

*Libéralisme Social (Social-Libéralisme)*
- **État-Providence** : Correction inégalités, services publics
- **Liberté Positive** : Capacités réelles, pas seulement formelles
- **Exemples** : New Deal (USA), sociaux-démocrates européens
- **Philosophes** : John Rawls ("Théorie de la Justice")

*Néo-Libéralisme*
- **Marché** : Extension tous domaines (éducation, santé)
- **Dérégulation** : Réduction intervention État
- **Privatisation** : Services publics
- **Mondialisation** : Libre-échange
- **Années 1980** : Reagan (USA), Thatcher (UK)
- **Critiques** : Inégalités, financiarisation, crises

*Libertarianisme*
- **État Minimal** : Seulement sécurité, justice, défense
- **Propriété Soi** : Corps, travail
- **Non-Agression** : Axiome fondamental
- **Exemples** : Robert Nozick, Ayn Rand, Ron Paul

**Penseurs**
- John Locke (1632-1704), John Stuart Mill (1806-1873), Friedrich Hayek (1899-1992)


### Socialisme / Social-Démocratie

**Socialisme (voir aussi [[Economy/Économie - Index#Socialisme]])**
- **Égalité** : Sociale, économique
- **Propriété Collective** : Moyens production (État, coopératives)
- **Planification** : Vs. anarchie marché
- **Solidarité** : Intérêt collectif > individuel

**Social-Démocratie**
- **Réformisme** : Changement graduel, démocratique
- **Économie Mixte** : Régulation marché, services publics
- **État-Providence** : Santé, éducation, retraites universelles
- **Redistribution** : Fiscalité progressive, allocations
- **Pleins Emploi** : Objectif politique
- **Exemples** : Scandinavie (Suède, Norvège, Danemark), Allemagne SPD

**Différence Socialisme Révolutionnaire**
- **Social-Démocrates** : Réforme capitalisme (Bernie Sanders, Jeremy Corbyn)
- **Socialistes** : Abolir capitalisme (Marx, Lénine)

**Partis**
- **Internationale Socialiste** : Coordination partis sociaux-démocrates
- SPD (Allemagne), Labour (UK), PS (France), PSOE (Espagne)


### Conservatisme

**Principes**
- **Tradition** : Sagesse accumulée générations
- **Ordre** : Stabilité, hiérarchies naturelles
- **Changement Graduel** : Réforme prudente, pas révolution
- **Scepticisme Raison** : Limites rationalisme (contre Lumières)
- **Famille, Religion** : Institutions fondamentales
- **Nation** : Identité, souveraineté

**Variantes**

*Conservatisme Traditionnel*
- **Burke** : "Reflections on the Revolution in France" (1790)
- **Aristocratie** : Élites naturelles
- **Église** : Morale, cohésion

*Conservatisme Libéral*
- **Économie** : Marché libre
- **Société** : Tradition, ordre moral
- **Exemples** : Thatcher, Reagan (fusionné avec néolibéralisme)

*Conservatisme Social*
- **Valeurs** : Famille traditionnelle, anti-avortement, anti-mariage homosexuel
- **Religion** : Christianisme (USA évangéliques)

*National-Conservatisme*
- **Souveraineté** : Anti-mondialisation, protectionnisme
- **Immigration** : Restriction
- **Exemples** : Orban (Hongrie), PiS (Pologne)

**Penseurs**
- Edmund Burke (1729-1797), Roger Scruton (1944-2020)

### Communisme

**Principes (Marx & Engels)**
- **Matérialisme Historique** : Lutte des classes moteur histoire
- **Aliénation** : Travailleur dépossédé sous capitalisme
- **Révolution** : Prolétariat renverse bourgeoisie
- **Dictature Prolétariat** : Phase transition
- **Société Sans Classes** : Communisme final (utopie)
  - Abolition propriété privée, État, argent
  - "De chacun selon capacités, à chacun selon besoins"

**Léninisme**
- **Parti d'Avant-Garde** : Révolutionnaires professionnels
- **Centralisme Démocratique** : Discipline parti
- **Révolution Russie** (1917) : Bolcheviks prennent pouvoir
- [[History/Russia/XX - Empire Russe]]

**Stalinisme**
- **Socialisme dans un Seul Pays** : Vs. révolution mondiale (Trotsky)
- **Planification** : Plans quinquennaux, collectivisation forcée
- **Terreur** : Purges, Goulags

**Maoïsme**
- **Paysannerie** : Vs. prolétariat urbain (Marx)
- **Révolution Permanente** : Révolution culturelle
- **Petit Livre Rouge** : Citations Mao

**Eurocommunisme**
- **Voie Démocratique** : Élections, pluralisme
- **Indépendance URSS** : Années 1970 (Italie, Espagne, France)

**Régimes Communistes Actuels**
- **Chine** : Capitalisme d'État autoritaire, parti unique (PCC)
- **Cuba** : Socialisme, réformes limitées
- **Vietnam, Laos** : Ouverture économique, autoritarisme politique
- **Corée du Nord** : Totalitarisme, dynastie Kim

**Effondrement Bloc Soviétique** (1989-1991)
- Chute Mur Berlin (1989), dissolution URSS (1991)
- Transition capitalisme (difficile : Russie années 1990)

### Fascisme

**Caractéristiques**
- **Nationalisme Extrême** : Culte nation, supériorité raciale/culturelle
- **Autoritarisme** : Chef charismatique (Duce, Führer)
- **Anti-Communisme** : Opposition farouche
- **Anti-Libéralisme** : Rejet démocratie, individualisme
- **Corporatisme** : État organise économie (syndicats, patronat)
- **Militarisme** : Glorification guerre, expansion
- **Totalitarisme** : Contrôle société (débat Italie vs. Allemagne)
- **Mythe Décadence** : Régénération par violence
- **Esthétique** : Symboles, rituels, propagande

**Exemples Historiques**
- **Italie** : Benito Mussolini (1922-1943)
  - Marche sur Rome (1922), Parti National Fasciste
  - Corporatisme, impérialisme (Éthiopie, Libye)
- **Allemagne** : Nazisme (1933-1945)
  - Adolf Hitler, NSDAP (Parti National-Socialiste)
  - Racisme (aryanisme, antisémitisme), espace vital (Lebensraum)
  - Shoah : Génocide 6 millions Juifs
  - [[History/WW2/Montée du nazisme]], [[History/WW2/Lebensborn]]
- **Espagne** : Franquisme (1939-1975, Franco)
- **Portugal** : Estado Novo (1933-1974, Salazar)
- **Japon** : Militarisme impérial (années 1930-1945)

**Néo-Fascisme Contemporain**
- Groupuscules extrême droite Europe, USA
- Symboles nazis, violence, racisme
- Illégal plupart pays démocratiques

**Différence avec Extrême Droite Moderne**
- Fascisme historique : Totalitarisme, guerre, corporatisme
- Extrême droite populiste : Nationalisme, immigration, démocratie illibérale

### Populisme

**Définition**
Opposition "peuple pur" vs. "élites corrompues" (Cas Mudde).

**Caractéristiques**
- **Antagonisme** : Nous (peuple) vs. Eux (élites, étrangers)
- **Leader Charismatique** : Incarnation volonté populaire
- **Anti-Establishment** : Rejet institutions, experts, médias
- **Démocratie Directe** : Référendums, contre représentation
- **Simplification** : Solutions simples problèmes complexes
- **Émotionnel** : Appel ressentiment, peur, fierté

**Types**

*Populisme de Gauche*
- **Cible** : Élites économiques, capitalisme, austérité
- **Exemples** : Podemos (Espagne), Syriza (Grèce), France Insoumise, Bernie Sanders
- **Thèmes** : Inégalités, services publics, souveraineté populaire

*Populisme de Droite*
- **Cible** : Immigration, islam, multiculturalisme, UE
- **Exemples** : Front National/RN (France), Lega (Italie), AfD (Allemagne), Trump (USA)
- **Thèmes** : Identité nationale, sécurité, tradition

**Contextes Favorable**
- **Crises** : Économique (2008), migratoire (2015), sanitaire (COVID)
- **Inégalités** : Déclassement classes moyennes
- **Défiance** : Institutions, partis traditionnels
- **Réseaux Sociaux** : Diffusion messages, polarisation

**Débats**
- **Menace Démocratie** : Dérive autoritaire, minorités menacées
- **Expression Légitime** : Voix oubliés, critique élites
- **Démocratie Illibérale** : Orban (Hongrie) - élections mais libertés restreintes

### Écologisme

**Principes**
- **Limites Planétaires** : Ressources finies, écosystèmes fragiles
- **Soutenabilité** : Besoins présents sans compromettre futurs
- **Décroissance** : Réduction production/consommation (débat)
- **Justice Environnementale** : Inégalités écologiques
- **Démocratie Écologique** : Participation, délibération

**Courants**

*Écologie Réformiste (Verte)*
- **Système** : Réforme capitalisme vert
- **Outils** : Taxes carbone, énergies renouvelables, régulation
- **Exemples** : Partis Verts (Allemagne, France), Green New Deal
- **Élections** : Participation gouvernements

*Écologie Radicale*
- **Système** : Rupture avec capitalisme
- **Décroissance** : Sortie croissance
- **[[Agriculture/Agriculture - Index#Permaculture]]** : Relocalisations, autonomie
- **Exemples** : Deep Ecology, écoféminisme

*Écologie Autoritaire*
- **Contrainte** : Restrictions libertés pour environnement
- **Débat** : Efficacité vs. dérive autoritaire

**Enjeux**
- [[Meteorology/Météorologie - Index#Changement Climatique]] : Urgence climatique
- [[Economy/Capitalisme de la finitude]] : Limites croissance
- Biodiversité, pollution, ressources (eau, minerais)

**Partis Politiques**
- Europe : Die Grünen (Allemagne), EELV (France), Groen (Belgique)
- Internationaux : Global Greens
