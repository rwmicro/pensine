# Systèmes Politiques


### Démocratie

**Définition**
Régime politique où le pouvoir appartient au peuple (du grec *demos* = peuple, *kratos* = pouvoir).

**Principes Fondamentaux**
- **Souveraineté Populaire** : Pouvoir légitime vient du peuple
- **Élections Libres** : Suffrage universel, secret, périodique
- **État de Droit** : Lois s'appliquent à tous, y compris gouvernants
- **Séparation Pouvoirs** : Exécutif, Législatif, Judiciaire (Montesquieu)
- **Libertés Fondamentales** : Expression, réunion, presse, association
- **Pluralisme** : Partis multiples, opposition légale
- **Alternance** : Changement pacifique pouvoir

**Types de Démocratie**

*Démocratie Directe*
- **Principe** : Citoyens décident directement des lois
- **Mécanismes** : Référendum, initiative populaire
- **Historique** : Athènes antique (Ve siècle av. J.-C.)
- **Moderne** : Suisse (référendums fréquents), Californie (initiatives)
- **Limites** : Complexité décisions, temps requis, taille population

*Démocratie Représentative*
- **Principe** : Citoyens élisent représentants qui décident
- **Avantages** : Efficacité, expertise, délibération
- **Types** :
  - **Parlementaire** : Gouvernement responsable devant parlement
  - **Présidentielle** : Président élu directement, indépendant législatif
  - **Semi-présidentielle** : Exécutif partagé (président + 1er ministre)

*Démocratie Délibérative*
- **Principe** : Décisions par délibération rationnelle, pas seulement vote
- **Outils** : Débats publics, jurys citoyens, budgets participatifs
- **Philosophes** : Jürgen Habermas

**Systèmes Électoraux**

*Scrutin Majoritaire*
- **Uninominal à un tour** : Plus de voix gagne (UK, USA, Canada)
  - Avantages : Simplicité, stabilité (majorités claires)
  - Inconvénients : Distorsion (perdants votes), bipartisme
- **Uninominal à deux tours** : Si pas majorité, 2e tour (France)
  - Avantages : Majorité absolue, représentation nuances
  - Inconvénients : Coûteux, alliances tactiques

*Scrutin Proportionnel*
- **Principe** : Sièges proportionnels aux voix (Pays-Bas, Israël)
- **Avantages** : Représentation fidèle, pluralisme
- **Inconvénients** : Fragmentation, coalitions instables
- **Seuil** : Minimum % voix pour sièges (5% Allemagne)

*Scrutin Mixte*
- **Combinaison** : Majoritaire + proportionnel (Allemagne, Nouvelle-Zélande)
- **Équilibre** : Stabilité + représentation

**Indices Démocratiques**
- **Democracy Index** (The Economist) :
  - Démocraties pleines : Norvège, Islande, Suède
  - Démocraties imparfaites : France, USA, Inde
  - Régimes hybrides : Turquie, Russie
  - Autoritaires : Chine, Arabie Saoudite, Corée du Nord
- **Freedom House** : Liberté politique, libertés civiles

**Défis Démocratiques**
- **Abstention** : Désintérêt, défiance
- **Populisme** : Simplification, démagogie
- **Désinformation** : Fake news, manipulation médias
- **Lobbying** : Influence intérêts particuliers
- **Inégalités** : Argent en politique, accès inégal
- **Technocratie** : Expertisation vs. souveraineté populaire


### Autoritarisme

**Définition**
Régime concentrant pouvoir dans mains d'un individu ou petit groupe, limitant libertés politiques.

**Caractéristiques**
- **Pouvoir Concentré** : Exécutif dominant
- **Libertés Limitées** : Presse, expression, association restreintes
- **Opposition Réprimée** : Partis interdits, dissidents emprisonnés
- **Élections Non-Libres** : Manipulées, pas alternatives crédibles
- **État de Droit Faible** : Justice contrôlée par pouvoir
- **Pluralisme Limité** : Mais pas nécessairement éliminé

**Variantes**

*Dictature Militaire*
- **Pouvoir** : Forces armées
- **Exemples** : Chili (Pinochet, 1973-1990), Myanmar (coup 2021)
- **Justification** : Ordre, stabilité, nationalisme

*Régime à Parti Unique*
- **Parti** : Monopole pouvoir politique
- **Exemples** : Chine (PCC), Vietnam, Cuba
- **Idéologie** : Souvent communiste, mais pas toujours

*Autocratie Personnelle*
- **Leader** : Culte personnalité
- **Exemples** : Turkménistan, Érythrée
- **Succession** : Dynastique parfois (Corée du Nord)

*Autoritarisme Compétitif (Régimes Hybrides)*
- **Élections** : Existent mais inéquitables
- **Opposition** : Tolérée mais handicapée
- **Exemples** : Russie (Poutine), Turquie (Erdoğan), Venezuela
- **Façade Démocratique** : Légitimité internationale

**Mécanismes de Contrôle**
- **Répression** : Police, armée, services secrets
- **Propagande** : Contrôle médias, censure
- **Cooptation** : Récompenses loyalistes, corruption
- **Clientélisme** : Faveurs en échange soutien
- **Nationalisme** : Mobilisation contre ennemis (externes/internes)

**Exemples Historiques**
- **Nazisme** : Allemagne ([[History/WW2/Montée du nazisme]], 1933-1945)
- **Fascisme** : Italie (Mussolini, 1922-1943)
- **Stalinisme** : URSS (Staline, 1927-1953)
- **Franquisme** : Espagne (Franco, 1939-1975)


### Totalitarisme

**Définition**
Forme extrême autoritarisme cherchant contrôle total société et vie privée.

**Caractéristiques (Hannah Arendt)**
- **Idéologie Totalisante** : Explication complète monde, utopie future
- **Parti Unique de Masse** : Mobilisation permanente population
- **Terreur** : Violence systématique, arbitraire (purges, camps)
- **Contrôle Médias** : Monopole information, propagande intense
- **Contrôle Économie** : Planification centralisée
- **Atomisation Sociale** : Destruction liens sociaux indépendants
- **Surveillance Totale** : Police secrète, délation
- **Culte Chef** : Leader divinisé

**Exemples Classiques**
- **Nazisme** : Allemagne (Hitler, 1933-1945)
  - Idéologie : Racisme, espace vital, antisémitisme
  - Terreur : Gestapo, camps concentration/extermination
  - [[History/WW2/Montée du nazisme]]
- **Stalinisme** : URSS (Staline, 1927-1953)
  - Idéologie : Communisme, homme nouveau
  - Terreur : NKVD, Goulags, grandes purges (1936-1938)
  - [[History/Russia/XX - Empire Russe]]
- **Maoïsme** : Chine (Mao, 1949-1976)
  - Révolution culturelle (1966-1976), gardes rouges
  - Grand Bond en avant (famine 15-45 millions)

**Débats**
- Corée du Nord aujourd'hui : Totalitaire ?
- Chine contemporaine : Autoritaire high-tech, pas totalitaire (espace privé limité)

**Différence Autoritarisme**
- **Autoritarisme** : Dépolitisation population (obéissance passive)
- **Totalitarisme** : Mobilisation active, enthousiasme forcé


### Monarchie

**Définition**
Régime où chef d'État est un monarque (roi, empereur, sultan) généralement héréditaire.

**Types**

*Monarchie Absolue*
- **Pouvoir** : Roi détient tous pouvoirs (exécutif, législatif, judiciaire)
- **Droit Divin** : Légitimité religieuse
- **Exemples Historiques** : Louis XIV (France, "L'État, c'est moi")
- **Exemples Actuels** : Arabie Saoudite, Brunei, Vatican (théocratie)
- **Caractéristiques** : Pas constitution, pas parlement élu

*Monarchie Constitutionnelle*
- **Constitution** : Pouvoirs roi limités par loi fondamentale
- **Parlement** : Partage pouvoir législatif
- **Exemples** : Maroc, Jordanie, Koweït
- **Roi** : Pouvoirs réels significatifs

*Monarchie Parlementaire*
- **Roi** : Rôle cérémoniel, symbolique
- **Pouvoir** : Gouvernement responsable devant parlement élu
- **Exemples** : Royaume-Uni, Espagne, Belgique, Pays-Bas, Suède, Japon
- **Avantages** : Continuité, neutralité, stabilité symbolique
- **"Le roi règne mais ne gouverne pas"**

**Monarchies Actuelles** (~40 pays)
- **Europe** : UK, Espagne, Belgique, Pays-Bas, Norvège, Suède, Danemark, Luxembourg, Monaco
- **Asie** : Japon, Thaïlande, Brunei, Bhoutan, Arabie Saoudite, Jordanie, Koweït, Bahreïn, Qatar, Oman, Émirats
- **Afrique** : Maroc, Lesotho, Eswatini
- **Océanie** : Tonga

**Succession**
- **Primogéniture** : Aîné hérite (traditionnellement masculin)
- **Réformes** : Égalité sexes (Suède 1980, Belgique 1991, UK 2013)


### Théocratie

**Définition**
Régime où pouvoir politique détenu par autorités religieuses ou légitimé par religion.

**Caractéristiques**
- **Loi Religieuse** : Charia (islam), Halakha (judaïsme)
- **Leaders Religieux** : Prêtres, ayatollahs, califes
- **Fusion** : Politique et religion indissociables

**Exemples**
- **Vatican** : Pape (monarchie élective théocratique)
- **Iran** : République islamique
  - Guide Suprême (ayatollah) > Président
  - Conseil Gardiens valide lois conformité islam
- **Afghanistan** : Émirat islamique (Taliban, depuis 2021)
- **Arabie Saoudite** : Monarchie absolue théocratique

**Historique**
- **Califats** : Omeyyade, Abbasside, Ottoman
- **États Pontificaux** : Vatican contrôlait Italie centrale (756-1870)
- **Tibet** : Dalaï-lama (avant 1959)


### Anarchie / Anarchisme

**Définition**
Absence d'autorité gouvernementale centralisée, ou idéologie prônant abolition État.

**Principes Anarchistes**
- **Anti-Autoritarisme** : Rejet hiérarchies coercitives
- **Auto-Organisation** : Communautés gèrent elles-mêmes
- **Fédéralisme** : Coordination horizontale, pas verticale
- **Action Directe** : Pas représentation
- **Entraide** : Solidarité (Kropotkine)

**Courants**
- **Anarcho-Communisme** : Kropotkine, propriété commune
- **Anarcho-Syndicalisme** : Syndicats, grève générale
- **Anarcho-Capitalisme** : Marché libre sans État (débat si vraiment anarchiste)
- **Anarcho-Primitivisme** : Retour société pré-industrielle

**Exemples Historiques**
- **Commune de Paris** (1871, France) : 2 mois
- **Territoire Libre** (Ukraine, 1918-1921, Makhno)
- **Catalogne Révolutionnaire** (Espagne, 1936-1939)

**Exemples Contemporains**
- **Rojava** (Kurdistan syrien) : Confédéralisme démocratique
- **Chiapas** (Mexique) : Zapatistes, autonomie indigène
- **ZAD** : Zones à défendre (France, occupations)

**Critiques**
- **Utopique** : Coordination grande échelle difficile
- **Sécurité** : Défense contre agression externe
- **Complexité** : Sociétés modernes nécessitent organisation
