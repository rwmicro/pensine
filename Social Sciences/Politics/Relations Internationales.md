# Relations Internationales


### Acteurs

**États**
- **Souveraineté** : Westphalie (1648) - principe non-intervention
- **Puissances** :
  - **Superpuissances** : USA (seule post-1991), Chine (émergente)
  - **Grandes Puissances** : Russie, UK, France, Allemagne, Japon
  - **Puissances Régionales** : Brésil, Inde, Turquie, Arabie Saoudite, Iran
  - **Puissances Moyennes** : Canada, Australie, Corée du Sud

**Organisations Internationales**
- **ONU** : 193 membres, sécurité collective (voir [[Geography/Géographie - Index#Organisations Internationales]])
- **UE** : 27 membres, intégration supranationale
- **OTAN** : 32 membres, alliance défense
- **OMC** : Commerce international
- **FMI, Banque Mondiale** : Finance, développement

**Acteurs Non-Étatiques**
- **ONG** : Amnesty, Greenpeace, MSF
- **Entreprises Multinationales** : Apple, Amazon, ExxonMobil
- **Groupes Armés** : Terroristes (Al-Qaïda, État Islamique), rebelles
- **Opinion Publique** : Mobilisations, réseaux sociaux

### Théories Relations Internationales

**Réalisme**
- **Anarchie** : Pas autorité supérieure États
- **Pouvoir** : Intérêt national, sécurité
- **Conflit** : Inévitable (nature humaine, structure système)
- **Équilibre Puissances** : Balance of power
- **Penseurs** : Thucydide, Machiavel, Morgenthau, Mearsheimer

**Libéralisme (Idéalisme)**
- **Coopération** : Possible via institutions
- **Démocraties** : Paix démocratique (ne se font pas guerre entre elles)
- **Interdépendance** : Commerce, organisations réduisent conflits
- **Droit International** : Règles, normes
- **Penseurs** : Kant ("Paix Perpétuelle"), Wilson

**Constructivisme**
- **Idées, Normes** : Constituent intérêts États
- **Identités** : Construites socialement
- **Culture Stratégique** : Détermine comportement
- **Changement** : Possible (pas structure fixe)
- **Penseur** : Alexander Wendt

**Marxisme**
- **Capitalisme** : Structure système international
- **Impérialisme** : Exploitation périphérie par centre
- **Dépendance** : Sous-développement résultat domination
- **Penseurs** : Lénine, Wallerstein (système-monde)

### Concepts Clés

**Puissance (Power)**
- **Hard Power** : Militaire, économique (coercition)
- **Soft Power** : Culture, valeurs, diplomatie (attraction)
- **Smart Power** : Combinaison hard + soft

**Sécurité**
- **Dilemme Sécurité** : Armes défensives perçues offensives → course armements
- **Sécurité Collective** : ONU, alliances (OTAN)
- **Sécurité Humaine** : Individus, pas seulement États

**Guerre et Paix**
- **Guerre Juste** : Critères (cause juste, proportionnalité, dernier recours)
- **Dissuasion** : Nucléaire (Guerre Froide)
- **Peacekeeping** : Casques bleus ONU
