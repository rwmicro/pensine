# Géopolitique

### Définition
Étude influence géographie (territoire, ressources, position) sur politique et relations internationales.

### Facteurs Géopolitiques

**Géographie Physique**
- **Accès Mer** : Ports, commerce (importance UK, Japon vs. enclavement Bolivie)
- **Ressources** : Pétrole (Moyen-Orient), minerais rares (Afrique)
- **Climat** : Agriculture, habitabilité
- **Frontières Naturelles** : Montagnes (Pyrénées), fleuves (Rhin)

**Position Stratégique**
- **Heartland** (Mackinder) : Contrôle Eurasie = domination mondiale
- **Rimland** (Spykman) : Périphérie Eurasie cruciale
- **Choke Points** : Détroits (Ormuz, Malacca, Gibraltar, Suez), canaux (Panama)

**Démographie**
- **Population** : Chine/Inde vs. Russie déclin
- **Jeunesse** : Afrique (opportunité/instabilité)

### Zones Géopolitiques Clés

**Moyen-Orient**
- **Pétrole** : 60% réserves mondiales
- **Conflits** : Israël-Palestine, Syrie, Yémen, Irak
- **Acteurs** : USA, Russie, Iran, Arabie Saoudite, Turquie
- [[History/Syrie/Répartition Ethnique]], [[History/Kurdes/Histoire]]

**Mer de Chine**
- **Tensions** : Chine revendique (ligne 9 traits), voisins contestent
- **Îles** : Spratleys, Paracels (constructions militaires Chine)
- **Commerce** : 30% commerce maritime mondial
- **USA** : Liberté navigation

**Arctique**
- **Fonte Glace** : Nouvelles routes maritimes, accès ressources
- **Revendications** : Russie, Canada, USA, Norvège, Danemark

**Afrique**
- **Ressources** : Cobalt (RDC), lithium, pétrole
- **Influence** : Chine (investissements), France (ex-colonies), USA
- **Conflits** : Sahel, Grands Lacs, Somalie

**Europe de l'Est**
- **Ukraine** : Guerre Russie (2022-), tampon OTAN/Russie
- **Pays Baltes** : Minorités russes, craintes agression
- [[History/Pridnestrovie - Transnistrie]]

### Enjeux Contemporains

**Multipolarité**
- **Fin Unipolarité** (USA seule, 1991-2010s)
- **Émergence** : Chine, Inde, Brésil
- **Rivalité USA-Chine** : Technologie, commerce, influence

**Cyber et Espace**
- **Cyberguerre** : Attaques infrastructures, ingérence élections
- **Espace** : Satellites (communication, espionnage), militarisation

**Climat et Migrations**
- **Réfugiés Climatiques** : Submersion îles, sécheresses
- **Ressources** : Guerres eau (Nil, Tigre-Euphrate)
