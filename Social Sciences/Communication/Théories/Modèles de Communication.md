# Modèles de Communication

Les grands modèles théoriques qui expliquent comment fonctionne la communication entre un émetteur et un récepteur.


### Modèle de Shannon-Weaver (1949)

Le modèle mathématique de la communication :

**Émetteur → Encodage → Canal → Décodage → Récepteur**

- **Bruit** : Toute interférence qui perturbe la transmission
- **Redondance** : Répétition pour contrer le bruit
- **Limites** : Modèle linéaire, ignore le contexte et le feedback

### Modèle de Jakobson (1960)

Six fonctions du langage :

1. **Référentielle** : Transmettre une information (contexte)
2. **Émotive** : Exprimer les émotions de l'émetteur
3. **Conative** : Agir sur le récepteur (ordre, conseil)
4. **Phatique** : Établir/maintenir le contact
5. **Métalinguistique** : Parler du code lui-même
6. **Poétique** : Focus sur la forme du message

### Modèle de Palo Alto

**École de Palo Alto** (Watzlawick, Bateson)

**Axiomes de la communication** :
1. On ne peut pas ne pas communiquer
2. Toute communication a un contenu et une relation
3. La nature d'une relation dépend de la ponctuation des séquences
4. Communication digitale (verbale) et analogique (non verbale)
5. Communication symétrique ou complémentaire

**Double contrainte (double bind)** :
- Messages contradictoires créant une situation sans issue
