# Rhétorique et Argumentation


### Rhétorique Classique

**Aristote** → [[Communication#La triade rhétorique d'Aristote|voir complet]]
- **Ethos** : crédibilité orateur
- **Logos** : arguments rationnels
- **Pathos** : émotions audience

**5 Canons de la Rhétorique**
1. **Inventio** : trouver arguments
2. **Dispositio** : organiser discours (exorde, narration, confirmation, réfutation, péroraison)
3. **Elocutio** : style, figures
4. **Memoria** : mémorisation
5. **Actio** : prononciation, gestuelle

### Argumentation Moderne

**Chaïm Perelman - Nouvelle Rhétorique (1958)**
- *Traité de l'argumentation*
- Rationalité argumentative (vs logique formelle)
- Auditoire universel vs particulier
- Techniques : exemple, illustration, analogie, métaphore

**Stephen Toulmin - Modèle Argumentatif (1958)**
- **Claim** (conclusion)
- **Data** (données)
- **Warrant** (garantie, lien data-claim)
- **Backing** (fondement warrant)
- **Qualifier** (modalisation)
- **Rebuttal** (réfutation)
