# Désirs — Psychologie et Philosophie

Le désir est une tension vers un objet que l'on se représente comme source de satisfaction. Il se situe entre le besoin (nécessité vitale) et le caprice (envie passagère). Le désir joue un rôle central dans la motivation humaine, l'identité et le bien-être.

## Définitions et distinctions

**Désir vs Besoin**

| | Besoin | Désir |
|---|---|---|
| Nature | Nécessité vitale ou physiologique | Aspiration subjective |
| Universalité | Objectif et universel | Culturel et individuel |
| Limite | Limité et satisfaisable | Illimité et tendanciellement insatiable |
| Exemples | Manger, dormir, sécurité | Reconnaissance, luxe, amour |

**Désir vs Volonté**

Le *désir* est une tension passive vers un objet — un état d'âme, une inclination ("je désire voyager"). La *volonté* est une décision active d'agir — un acte de la conscience, une détermination ("je décide de voyager"). La philosophie et la psychologie s'accordent sur cette distinction, mais divergent sur le rapport entre les deux.

## Perspectives philosophiques

### Platon : désir et raison

Dans le *Phèdre*, Platon décrit l'âme comme un char attelé à deux chevaux :

```
              ┌───────────────────────────────────────┐
              │           LE CHAR DE L'ÂME            │
              │                                       │
              │         [Cocher : la RAISON]          │
              │              (logistikon)              │
              │                  │                    │
              │        ┌─────────┴──────────┐         │
              │        │                    │         │
              │  [Cheval blanc]      [Cheval noir]    │
              │  Désirs nobles       Désirs vils       │
              │  (thumos : courage)  (epithumia :      │
              │                      appétits)        │
              └───────────────────────────────────────┘

  La raison doit gouverner les désirs pour atteindre la sagesse.
```

### Aristote : le juste milieu

Le désir n'est ni bon ni mauvais en soi — c'est l'excès ou le défaut qui pose problème. La *vertu* est le juste milieu entre deux extrêmes : le courage entre la lâcheté et la témérité, la tempérance entre l'insensibilité et l'intempérance.

### Épicure : hiérarchie des désirs

```
  Désirs naturels           Désirs vains
  et nécessaires            (ni naturels, ni nécessaires)
  ───────────────           ─────────────────────────────
  Faim, soif, sommeil       Gloire, richesse, pouvoir infini
  → Satisfaire              → Éviter : source d'insatisfaction
                            → Ces désirs croissent avec leur satisfaction

  Désirs naturels
  mais non nécessaires
  ─────────────────────
  Gastronomie, confort
  → Modération
```

**Ataraxie** : absence de trouble, tranquillité obtenue en satisfaisant les désirs nécessaires et en renonçant aux désirs vains.

### Stoïcisme : maîtrise des désirs (Épictète, Marc Aurèle)

```
  Dichotomie du contrôle

  ┌──────────────────────────────────────────────────────────┐
  │                  TOUT CE QUI EXISTE                      │
  │                                                          │
  │  ┌───────────────────────┐  ┌───────────────────────┐   │
  │  │  Ce qui dépend de MOI │  │ Ce qui ne dépend      │   │
  │  │                       │  │ PAS de moi            │   │
  │  │  • Mes jugements      │  │ • Corps, santé        │   │
  │  │  • Mes désirs         │  │ • Réputation          │   │
  │  │  • Mes aversions      │  │ • Richesse            │   │
  │  │  • Mes choix          │  │ • Opinions d'autrui   │   │
  │  │                       │  │ • Événements externes │   │
  │  │  → Liberté totale     │  │ → Ne pas en dépendre  │   │
  │  └───────────────────────┘  └───────────────────────┘   │
  └──────────────────────────────────────────────────────────┘

  Principe : ne désirer que ce qui dépend de nous.
  Accepter ce qui arrive : amor fati.
```

### Spinoza : le désir comme essence

Pour Spinoza, le désir (*conatus*) est l'effort de persévérer dans son être — c'est l'essence même de l'homme, pas un défaut à corriger. Il n'y a pas de jugement moral sur les désirs en soi. La joie augmente la puissance d'agir ; la tristesse la diminue. Comprendre ses désirs, c'est accéder à la liberté.

### Schopenhauer : le désir et la souffrance

```
  ┌────────────────────────────────────────────────────────────┐
  │               Le cycle de Schopenhauer                    │
  │                                                            │
  │   Désir  ──→  Tension  ──→  Souffrance (manque)           │
  │     ↑                              │                       │
  │     │                              ▼                       │
  │  Nouveau   ←──  Ennui  ←──  Satisfaction éphémère         │
  │  désir          (vide)                                     │
  │                                                            │
  │  "La vie oscille comme un pendule entre la souffrance      │
  │   et l'ennui."                                             │
  └────────────────────────────────────────────────────────────┘

  Solution proposée : ascétisme, contemplation esthétique, compassion.
```

### Nietzsche : désir et volonté de puissance

La *volonté de puissance* est le désir fondamental d'affirmer sa vie, de croître, de surpasser. Le désir n'est pas à éradiquer mais à *sublimer*. "Deviens ce que tu es" — *amor fati* : aimer son destin, affirmer la vie dans toutes ses dimensions.

### Freud : désir et inconscient

La *libido* est l'énergie psychique du désir. Le conflit psychique oppose :

```
  Ça          : désirs inconscients, principe de plaisir
  Surmoi      : interdits intériorisés, normes sociales
  Moi         : arbitre entre le ça et la réalité

  Sublimation : transformer les pulsions en créations socialement
                valorisées (art, science, religion)
```

### Lacan : désir et manque

"Le désir est le désir de l'Autre." Le désir naît d'un manque structurel — on ne désire jamais l'objet lui-même mais d'être reconnu, désiré par l'Autre. Le désir est donc constitutionnellement inextinguible.

```
  Besoin   : biologique, satisfaisable (faim → nourriture)
  Demande  : appel à l'Autre (demander à être aimé)
  Désir    : ce qui reste entre besoin et demande = le manque irreductible
```

## Perspectives psychologiques

### Maslow : pyramide des besoins

```
             ╱     ╲
            ╱  5.   ╲         Accomplissement de soi
           ╱ Accom-  ╲        Réalisation du potentiel
          ╱─plissement─╲
         ╱              ╲
        ╱   4. Estime    ╲     Confiance, respect, reconnaissance
       ╱──────────────────╲
      ╱                    ╲
     ╱  3. Appartenance    ╲   Amour, amitié, sentiment d'appartenir
    ╱────────────────────────╲
   ╱                          ╲
  ╱     2. Sécurité            ╲  Protection, stabilité, ordre
 ╱──────────────────────────────╲
╱                                ╲
╲    1. Besoins physiologiques   ╱  Faim, soif, sommeil, chaleur
 ╲══════════════════════════════╱

Les besoins supérieurs n'émergent significativement
que si les besoins inférieurs sont suffisamment satisfaits.
```

**Limites de Maslow :** l'ordre strict de la hiérarchie est contesté empiriquement. Des individus en situation de grande insécurité poursuivent des buts d'accomplissement, et vice versa.

### Théorie de l'autodétermination (Deci & Ryan)

Trois besoins psychologiques fondamentaux sont universels :

```
  AUTONOMIE     : sentiment de choisir ses actions, d'être l'auteur de sa vie
  COMPÉTENCE    : sentiment d'efficacité, de maîtrise
  RELATION      : sentiment d'appartenir, d'être lié à d'autres

  → Leur satisfaction favorise la motivation intrinsèque
    (faire une chose pour le plaisir de la faire)

  → Leur frustration génère motivation extrinsèque
    (faire pour une récompense, par peur) ou amotivation
```

### Désir mimétique (René Girard)

```
  Le triangle mimétique de Girard

         Objet (ce qui est désiré)
           ╱                   ╲
          ╱  désir de l'objet   ╲
         ╱                       ╲
  Sujet ─────────────────────── Médiateur
  (moi)   imitation du désir     (modèle : l'Autre
          du médiateur            dont je désire ce qu'il désire)

  "Je ne désire pas l'objet directement.
   Je désire ce que mon modèle désire."
```

**Conséquences :** rivalité (quand le même objet est désiré), violence (escalade du conflit), bouc émissaire (transfert de la violence sur un tiers). La publicité construit délibérément des modèles pour déclencher le désir mimétique.

## Paradoxes et limites du désir

### Le tapis roulant hédonique

On s'habitue rapidement aux nouveautés. Le niveau de bonheur subjectif revient à sa ligne de base après un gain (loterie) ou une perte (accident). Il faut toujours davantage pour maintenir le même plaisir.

### Paradoxe du désir

Désirer rend malheureux (Schopenhauer). Ne pas désirer rend la vie vide de sens. La résolution partielle : désirer le *processus* plutôt que seulement le résultat (Csikszentmihalyi : le *flow*).

### Le bonheur hédonique vs eudémonique

```
  Hédonisme       : satisfaction des désirs immédiats, plaisir
                    → bonheur éphémère, tapis roulant hédonique

  Eudémonisme     : épanouissement, réalisation de soi, vie vertueuse
  (Aristote)        → bonheur plus stable, corrélé au sens et aux relations
```

## Gestion des désirs

**Discernement**
- Ce désir est-il vraiment le mien ou influencé par autrui ? (Girard)
- Est-ce un besoin ou un caprice ?
- Ce désir est-il aligné avec mes valeurs ?

**Gratification différée (Mischel)**
Les enfants capables de résister à la guimauve pour en obtenir deux plus tard montraient de meilleures performances à long terme. La compétence s'entraîne : visualiser les conséquences à long terme, créer des obstacles entre soi et la tentation.

**Expression saine : la Communication Non Violente (Rosenberg)**

Structure en quatre étapes :
```
  1. Observation : décrire les faits sans jugement
  2. Sentiment   : exprimer son émotion
  3. Besoin      : identifier le besoin sous-jacent
  4. Demande     : formuler une demande claire et négociable

  Exemple :
  "Quand tu regardes ton téléphone pendant que je parle [observation],
   je me sens frustré [sentiment], car j'ai besoin d'attention [besoin].
   Pourrais-tu le ranger pendant notre conversation ? [demande]"
```

**Thérapie d'Acceptation et d'Engagement (ACT)**
Observer ses désirs sans jugement, comme des phénomènes mentaux qui passent. Agir selon ses valeurs, pas selon les impulsions du moment.

## Désirs et société

**Économie de l'attention**
Les plateformes numériques sont conçues pour créer le désir de revenir — par des récompenses variables (likes, notifications), exploitant les mêmes mécanismes dopaminergiques que les jeux d'argent.

**FOMO** (*Fear Of Missing Out*) : peur de rater quelque chose, amplifiée par la comparaison sociale permanente des réseaux sociaux.

**Publicité et désir mimétique**
La publicité crée le désir en montrant des modèles désirables qui possèdent ou désirent le produit — mécanisme girardien à l'échelle industrielle.
